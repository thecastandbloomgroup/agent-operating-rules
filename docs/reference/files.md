# Files

## Folders

| Folder   | Its job                                                                   | In git |
| -------- | ------------------------------------------------------------------------- | ------ |
| sources/ | What the repository delivers: the rules, and the data that the rules name | yes    |
| bin/     | Programs that a person or a task runs                                     | yes    |
| tests/   | The tests of the sources, and the records of each test run                | yes    |
| docs/    | Tutorials, how-to guides, reference and explanation                       | yes    |
| .build/  | The release folder that task build makes                                  | no     |
| .task/   | The checksum of the sources of task build, so Task skips a second build   | no     |
| dist/    | The release zip that task package makes                                   | no     |

## Each file

| File                                       | Purpose                                                                                                                                                                                              | Who reads it                   |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------ |
| sources/model-operating-rules.md           | The system prompt. Its version line matches version.json.                                                                                                                                            | Every model                    |
| sources/banned-words.txt                   | Word list read by deterministic-tests.py, by category                                                                                                                                                | People, deterministic-tests.py |
| bin/deterministic-tests.py                 | Tests with a fixed expected result: sentence length, dashes, banned words, citations, references                                                                                                     | People, CI                     |
| bin/check-links.py                         | Finds each relative link to a file that does not exist                                                                                                                                               | task docs                      |
| bin/check-commits.py                       | Finds each commit subject that is not a Conventional Commit 1.0.0                                                                                                                                    | task commits, CI               |
| bin/run-evaluation.py                      | Sends the evaluation prompts through the Perplexity Agent API, has two judges score each answer, writes one JSONL file per provider, merges them, and compares the scores of a human with the judges | task eval, people              |
| bin/script-checks.py                       | Scores the answers of runs with the script checks of item-labels.yaml, with no judge and no API call, and compares two runs                                                                          | People                         |
| bin/judge-actions.py                       | Samples labelled actions of a run, and has a judge of another provider check the domain and the reason of each                                                                                       | People                         |
| bin/judge-loo.py                           | Judges each row of a marking sheet with the human marks of the other rows as examples, and prints the kappa with the human                                                                           | People                         |
| bin/judge-procedures.py                    | Has a judge of another provider score the procedure of each passed P7 unit on three criteria, from 0 to 100                                                                                          | People                         |
| bin/bloom-calibration.py                   | Samples questions with Bloom labels by people, and scores the labels of a model against them                                                                                                         | People                         |
| bin/ladder-scores.py                       | Scores each model on the Bloom ladders of the design note, from the script checks, judge checks, and tool checks of runs                                                                             | People                         |
| bin/second-turn.py                         | Sends a second turn after answers of a run: pushback, the note of a judge, or a plain retry                                                                                                          | People                         |
| bin/marking-items.py                       | Writes the items of a marking sheet: the prompt, the End section, and the action text of each row, with no judge result                                                                              | task marking                   |
| tools/marking/                             | A local SvelteKit app for blind marking: one action at a time, saved to the sheet, with the judge agreement shown only after the last mark                                                           | task marking, people           |
| bin/run-psychomotor.py                     | Sends the psychomotor prompts to the executors with the sandbox tools, and saves the transcript and sandbox of each unit                                                                             | People                         |
| bin/repair-psychomotor.py                  | Sends a second turn to the failed psychomotor units of a run, from the end state of each sandbox, in a named or a retry mode                                                                         | People                         |
| bin/tool-sandbox.py                        | The four file tools of the psychomotor prompts, confined to one sandbox folder                                                                                                                       | bin/run-psychomotor.py         |
| bin/check-psychomotor.py                   | Grades a psychomotor run from its transcripts and sandbox end states, and writes tool-checks.csv                                                                                                     | People                         |
| install.sh                                 | Installs the rules file for one agent harness, as a pointer or a copy, and never overwrites other content                                                                                            | People, agents                 |
| bin/record-evaluation.py                   | Writes evaluation-scores.csv, the summary and runs of evaluation-results.md, and the results of the evaluation reference, from the run folders                                                       |                                |
| bin/connect-doppler-to-gitlab.sh           | Makes a Doppler service token for the config `dev` of `cast-and-bloom`, and pipes it into the GitLab variable `DOPPLER_TOKEN`                                                                        | People, one time               |
| tests/unit/test_bin.py                     | The unit tests of the scripts in bin/, with unittest of the standard library                                                                                                                         | task test                      |
| tests/evaluation/evaluation-tests.md       | Prompts and a rubric for the judgment rules in Sections 6.4 and 6.5                                                                                                                                  | People, graders                |
| tests/evaluation/item-labels.yaml          | The Bloom's taxonomy label of each evaluation item: taxonomy, level, expected evidence, and yes or no checks with a grader each                                                                      | People, graders                |
| tests/evaluation/pairs.json                | The executor and judges of each provider, the order of its models, and the price of each model                                                                                                       | bin/run-evaluation.py          |
| tests/evaluation/evaluation-results.md     | Log of evaluation runs: one block per model per run, plus a cross-model summary. `task eval:record` writes it                                                                                        | People                         |
| tests/evaluation/evaluation-scores.csv     | One row per prompt per grader for each recorded run; the data behind any summary or chart                                                                                                            | People, scripts                |
| tests/evaluation/attachments/              | The files that a prompt names as attached, one folder per prompt ID. The run sends them with the prompt to the executor and the judges                                                               | bin/run-evaluation.py          |
| tests/evaluation/psychomotor-tests.md      | Prompts for the psychomotor ladder, one per level from Perception to Origination, with the checks of each                                                                                            | People, bin/run-psychomotor.py |
| tests/evaluation/sandbox/                  | The sandbox fixture of each psychomotor prompt, one folder per prompt ID. Each unit of a run acts on its own copy                                                                                    | bin/run-psychomotor.py         |
| tests/evaluation/results/                  | One folder for each evaluation run, and the responses that a person scores by hand                                                                                                                   | People, graders                |
| tests/evaluation/results/harness-log.jsonl | The episodic log of harness sessions under the rules: one line per session, with each break of the rules                                                                                             | People, future probes          |
| README.md                                  | What the rules file is, and why one file serves all models                                                                                                                                           | People                         |
| CHANGELOG.md                               | The changes of each version, in the format of Keep a Changelog 1.1.0                                                                                                                                 | People, task build             |
| version.json                               | The version, as its Semantic Versioning parts. The major version stays at 0                                                                                                                          | People, task build             |
| Taskfile.yml                               | The tasks of each CI stage, and the pinned versions of the format and lint tools                                                                                                                     | People, CI                     |
| .gitlab-ci.yml                             | The GitLab pipeline: one job per stage, and each job calls its task                                                                                                                                  | GitLab                         |
| .pymarkdown.json                           | The settings of the Markdown lint                                                                                                                                                                    | task lint                      |
