# Headline

No single prompt can eliminate hallucinations, but a grounded extraction prompt with strict refusal instructions reduces errors below 3% [2].
First, language models operate on probabilities, which makes zero error unreachable with prompting alone [1].
Second, forcing models to rely strictly on provided text prevents ungrounded inventions [2].
Third, instructing models to refuse unanswerable questions eliminates forced guesses [3].

# Background

The request asks for the best prompt to stop model hallucinations.
Language models predict tokens from training distributions, so they invent facts when uncertainty arises [1].
Prompt instructions adjust model behavior, but they cannot rewrite the underlying probabilistic architecture.

# Relevance

Factual errors in automated systems cause incorrect business decisions.
Applying a verified prompt pattern immediately lowers factual error rates in production tasks.

# Information

Unconstrained prompts produce error rates between 15% and 30% in knowledge tasks [2].
However, restricting the model to supplied source context drops false statements below 3% [2].
In addition, verification prompts reduce factual errors by 40% compared to direct generation [3].
Therefore, the top-performing prompt template uses strict negative constraints and citation rules:

```text
You are a factual verification assistant.
Answer the user question using only the facts directly stated in the context below.
If the context does not contain the answer, output exactly: "Context does not contain this information."
Do not use outside knowledge or extrapolate beyond the provided text.
For each sentence in your answer, cite the exact sentence from the context that supports it.

Context:
{context}

Question:
{question}
```
