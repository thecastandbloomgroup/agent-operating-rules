### Information

PostgreSQL supports column renames through the `ALTER TABLE` command [1].
The operation acquires an `ACCESS EXCLUSIVE` lock [1].
However, the operation does not rewrite table data [1].
The lock duration is brief because the engine only updates catalog rows [1].
If existing transactions hold locks on the table, the rename statement waits [judgment].
Waiting statements block following reads and writes [judgment].
Therefore, we set `lock_timeout` before the rename statement [judgment].
