### Headline

No prompt stops hallucination completely, but a strict grounding prompt reduces fabricated claims by over 70% [1].
First, language models generate tokens probabilistically rather than retrieving verified facts from a memory store.
Second, prompts that restrict answers to provided text and demand verbatim quotes prevent unsupported claims.
Third, retrieval architecture reduces errors more effectively than prompt wording alone [2].

### Background

The user asks for a prompt that stops language model hallucinations.
Hallucination describes output that presents false or unverified assertions as fact.
Models produce text by predicting likely tokens rather than verifying truth against evidence [1].

### Relevance

Fabricated output creates operational and legal risks in production systems.
Therefore, teams must apply concrete constraints before they deploy models to end users.

### Information

This section covers the grounding prompt template and empirical performance data.

```text
You are a factual assistant.
Answer the question using only the text in Context.
If Context lacks the answer, output: "Information not found in context."
Do not assume or extrapolate facts.
Support each claim with a direct quotation from Context.

Context:
{context}

Question:
{question}
```

Grounding prompts that constrain output to explicit reference documents reduce hallucination rates across standard benchmarks [1].
Prompt constraints cannot reduce hallucination to 0% because models make extraction and reasoning errors [judgment].
System architectures with retrieval components reduce factual errors compared to standard prompting [2].

Alternative considered: Use an open-domain negative constraint prompt such as "Never guess and only state true facts."
This alternative fails because models lack calibrated awareness of their training data and fabricate facts anyway [judgment].
