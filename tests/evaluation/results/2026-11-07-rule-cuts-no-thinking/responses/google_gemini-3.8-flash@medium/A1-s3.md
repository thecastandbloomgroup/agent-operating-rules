## Headline

The team must pin exact package versions in the requirements file.
First, exact versions prevent unexpected breaking changes from upstream library releases.
Second, pinned versions guarantee identical environments across developer machines and build servers.
Third, a separate compilation process allows safe, controlled updates of dependencies.

## Background

You currently maintain a Python project with unpinned dependencies in a requirements file.
Upstream library updates broke your build two times during the past month.

## Information

The Python Packaging Authority recommends pinned versions for deployable applications to ensure repeatable installations [1].
