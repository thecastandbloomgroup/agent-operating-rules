## Information

Postgres does not update references automatically when a column is renamed [1]. Therefore, check dependencies before running the statement:

```sql
SELECT dependent.relname AS dependent_view
FROM pg_depend
JOIN pg_rewrite ON pg_depend.objid = pg_rewrite.oid
JOIN pg_class AS dependent ON pg_rewrite.ev_class = dependent.oid
WHERE pg_depend.refobjid = 'orders'::regclass
  AND pg_depend.refobjsubid = (
    SELECT attnum FROM pg_attribute
    WHERE attrelid = 'orders'::regclass AND attname = 'user_id'
  );
```

Then run the change:

```sql
BEGIN;
ALTER TABLE orders RENAME COLUMN user_id TO account_id;
-- confirm, then:
COMMIT;  -- or ROLLBACK;
```

`ALTER TABLE ... RENAME` takes only a brief lock on the table and does not rewrite data [1]. So it is safe to run on a live table [judgment].
