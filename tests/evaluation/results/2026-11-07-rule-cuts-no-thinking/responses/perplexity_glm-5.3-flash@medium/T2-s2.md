## Headline

No prompt removes hallucination, so the best prompt forces an answer from attached text, a named quote, and the refusal line "Not in the sources".

1. An answer built from visible text beats an answer built from memory, because retrieval at answer time improves factuality on knowledge tasks [1].
2. Instruction alone reduces but does not stop fabrication, so add an error rate that you can measure [judgment].
3. When no source exists, force confidence labels and treat the low labels as leads, not as facts [judgment].

## Background

The request asks for the one prompt that stops a model from hallucinating. Hallucination here means a fluent claim with no source. The request gives no interface, no task, and no source set.

## Relevance

A prompt that fails silently damages decisions, because unsupported names, dates, and numbers look like verified facts [2]. A prompt that shows its evidence lets a reader check each claim in seconds.

## Information

Two forms cover the cases. First, the grounded form, used when you can attach text.

```text
Answer only from the text under SOURCES.
After each claim, quote the exact sentence that supports it.
If the SOURCES text does not contain the answer, write "Not in the sources". Do not guess.
If SOURCES is empty or missing, ask me to attach it.
```

This is the smallest version of retrieval augmented generation, where the system fetches the text before the answer [1]. Copying a visible sentence is easier than recalling a fact, because the model does not generate the fact at all [inference]. The quote also gives the reader a check in one glance [judgment].

Second, the confidence form, used when no source exists.

```text
Answer in numbered steps.
Before each claim, write one confidence label: high, medium, or low.
Use high only when you can name the source of the fact.
Use low when you recall the fact but cannot name its source.
If you do not recall a fact, write "I am not sure". Do not invent names, dates, numbers, or citations.
After the answer, list every claim labeled low, so a human can check them.
```

Surveys of text generation list hallucination as an open problem, so no form is a full fix [2]. The confidence labels turn silent guesses into visible leads [judgment].

Assumption: the question goes to a chat model that reads attached text. Why not measured: the request does not name the interface. Validate by: check the input screen for a file or text limit. If wrong: use the confidence form only, and check its low labels more strictly.

Assumption: no human reviews every answer before reuse. Why not measured: the request does not state a review step. Validate by: confirm the review practice with the answer owner. If wrong: with a full review, skip the confidence form and keep the grounded form.

Alternative considered: keep free chat and rely on instruction only. It loses because generating a fact is harder than copying it [1], and because free chat gives you no count to track [judgment].

## End

I recommend that we take four actions. Order follows leverage, and the largest blocker is answering from memory [judgment].

1. **Attach sources and use the grounded form.** Increment: one prompt plus pasted text, done in one session. Blocker removed: answers from memory, where fabrication starts. Test (stochastic, written first): the metric is unsupported claims per answer, the baseline is the current free-chat rate, the pass threshold is 0 unsupported claims, the sample size is 10 questions with known answers.
```text
Given a question with a known answer
When the model answers with the grounded form
Then every claim carries a quote, and the answer contains no claim outside SOURCES
```
Domain: Clear; copying a visible fact follows a known rule, so this is deduction from [1].
2. **Score the grounded form against the free form.** Increment: one scoring session on the same 10 questions. Blocker removed: the change would otherwise rest on opinion. Step 2 MUST NOT start until Step 1 has a source set. Test (evaluative, rubric first): criteria are unsupported-claim rate (weight 5), refusal correctness (weight 3), answer usefulness (weight 2); pass threshold is a total of 8 of 10; evidence is the scored answers. Domain: Complicated; the score analysis picks the practice, so this is deduction.
3. **Use the confidence form when no source exists, and check the low labels before reuse.** Increment: one prompt plus a check step. Blocker removed: silent guesses. Test (evaluative): the rubric is reuse only after each named fact passes a human check against the origin. Domain: Clear; verifying a named fact against its origin is a fixed rule.
4. **Log the unsupported-claim count per week.** Increment: one count sheet, 10 sampled answers per week, budget of 1 hour per week. Blocker removed: drift in model behavior becomes visible. Step 4 MUST NOT start until Step 2 picks a form. Test (stochastic): the metric is unsupported claims per 10 answers, the baseline is the Step 2 count, the pass threshold is at or below that baseline after 4 weeks, the sample size is 10 per week. Domain: Complex; the effect across weeks shows only in the data, so this is induction from trials, and the budget caps the probe.

If the chat tool cannot take attached text, replace Step 1 with Step 3 and keep the log.

## Follow-up

Condition that changes the recommendation: if the task must answer without any attached source, the grounded form does not apply, and the error rate rises [judgment].
