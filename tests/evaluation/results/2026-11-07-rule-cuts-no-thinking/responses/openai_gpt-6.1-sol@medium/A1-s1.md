## Information

Include indirect dependencies, which are packages your chosen libraries require. Pinning only direct dependencies leaves indirect dependencies free to change. [judgment]

Keep a separate list of direct dependencies if that makes maintenance easier. Generate the complete, pinned `requirements.txt` from that list with a dependency tool such as `pip-tools`. [judgment]

Pins control package versions, not the whole build environment. Keep the Python version and build environment stable too. [judgment]
