## Information

An exact pin looks like `package-name==1.2.3`. Dependencies installed through another package are called *transitive dependencies*.

For an application, record exact versions for both direct and transitive dependencies. Otherwise, an unpinned transitive dependency can still change between installs. [judgment]

Use a verified environment as the source, not an arbitrary developer environment. A command such as `python -m pip freeze > requirements.txt` records installed versions, including unrelated packages present there. [judgment]
