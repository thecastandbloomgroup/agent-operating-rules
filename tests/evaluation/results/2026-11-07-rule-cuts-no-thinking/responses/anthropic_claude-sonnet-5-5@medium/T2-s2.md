## Headline

No prompt removes hallucination, but a grounded prompt with a permitted refusal reduces it the most.

- Models guess when they lack facts, so the prompt must supply the facts and allow "Not in the sources." [4]
- A quote requirement makes each claim checkable.
- A second verification pass catches errors that the first pass misses. [2]
- A short test on your own questions shows whether the prompt works.

## Background

You asked for one prompt that stops a model from stating false facts. Such false output is called hallucination. Surveys describe it as output that is fluent but unfaithful to the source or to reality. [1]

## Relevance

You will rely on the model's answers, so a false claim costs you time or trust. A tested prompt is cheaper than a late correction.

## Information

Use this prompt. Paste your source text where marked.

```text
Answer only from the sources below.
Do not use outside knowledge. Do not guess.
For each claim, quote the passage that supports it.
Label each claim "quoted" or "inferred".
If the sources do not contain the answer, write: Not in the sources.
End with a confidence level (high, medium, or low) and the reason.

Sources:
[paste text here]

Question:
[paste question here]
```

Evidence for each design choice:

- Retrieval of source text before generation improved factual accuracy on knowledge tasks in the original study. [3]
- A verify step that checks each claim with separate questions lowered false claims in tested lists and long answers. [2]
- Theory says a model trained to be calibrated must still produce some false facts, so zero hallucination is not a realistic goal. [4]
- The refusal line works because it gives the model a safe output when evidence is missing. This is [judgment]; no source in this session measures it.
