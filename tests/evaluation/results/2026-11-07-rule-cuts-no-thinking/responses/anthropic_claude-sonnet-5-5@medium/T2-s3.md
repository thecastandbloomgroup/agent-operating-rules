## Headline

No prompt stops hallucination (output that sounds right but is false), but the prompt in the Information section lowers it, and a short test shows by how much.

- A prompt cannot remove the cause, because models learn to guess when they are unsure [1].
- The prompt works by allowing "Not known", requiring a source for each claim, and adding a self-check [2].
- Source text in the prompt cuts errors more than any wording does [judgment].
- You must test the prompt on your own questions, because results differ by model and task.

## Background

You want one prompt that stops a model from inventing facts. The material does not name the model or the task. This answer gives a general prompt and a way to test it.

## Relevance

A wrong answer that sounds sure is costly, because the reader acts on it. A tested prompt gives you a measured gain instead of a hope.

## Information

**Evidence.** It is very likely (90 to 100%) that no prompt gives zero hallucination. Training and scoring reward a guess over "unknown", so models guess [1].

Models can often judge whether their own answer is true [2]. That supports the "Not known" and confidence clauses.

A draft, check, and revise loop reduced hallucination in published tests [3]. That supports the self-check clause.

It is likely (66 to 100%) that the prompt lowers the error rate on factual questions [judgment]. The size of the drop is not known until you test it.

**The prompt.** Put it in the system message:

```text
Answer only from the sources provided or from facts you know with high confidence.
If you do not know, reply "Not known." Do not guess.
Do not invent names, numbers, quotes, or links.
After each factual claim, name its source or write "no source".
State your confidence as high, medium, or low.
Before you finish, check each claim. Remove any claim you cannot support.
```

**Assumption log.**
Assumption: the model is a chat model with no search tool. Why not measured: the material does not state it. Validate by: check the model settings for tool access. If wrong: skip Step 2 and ground the model on sources first.

**Alternative considered.** Retrieval means you give the model source text and require answers from it. It beats any wording change when facts are narrow or recent [judgment]. It loses here because it needs a document store, and you asked for a prompt.

## End

I recommend that we take these steps in order:

1. **Build a test set of 50 questions, 20 of them unanswerable.**
   - Increment: one working session.
   - Blocker removed: without a test set, no one can see whether the prompt works.
   - Kind: deterministic.
   - Cynefin domain: Clear, because grading against known answers is a known practice (deduction).
   - Test:
     - Given 50 questions with verified answers and 20 marked "no answer exists"
     - When a reviewer checks the file
     - Then every question has one verified answer or the "no answer exists" mark

2. **Run the prompt as a probe against the baseline.** Step 2 MUST NOT start until the test in Step 1 passes.
   - Increment: 3 runs per arm, 150 calls per arm, one session.
   - Capability added: a measured effect size.
   - Kind: stochastic.
   - Cynefin domain: Complex, because the effect varies by model and task (induction). A new model or question type could break the pattern. Leverage is a guess.
   - Test:
     - Metric: share of answers that are wrong and stated with confidence.
     - Baseline: the same model with no prompt.
     - Pass threshold: a relative drop of at least 30%, and correct answers to answerable questions fall by no more than 5 points.
     - Sample size: 150 answers per arm.
   - Stop condition: 300 calls in total, or a worse result than baseline after run 2.

3. **Add source text if Step 2 fails the threshold.** Step 3 MUST NOT start until Step 2 reports its result.
   - Increment: paste the relevant documents into the prompt for the 50 questions.
   - Blocker removed: the model has no facts to draw on.
   - Kind: deterministic.
   - Cynefin domain: Complicated, because you must first analyse which documents cover the questions (deduction from the analysis).
   - Test:
     - Given a source that lacks the answer
     - When the model gets the question
     - Then the reply is "Not known."

## Follow-up

**Conditions that change the recommendation.**
- If Step 2 meets the threshold, skip Step 3 and keep the prompt.
- If the model has search tools, add the line "Search before you answer" and rerun Step 2.
