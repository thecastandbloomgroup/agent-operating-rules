## Headline

Yes, pin every version, including indirect dependencies, and update the pins on a schedule.

- An unpinned install takes the newest release, so each upstream release can change your build.
- Two breaks in one month show that this risk is real in your project [1].
- Pins for direct and indirect packages make each build install the same set.
- A scheduled update keeps the pins from going stale.
