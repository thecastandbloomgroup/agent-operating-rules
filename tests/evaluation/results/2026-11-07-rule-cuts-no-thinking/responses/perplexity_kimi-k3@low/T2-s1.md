## Headline

Use a prompt that permits the model to refuse: "Answer only if you know. If unsure or you lack a source, say 'I do not know.' Never guess or invent facts."

- A clear exit option cuts false claims more than any other phrasing does [judgment].
- Demanding a source per claim adds a check the model cannot fake well [judgment].
- Short tasks with narrow scope reduce error rates [judgment].

## Background

You want one prompt that reduces fabricated answers from a language model. Hallucination means the model states false or invented content as fact.

## Relevance

Hallucination has no single fix, because model behavior varies across runs. A well-formed prompt is the cheapest control you can apply today.

## Information

The strongest prompt pattern in practice [judgment, no source]:

```text
Answer the question using only facts you are confident are true.
For each key claim, state a source (title, author, year) or say "[no source]".
If you do not know, say "I do not know" and stop. Do not guess.
Keep the answer as short as the question allows.
```

Why it works: it permits refusal, so the model's default of always answering changes [judgment]. It also forces visible sourcing, so unsupported claims stand out [judgment]. Alternative considered: using retrieval augmented generation, that is, giving the model documents to answer from. This beats prompting alone [judgment], but it costs setup time and infrastructure, so the prompt wins as the immediate step.

Assumption: the failure is generic fabrication, not wrong facts inside supplied documents. Why not measured: the material does not state it. Validate by: test the prompt on ten questions where truth is known. If wrong: add Step 3 (document grounding).

## End

I recommend that we act in this order:

1. **Adopt the prompt above for your next real query.** Increment: paste it before one question in one session. Blocker removed: the model guesses when it lacks knowledge. Domain: Clear, deduction from a known rule. Task kind: stochastic, so write the acceptance test first:
   - Metric: rate of false factual claims. Baseline: your current rate without the prompt. Pass threshold: fewer false claims. Sample size: 10 questions with known answers.
2. **Add a follow-up instruction that asks for sources per claim.** Increment: add one line asking for title, author, and year. Blocker removed: unsupported claims pass unnoticed. Test: same metric, threshold, and sample size as Step 1. Domain: Clear, deduction. Task kind: stochastic, test written first.
3. **Feed the model the source documents and ask it to quote them directly.** Increment: attach one document to one query this session. Blocker removed: answers without any basis in real text. Test: Given a question whose answer sits in the attached document, When the model answers, Then every claim matches a quoted passage. Domain: Complicated, analysis of which passages apply. Task kind: deterministic, Gherkin test written before the run.

Step 3 MAY wait, but Steps 1 and 2 run together in one session.

## Follow-up

No open questions. No references: all claims are judgment. Condition that changes this: if the model answers questions about documents you supply, start with Step 3 instead.
