## Headline

No single prompt stops hallucination, because the model cannot verify its own facts, but one prompt design reduces it most: require the model to answer only from provided material and to say "I don't know" otherwise. This works because most hallucinations come from the model filling gaps with plausible text rather than from missing knowledge. Adding a rule to cite a source for every claim adds a second line of defense.

## Background

You want one prompt that makes a language model stop inventing false facts. Hallucination means the model states false or unverifiable content as fact.

## Relevance

Prompts only help when the model has access to true material or a tool to check. Without either, no prompt achieves zero hallucination, so the goal shifts to reduction [judgment].

## Information

Research on retrieval-augmented generation, which grounds answers in supplied documents, reduces factual error rates against a no-context baseline [1]. However, even grounded models still hallucinate at low rates, so a human or tool check on claims remains necessary [judgment].

Assumption: you use the model through a chat or API with no retrieval tool attached. Why not measured: the material does not state your setup. Validate by: test the prompt in your setup within one session. If wrong: add a retrieval step before the prompt.

**Best prompt, copy and adapt:**

```text
Answer using only the text below. If the text does not contain
the answer, reply: "Not in the provided material."
Quote the line that supports each claim. Do not use any other
knowledge.

TEXT:
<paste the source material here>

QUESTION:
<your question>
```

Alternative considered: "think carefully and be accurate" style prompts. These lose because they state a goal with no mechanism. Tests show goal-only phrasing does not reduce factual error reliably [judgment].

## End

I recommend that we do three steps:

1. Paste the prompt above with your source text and a question you know the answer to. This is a deterministic check. Given a source text and question, When the model answers, Then every claim carries a quote from the text.
2. Ask one question whose answer is not in the text. Given missing information, When the model answers, Then it replies "Not in the provided material."
3. If both pass, add a retrieval tool or attach reference documents for real use, because volume of source material is what shrinks the hallucination space at scale [1]. This step is Complicated, since tool choice needs analysis of your setup. It must not start until Steps 1 and 2 pass.

Steps 1 and 2 are Clear domain, because a known best practice exists and cause and effect are known. Step 3 is Complicated, with deduction from your [judgment: deleted—no] your case requirements.

If you have no source text to supply, replace the prompt with: "If you are not sure, say 'uncertain' and state what source would settle it." This reduces, but does not remove, false claims.
