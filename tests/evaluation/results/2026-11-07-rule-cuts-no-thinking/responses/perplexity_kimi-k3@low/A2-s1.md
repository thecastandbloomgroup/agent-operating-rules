## Information

The command is:

```sql
ALTER TABLE orders RENAME COLUMN user_id TO account_id;
```

Postgres renames metadata only, so it runs in milliseconds and preserves indexes, constraints, and defaults. Views that reference the column follow the rename automatically [1]. Foreign keys from other tables that point at orders.user_id also follow the rename [1]. It takes an ACCESS EXCLUSIVE lock for the length of the statement [1].
