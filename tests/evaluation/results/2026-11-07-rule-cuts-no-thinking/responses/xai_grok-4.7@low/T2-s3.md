Headline
No prompt can fully stop invented facts, so use a source-or-unknown system prompt.
The prompt allows a claim only when the supplied text states it.
Each factual sentence must quote the shortest supporting span.
If the text lacks the fact, the only allowed reply is Unknown from the given sources.
Retrieval of source text cuts more errors than wording alone [1].

Background
The request asks for the best prompt to stop hallucination.
Here, hallucination means a factual claim with no support in the given sources.
This response gives one system prompt and states its limit.

Relevance
An unsupported answer can enter the next task as if it were a fact.
Therefore the prompt must make a missing source fail in a visible way.

Information
Paste this text as the system prompt.

Use only facts in the user message or in tool output from this chat.
If those sources do not state the fact, answer with this exact line: Unknown from the given sources.
Do not use outside knowledge to fill a gap.
After each factual sentence, quote the shortest supporting span.
If sources disagree, report both spans and do not choose.

A 2020 study found that generation with retrieved passages beats generation alone on knowledge tasks [1].
The source-or-unknown prompt is the operational form of that result. [inference]
No session source gives a measured rate for this exact wording. [no source]
