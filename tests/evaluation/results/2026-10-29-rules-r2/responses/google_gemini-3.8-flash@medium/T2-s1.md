### Headline

No single prompt stops all hallucinations, but a grounding prompt with an explicit refusal instruction reduces false statements.
Prompting alone cannot eliminate hallucinations because language models generate text by token probability rather than factual verification [inference].
Prompts that restrict answers to supplied context and mandate a refusal string cut unsupported statements [1].

You asked for the best prompt to prevent model hallucinations.

### Relevance

### Information

A system prompt reduces hallucinations by forcing the model to rely only on provided documents [1].
Research shows that truthfulness benchmarks improve when models receive explicit instructions to admit ignorance [2].
For example, TruthfulQA tests show that instruction-tuned models double their truthfulness scores when prompted to refuse unknown questions [2].

Use this system prompt template for grounded tasks:

```text
You are a factual assistant. Answer the question using ONLY the facts provided in the Context below.
If the Context does not contain the answer, state: "The provided context does not contain this information."
Do not use outside knowledge. Do not extrapolate.
Cite the exact sentence from the Context that supports each claim.

Context:
{context}

Question:
{question}
```
