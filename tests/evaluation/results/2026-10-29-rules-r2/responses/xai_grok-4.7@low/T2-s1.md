Headline
No prompt makes a model stop inventing facts.
Limit answers to text you supply, require an explicit unknown, and require a source label on each claim.
Low randomness in settings cuts extra variation on top of those three controls.
A search step that inserts real documents beats a prompt used alone.

Background
You asked for the best prompt to stop hallucination.
Hallucination means a fluent claim that the given evidence does not support.
This note gives one prompt and states what that prompt cannot do.

Relevance
A loose prompt still lets wrong facts reach a user or a later system.
Therefore the prompt must refuse when the supplied text has no answer.

Information
Text generation still produces unsupported claims as a known failure mode [1].
A setup that inserts retrieved documents improves knowledge tasks versus the model alone [2].
A prompt cannot insert facts the model does not hold [judgment].
Therefore the useful prompt limits the model to supplied text and requires an unknown reply.

Use this system text:

Answer only from the sources in this message.
If those sources do not contain the answer, reply: I do not know.
Put a source label after each factual claim.
Do not fill gaps from general knowledge.
If two sources conflict, state both and do not choose.

A1. The target is a general chat or API model, not a model already tied to search. Why not measured: the material does not state it. Validate by: name the product and say if search is on. If wrong: turn search on before you tune the prompt.

A2. You can set a system instruction. Why not measured: the material does not state it. Validate by: paste the text into the system field and run one known question. If wrong: put the same lines at the top of each user message.

A3. The API lets you set temperature. Why not measured: the material does not state it. Validate by: open the generation settings. If wrong: skip Step 3.

The strongest alternative is the line "Do not hallucinate."
It loses because it states a ban and gives no check the model can apply [judgment].

End
I recommend that we take these steps.

1. Complicated domain. Deterministic. The analysis is a check that this document is the authority for the question.
Test: Given that document in the same message, When the model states a fact, Then each fact has a label that points into that document.
Attach that document in one session.
This removes answers built with no evidence.
Step 2 MUST NOT start until this test is written.

2. Clear domain. Deterministic.
Test: Given a question whose answer is absent from the attached source, When the model replies, Then the reply is exactly "I do not know."
Paste the system text above in the same session.
This removes gap filling.
Step 2 starts after the test in Step 1 is written.

3. Clear domain. Deterministic.
Test: Given the same prompt and source twice, When temperature is 0, Then the two replies match on every factual sentence.
Set temperature to 0 in one settings change.
This removes extra invented detail from sampling.
Skip Step 3 if A3 is false.

4. Complex domain. Stochastic. Run this probe in parallel with Steps 1 to 3.
Test: metric is unsupported claims per answer, baseline is the same 10 questions with no source limit, pass threshold is 0 unsupported claims, sample size is 10.
Score 10 questions whose answers you already know.
Budget is one session.
Stop if you cannot score each claim against a known source.
Leverage of this probe is a guess.

Follow-up
If search is already on, keep the prompt and do not build a second retrieval path.
If the task is fiction, do not use this prompt, because invention is the goal.
If A3 is false, skip Step 3 and keep Steps 1, 2, and 4.
