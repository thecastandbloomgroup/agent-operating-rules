**Code pattern**

```python
import logging
import sys

logger = logging.getLogger(__name__)

def main():
    logging.basicConfig(
        level=logging.INFO,
        stream=sys.stdout,
        format="%(asctime)s %(levelname)s %(name)s: %(message)s",
    )
    logger.info("started on port %s", 8080)
```

Before: `print(f"started on port {port}")`. After: `logger.info("started on port %s", port)`.
