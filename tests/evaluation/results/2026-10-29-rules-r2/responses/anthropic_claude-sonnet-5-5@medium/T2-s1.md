## Headline

No prompt stops hallucination fully, but one grounded prompt reduces it most.

- Give the model the source text, because a model with no source fills gaps from memory.
- Allow the answer "the sources do not say", because a model that must answer will guess.
- Require exact quotes before the answer, so you can check each claim.

The prompt:

```text
Do not use outside knowledge. Do not guess.

<sources>
[paste your text here]
</sources>

Question: [your question]
```
