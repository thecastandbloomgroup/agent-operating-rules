## Headline

No prompt stops hallucination fully, but one prompt reduces it: it limits answers to supplied sources and allows "I do not know."

- The prompt in the End section forces grounding, quotes, and refusal when evidence is missing.
- Source text in the prompt matters more than the wording of the prompt.
- You must measure the result, because output varies from run to run.

## Background

You ask for the best prompt to stop a large language model (LLM) from stating false facts. An LLM predicts likely text. It does not check facts. I assume a general chat model, as A1 and A2 show.

## Relevance

A false answer that sounds sure costs you time or causes wrong decisions. A short test shows whether the prompt works for your use.

## Information

Evidence:

- Surveys of the field report that hallucination persists across models and tasks. [judgment] A prompt alone therefore lowers the rate and does not remove it.

  Source: Ji et al., 2023 [1].

- Supplying retrieved source text to the model improves factual output on knowledge tasks. Confidence: moderate, one primary study.

  Source: Lewis et al., 2020 [2].

- Allowing "I do not know" removes the pressure to fill gaps. [judgment]

Assumption log:

A1. You use a general chat model with no built-in search. Why not measured: the material does not state it. Validate by: ask which tool you use. If wrong: Step 2 changes to use the built-in search.

A2. You can paste source text into the prompt. Why not measured: the user has not answered. Validate by: try it on one question. If wrong: use the prompt without sources and expect a weaker effect.

Alternative considered: ask the model to "be accurate" or "think step by step" only. It loses because it adds no source, no refusal path, and no check. [judgment]

## End

I recommend that we take these steps in order:

1. Use this text as the system prompt. Increment: one paste, five minutes. Blocker removed: the model has no rule to refuse. Kind: deterministic. Domain: Clear.
   - Test: Given the prompt is set, When I ask a question the sources do not answer, Then the reply says "I do not know."

   ```text
   Answer only from the sources I give you.
   If the sources do not contain the answer, say "I do not know."
   Do not guess.
   Quote the sentence that supports each claim.
   If my question has a false premise, say so.
   State your confidence as a percentage.
   ```

2. Paste the source text under the prompt. Increment: one document per session. Blocker removed: the model relies on memory. Kind: deterministic. Domain: Complicated. Choose the most relevant document first.
   - Test: Given a source with a known fact, When I ask about it, Then the reply quotes that fact.
   - Step 2 MUST NOT start until the test in Step 1 passes.

3. Run a trial of 50 questions: 30 answerable, 20 not answerable. Increment: one working session. Blocker removed: no measure of the effect. Kind: stochastic. Domain: Complex, so treat it as a capped probe.
   - Test, written first: the metric is the share of replies with an unsupported claim. The baseline is the same questions without the prompt. The pass threshold is a drop of at least 30% from baseline. The sample size is 50.
   - Budget: 2 hours. Stop if the first 20 replies show no drop.

4. Add a check step in a second message: "List each claim and its supporting quote. Mark any claim without a quote." Increment: one message template. Blocker removed: unsupported claims stay hidden. Kind: stochastic. Domain: Complex, run in parallel with Step 3.
   - Test, written first: the metric is the number of unsupported claims caught per 50 replies. The baseline is Step 3 without the check. The pass threshold is at least 10 more caught. The sample size is 50. Budget: 1 hour.

If A2 is false, replace Step 2 with a request to name the source for each claim, and expect a smaller drop.
