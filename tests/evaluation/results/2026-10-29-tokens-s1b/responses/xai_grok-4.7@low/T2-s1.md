Headline
No prompt can make a model stop hallucinating.
Hallucination is a model limit, so wording alone cannot remove it.
The strongest prompt allows only sourced claims and an explicit "I do not know."
A check after the answer cuts more unsupported claims than a longer instruction.

Background
You asked for one prompt that stops a model from inventing facts.
That full stop is not available from an instruction.
This note gives the strongest prompt and the checks that must sit with it.

Relevance
Unsupported facts can leave the chat before a person reviews them.
Therefore the prompt should refuse a gap instead of filling it.

Information
Models can write fluent text that is false.
[1]

A verify-then-answer procedure can reduce those errors.
It does not erase them.
[2]

A ban such as "never hallucinate" adds no new evidence, so the model can still invent a fact.
[judgment]

Use this prompt as the standing instruction:

Use only facts in the sources I provide.
If those sources do not contain the answer, write "I do not know."
Do not add facts from memory to fill a gap.
Mark each claim with its source span, or mark it "not in sources."
If two sources conflict, quote both and do not choose a winner.
