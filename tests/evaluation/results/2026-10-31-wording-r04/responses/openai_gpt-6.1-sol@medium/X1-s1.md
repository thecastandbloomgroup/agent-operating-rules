### Define what “wrong” means

Use these separate error types. A summary can contain several errors. [judgment]

| Error type | Definition | Example |
|---|---|---|
| Incorrect statement | Contradicts the conversation | Says a refund succeeded when it failed |
| Unsupported statement | Adds something the conversation does not establish | Invents a reason for cancellation |
| Material omission | Leaves out information needed for the next support action | Omits an unresolved refund request |
| Presentation defect | Contains the right information but fails the required format | Hides the next action in unnecessary detail |

Separately, mark **severe errors**: errors that change the customer, money, account access, commitments, or next required action. [judgment]

- **Secondary:** agent correction time, response time, and cost per summary. [judgment]

Count defective summaries, not just individual errors, so long summaries do not distort the main measure. [judgment]
