## Headline

No single prompt stops a model from inventing facts; grounding and checking reduce them more than wording. The best move is a short instruction block plus sources in the message plus one verify pass.

- A prompt that allows "I do not know" lowers fabrication against a plain prompt baseline [inference].
- Answers built only from pasted source text contain fewer invented facts than closed-book answers, per the mitigation survey [2].
- Residual errors remain in every method family, so a check step is not optional [2].

## Background

You ask for the best prompt to make a model stop hallucinating. A hallucination here is generated text that is unfaithful to the source or nonsensical [1]. The request assumes one prompt can remove the problem.

## Relevance

Invented facts in code, reports, or citations cost rework each time you trust an answer. The fix changes how you write each request, starting today.

## Information

**Evidence**

1. The survey of mitigation methods groups prompts, retrieval grounding, and post-hoc verification as separate method families [2]. One family alone does not match the combined effect, per the survey's framing [2].
2. Theme: grounded answers, where the model cites pasted text, carry fewer unsupported claims than closed-book answers. One source supports it [2]. No disagreeing source appears in this session.
3. [judgment] A prompt that permits refusal lowers fabrication, because the model no longer needs a plausible answer when it lacks the fact.
4. [judgment] A command like "do not hallucinate" fails as a control, because it gives no test, no source, and no fallback.

**Assumption log**

A1. You want fewer invented facts in chat answers, not a change to model training. Why not measured: the query does not state the setting. Validate by: check whether the task is chat or fine-tuning. If wrong: the recommendation changes to data and training work.
A2. You can paste source text, but you cannot attach retrieval tools. Why not measured: the material does not state it. Validate by: check whether the interface supports file upload. If wrong: Step 2 becomes a retrieval pipeline instead of pasting.

**Alternative considered**

Add "do not hallucinate" or "be accurate" to every prompt. It loses because instructions without sources, tests, or a fallback show no measured gain against a baseline; the survey treats such prompts as one weak method among several [2].

## End

I recommend that we run the following steps, in order.

1. **Write one reusable instruction block** for every request: "If you do not know, say 'I do not know'. Label each factual claim with its source type." This removes the pressure to fill gaps with plausible text. Test first (stochastic): metric = share of answers with at least one invented fact; baseline = answers under the current prompt on 20 fixed questions; pass = half or less of baseline; sample = 20 answers per arm. Cynefin: Complex. Leverage is a guess until the 20-answer trial runs.

2. **Paste the source text into the message** and add: "Answer only from the pasted text. Quote the supporting line for each claim." This blocks recall-based fabrication. Step 2 runs in parallel with Step 1, capped by the same 20-question budget. Test first (stochastic): same metric, baseline, threshold, and sample as Step 1. Cynefin: Complex.

3. **Add a verify pass after each answer**: ask the model to list every factual claim with its source type, then remove or replace weak claims. This catches residual errors from Steps 1 and 2. Step 3 MUST NOT start until an answer from Step 1 or 2 exists. Test first (evaluative): rubric = each claim has a source (weight 50), the source is primary or secondary (weight 30), unknown claims carry the label "unknown" (weight 20); pass threshold = 100% of claims classified; evidence = the claim list itself. Cynefin: Complicated.

4. **Check any fact before reuse in work that others see**: open the primary source and compare. This is the last line of defense and a best practice. Test first (deterministic), in Gherkin form:

   ```gherkin
   Given a fact copied from model output
   When I open the primary source
   Then the fact matches the source, or I remove the fact
   ```

   Cynefin: Clear.

Hedge: if A2 is false and retrieval tools are available, replace Step 2 pasting with a retrieval step that returns the source passages.

## Follow-up

Conditions that change the recommendation: creative writing tasks, where invention is the goal, need none of the four steps. Tasks with a scoring rubric or a source document change Step 2 from pasting to structured input.
