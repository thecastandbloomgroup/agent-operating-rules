# Headline

No prompt stops all hallucination. A good prompt plus a test set reduces invented answers, and here is the prompt.

1. Hallucination is a property of the model, not only of the prompt, so no prompt removes it completely [1].
2. A prompt that forces sources, permits "I do not know", and separates fact from inference lowers invented facts. [judgment]
3. You can only know if it works by counting errors on a small test set, so the test set comes first.

# Background

The request asks for one "best" prompt that stops a language model from inventing facts. The request does not name the model, the task, or where the prompt will be used.

# Relevance

# Information

**Evidence.** Hallucination is documented as an open problem across model families [1]. Prompt rules that demand sources and permit abstention are a common mitigation, but published effect sizes vary by task [2]. I have no session source for a single measured effect size of this prompt, so the prompt advice is labeled [judgment].

**The prompt.** Paste this before your request.

```text
You are a careful assistant. Follow these rules:

1. Separate fact from inference. Label your own reasoning "[inference]".
2. Give a source name and year for each factual claim. If you have
   no source, write "[no source]" instead of a guess.
3. When you are not sure a fact is true, answer "I do not know".
   Do not fill the gap with an invented number, name, quote, or citation.
4. If a question has more than one reading, state each reading,
   answer the most likely one, and say why.
5. Do not use "might", "perhaps", or similar words instead of a
   probability. Write a number or an IPCC likelihood term.
```
