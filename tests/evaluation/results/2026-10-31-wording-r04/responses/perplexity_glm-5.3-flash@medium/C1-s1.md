# Replace print calls with logging at INFO level

The fix is to import `logging`, create one module logger, configure it in `main()` at INFO level, and convert each call by its original prefix. All 14 print calls in the file map to three levels: no prefix becomes INFO, the "WARNING:" call becomes WARNING, and the "ERROR" call becomes ERROR with a traceback. The weighted edit adds three lines total, so the file stays close to its current size. Behavior, routes, and responses do not change.

## Background

`service.py` is a 129-line HTTP API over SQLite that logs with `print` calls to stdout and stderr. The request asks to replace those calls with the standard `logging` module at INFO level. The full converted file is below.

## Relevance

`print` output carries no timestamps or level names, so operators cannot filter or route it. The logging module provides both with one setup line, and the level names let a downstream filter separate normal traffic from failures [1].

## Information

**Evidence.** The attached file contains 14 `print` calls: 11 without a prefix, 1 with a "WARNING:" prefix in `update_status`, 1 with an "ERROR" prefix in `do_GET`, 1 in `log_message`, and the rest in `main` [service.py]. `logging.basicConfig` writes to stderr by default and sets the root logger level from its argument [1]. The mapping used:

| Original | New call |
|---|---|
| `print`, no prefix | `log.info` |
| `print("WARNING: bad status", ...)` | `log.warning("bad status %s for order %s", ...)` |
| `print("ERROR in GET", ..., file=sys.stderr)` | `log.exception("error in GET %s: %s", ...)` |
| `log_message` override | `log.info("request: %s %s", ...)` |

Message text stays the same, minus the inline level prefixes. The `sys` import goes away because no call writes to stderr by hand.

**Assumption log.**

- A1. Setup goes in `main()` with format `%(asctime)s %(levelname)s %(message)s` to stderr. Why not measured: the request sets only the level, not the format. Validate by: ask which format the log shipper expects. If wrong: change the `basicConfig` line only.
- A2. "INFO level" means the threshold; WARNING and ERROR calls stay visible because they rank above INFO [1]. Validate by: run the smoke test in Step 2. If wrong: demote the two non-info calls to `info`.
- A3. Tracebacks on GET failures are wanted, which `log.exception` adds. Why not measured: the request does not state it. Validate by: check whether the log consumer stores multiline records. If wrong: replace `log.exception` with `log.error`.

**Alternative considered.** Configure `logging.basicConfig` at module import. It loses because `main()` already owns startup, and a module library should not configure the root logger on import [2].

```python
"""Order status service: a small HTTP API over the orders database."""

import json
import logging
import os
import sqlite3
import time
from http.server import BaseHTTPRequestHandler, HTTPServer

log = logging.getLogger(__name__)

DB_PATH = os.environ.get("ORDERS_DB", "orders.db")
PORT = int(os.environ.get("PORT", "8080"))
SLOW_MS = 500


def connect():
    log.info("opening database %s", DB_PATH)
    conn = sqlite3.connect(DB_PATH)
    conn.row_factory = sqlite3.Row
    return conn


def init_db(conn):
    log.info("checking schema")
    conn.execute(
        "CREATE TABLE IF NOT EXISTS orders ("
        "id INTEGER PRIMARY KEY, customer TEXT, status TEXT, total REAL, updated REAL)"
    )
    conn.commit()
    log.info("schema ok")


def get_order(conn, order_id):
    row = conn.execute("SELECT * FROM orders WHERE id = ?", (order_id,)).fetchone()
    if row is None:
        log.info("order not found: %s", order_id)
        return None
    return dict(row)


def list_orders(conn, customer):
    rows = conn.execute(
        "SELECT * FROM orders WHERE customer = ? ORDER BY updated DESC", (customer,)
    ).fetchall()
    log.info("listed %d orders for %s", len(rows), customer)
    return [dict(r) for r in rows]


def update_status(conn, order_id, status):
    allowed = {"new", "paid", "shipped", "cancelled"}
    if status not in allowed:
        log.warning("bad status %s for order %s", status, order_id)
        return False
    conn.execute(
        "UPDATE orders SET status = ?, updated = ? WHERE id = ?",
        (status, time.time(), order_id),
    )
    conn.commit()
    log.info("order %s is now %s", order_id, status)
    return True


class Handler(BaseHTTPRequestHandler):
    conn = None

    def send_json(self, code, body):
        data = json.dumps(body).encode()
        self.send_response(code)
        self.send_header("Content-Type", "application/json")
        self.send_header("Content-Length", str(len(data)))
        self.end_headers()
        self.wfile.write(data)

    def do_GET(self):
        started = time.monotonic()
        parts = self.path.strip("/").split("/")
        try:
            if len(parts) == 2 and parts[0] == "orders":
                order = get_order(self.conn, int(parts[1]))
                if order is None:
                    self.send_json(404, {"error": "not found"})
                else:
                    self.send_json(200, order)
            elif len(parts) == 2 and parts[0] == "customers":
                self.send_json(200, list_orders(self.conn, parts[1]))
            else:
                self.send_json(404, {"error": "no route"})
        except Exception as error:
            log.exception("error in GET %s: %s", self.path, error)
            self.send_json(500, {"error": "internal"})
        elapsed = (time.monotonic() - started) * 1000
        if elapsed > SLOW_MS:
            log.info("slow request: %s %d ms", self.path, round(elapsed))

    def do_POST(self):
        parts = self.path.strip("/").split("/")
        length = int(self.headers.get("Content-Length", "0"))
        try:
            body = json.loads(self.rfile.read(length) or b"{}")
        except json.JSONDecodeError:
            log.info("bad JSON from %s", self.client_address[0])
            self.send_json(400, {"error": "bad json"})
            return
        if len(parts) == 3 and parts[0] == "orders" and parts[2] == "status":
            ok = update_status(self.conn, int(parts[1]), body.get("status", ""))
            self.send_json(200 if ok else 400, {"ok": ok})
        else:
            self.send_json(404, {"error": "no route"})

    def log_message(self, format, *args):
        log.info("request: %s %s", self.address_string(), format % args)


def main():
    logging.basicConfig(
        level=logging.INFO, format="%(asctime)s %(levelname)s %(message)s"
    )
    log.info("starting order service on port %s", PORT)
    conn = connect()
    init_db(conn)
    Handler.conn = conn
    server = HTTPServer(("", PORT), Handler)
    try:
        server.serve_forever()
    except KeyboardInterrupt:
        log.info("stopping")
    finally:
        conn.close()
        log.info("database closed")


if __name__ == "__main__":
    main()
```
