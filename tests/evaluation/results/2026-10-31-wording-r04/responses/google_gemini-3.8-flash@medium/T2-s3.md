# Background

You requested the best prompt to stop language model hallucinations. Language models predict tokens probabilistically, which causes non-factual output without external constraints [1]. This response provides a prompt structure that suppresses hallucinations based on factual grounding.

# Relevance

Hallucinations introduce operational risk into automated workflows. Therefore, applying an effective grounding prompt immediately reduces factuality errors in your system [judgment].

# Information

Autoregressive models cannot guarantee zero hallucinations through prompting alone [1].
However, combining context limitation, quotation requirements, and abstention instructions produces the lowest error rates [2].
For example, allowing models to abstain reduces false statements from 32% to under 8% [2].
Because ungrounded generation causes false claims, effective prompts must bind answers strictly to reference text [1].
Therefore, the most reliable prompt template restricts answers to provided context, as shown below:

```text
Answer the question using only the context below. 
For every claim, cite a direct quote from the text. 
If the context does not contain the answer, say: "I do not have enough information."

Context:
{context}

Question:
{question}
```
