## Headline

No prompt removes hallucination, but a grounding prompt with a quote rule cuts it, and you must test the result.

- A prompt changes the model's behavior. It does not change what the model knows.
- The best prompt limits answers to supplied text, allows "I don't know", and demands a quote for each claim.
- A test on your own questions shows whether the prompt works.

## Background

You asked for one prompt that stops a model from inventing facts. The material gives no model name, task, or source text. I assume a general chat model and a task where you can paste source text.

## Relevance

A false answer that sounds sure costs you time or trust. A tested prompt is cheap to build and cheap to replace.

## Information

**Evidence**

- Hallucination has several causes, including training data gaps and decoding. A prompt reaches only some of them [1]. Confidence: high, one broad survey.
- A model asked to check its own claims with separate verification questions makes fewer false statements [2]. Confidence: moderate, one study, not run on your model.
- Models often judge well whether they know an answer [3]. This supports the "say you are unsure" rule. Confidence: moderate, one study.
- The exact size of the gain on your task is unknown [judgment]. Step 3 below measures it.

**The prompt**

```text
Answer only from the SOURCE below.
If the SOURCE does not contain the answer, write: "The source does not say."
Do not use outside knowledge.
After each claim, quote the sentence from the SOURCE that supports it.
Do not guess names, numbers, dates, or links.
If you are unsure, say so and give a confidence from 0 to 100%.
Before you finish, check each claim against its quote. Delete any claim without a quote.

SOURCE:
<paste text here>
```

**Assumption log**

A1. You can paste source text into the prompt. Why not measured: the material does not state it. Validate by: ask whether the task has a source document. If wrong: replace Step 3 with a retrieval step, and the quote rule has no source to cite.

A2. The model has no web or search tool. Why not measured: no tool can reach your setup. Validate by: ask the model to name its tools. If wrong: add "search first" to the prompt and re-run Step 3.

**Alternative considered**

Fine-tuning or retrieval-augmented generation (RAG, which means the system fetches source text for each question) fixes more causes [1]. It loses for now because it costs days of work, not one session [judgment].
