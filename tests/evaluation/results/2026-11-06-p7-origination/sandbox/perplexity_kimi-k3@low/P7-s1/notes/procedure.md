# Procedure: fix banned words and long sentences

Follow these steps in order for one notes file.

1. Count the words in each sentence of the file.

2. Split any sentence with more than 25 words into two or more sentences. Keep each idea in one sentence. Keep the original meaning.

3. Scan the file for banned booster words, banned hedge words, em dashes, and en dashes.

4. Remove each booster word. If the sentence loses meaning, restate it with a number or a fact instead.

5. Replace each hedge with a probability or a confidence statement with a basis. If no value is known, state the fact without the hedge.

6. Replace each em dash or en dash with a comma, colon, or period.

7. Use the active voice. Use the present tense. Use one instruction per sentence.

8. Read the file again. Confirm the meaning matches the original.

9. Repeat steps 1 to 8 until the check on the file passes.
