# Headline

No prompt stops all hallucinations (false claims that the model states as fact), but the prompt below likely reduces them for factual tasks.

1. **Grounding:** It limits answers to sources you supply and asks for a quote behind each claim.
2. **Abstention:** It makes "I don't know" cheaper than a wrong guess, so the model has less reason to guess.
3. **Self-check:** It makes the model check each claim against its quote before it answers.

```text
Answer only from the sources below and from facts you are sure of.
If the sources do not contain the answer, say "I don't know." Do not guess.
For each factual claim, quote the source sentence that supports it.
If you cannot find a supporting quote, delete the claim.
Before you answer, check each claim against its quote. Delete any claim that fails.
Scoring: a correct answer earns 1 point. "I don't know" earns 0 points. A wrong answer costs 3 points.
So answer only when you are more than 75% sure.

<sources>
[paste your documents here]
</sources>
```

# Background

You want one prompt that stops the model from inventing facts. A prompt can lower the rate of false claims. However, no known prompt brings the rate to zero.

# Relevance

A false claim that reads as fact costs more than a gap that the model admits. You need the prompt and a way to check whether it works on your own tasks.

# Information

**Evidence**

The evidence falls into four themes.

**Theme 1: No prompt removes all hallucinations.** Two sources support this theme. No source in this session disagrees [judgment].

- Xu et al. argue from learning theory that every computable language model hallucinates on some inputs.

  [2]

- Kalai et al. trace part of the errors to the statistics of pretraining.

  [1]

**Theme 2: Grounding in supplied text reduces false claims.** One source supports this theme.

- Shuster et al. report fewer hallucinations in dialogue when the model draws on retrieved documents.

  [3]

- Grounding is the largest lever when you have documents, so this theme matters despite one source [judgment].

**Theme 3: A reward for abstention reduces guesses.** One source supports this theme.

- Kalai et al. state that current tests reward a guess over "I don't know." They propose a stated confidence threshold t, with a wrong answer costing t/(1-t) points.

  [1]

- At t = 0.75, that penalty is 3 points. This value appears in the prompt.

**Theme 4: A separate check step reduces false claims.** One source supports this theme.

- Dhuliawala et al. have the model draft an answer, plan check questions, answer them independently, and revise. This method reduced hallucinations in their tests.

  [4]

**Confidence**

Medium confidence that the prompt reduces false claims on your tasks. The basis is three separate lines of research, but none of them used your data.

The size of the reduction for your tasks is unknown, so Step 2 in the End section measures it.

**Assumption log**

A1. You use the prompt for factual questions, not creative writing. Why not measured: the user has not answered. Validate by: read ten of your real requests. If wrong: drop the source and quote rules, and keep the "I don't know" rule.

A2. You can paste source documents into the prompt. Why not measured: the material does not state it. Validate by: check whether your task has a reference document. If wrong: remove the sources block, keep the other rules, and expect a smaller reduction [judgment].

A3. You accept more "I don't know" answers in exchange for fewer false ones. Why not measured: the user has not answered. Validate by: count abstentions in the Step 2 trial. If wrong: lower the threshold to 50%, that is, a penalty of 1 point.

**Alternative considered**

The strongest alternative is a full retrieval system that searches a database and feeds each result to the model. It loses for now because it costs more than one work session, and you asked for a prompt [judgment].
