### Define “wrong”

Use these defect categories. Assign each defect to one category, but allow several defects within one summary. [judgment]

| Defect | Definition | Example |
|---|---|---|
| Contradicted fact | The summary conflicts with the conversation | “Refund issued” when the agent only requested approval |
| Unsupported claim | Neither the conversation nor an approved source supports the claim | An invented cause or promised deadline |
| Consequential omission | Missing information changes the next support action | An unresolved issue or customer constraint disappears |
| Usability defect | The facts remain correct, but presentation adds work | Repetition or unclear structure |

Track these measures separately: [judgment]

- **Factual-error rate:** summaries with contradicted facts or unsupported claims, divided by summaries reviewed.
- **Omission rate:** summaries with consequential omissions, divided by summaries reviewed.
- **High-risk error count:** errors that misstate money, account access, security, or customer commitments.
- **Review time:** median seconds agents need to approve or correct a summary.

Do not combine these measures into one score. A shorter review time must not hide more factual errors. [judgment]
