# Headline

Run one Postgres command to rename the column, but do it after the cutover steps because a rename can break running code and views.

1. The command is `ALTER TABLE orders RENAME COLUMN user_id TO account_id;`.
2. The rename locks the table briefly and instantly invalidates code that still queries `user_id`.
3. Views and stored functions that reference `user_id` break and need updates too.

## Background

A Postgres `orders` table needs its `user_id` column renamed to `account_id`. The change must happen before a flight.

## Relevance

A wrong rename during a live deploy can take down queries that read or write `orders`. One command is enough if the app tolerates the change.

4. Drop `user_id` afterward.
