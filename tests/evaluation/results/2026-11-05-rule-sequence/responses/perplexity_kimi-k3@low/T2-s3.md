# Headline

No prompt stops hallucination, but the best single prompt makes the model refuse to answer without evidence. First, the prompt forces a check against given sources. Second, it gives the model permission to say "I do not know." Third, this cuts false answers but does not remove them.

# Background

You asked for the best prompt to stop hallucination. Hallucination is content the model generates without support in its data or context.

# Relevance

A wrong answer stated with confidence costs more than no answer. One prompt change can reduce this risk today, without new tools.

# Information

**Claim: prompts reduce but do not eliminate hallucination.** Controlled tests show retrieval grounding and explicit refusal options lower unsupported claims, but rates stay above zero [1]. A prompt is therefore a mitigation, not a fix [judgment].

**The recommended prompt:**

> "Answer only from the sources provided below. If the sources do not contain the answer, reply: 'Not in the provided sources.' Quote the source for every claim. Do not use outside knowledge."

**Why each line matters:**

1. "Answer only from the sources" restricts the model to groundable content [1].
2. The explicit refusal option reduces confident wrong answers [1].
3. "Quote the source" makes each claim checkable [judgment].

**Alternative considered:** Chain-of-thought prompts ("think step by step") were the main alternative. They lose because they can add fluent but unsupported reasoning, which raises apparent confidence without raising accuracy [judgment, no source].

A1. The user means a general chat use case, not a code-assistant or agent setup. Why not measured: the material does not state it. Validate by: ask which setting the prompt is for. If wrong: the prompt still applies, but an agent setup would add tool-grounding steps.
