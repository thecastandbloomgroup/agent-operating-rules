Headline

No prompt fully stops hallucination. Models still invent text when a task demands an answer they lack. A source-bound prompt cuts gap-filling more than a ban on invention. Retrieval and a later check cut more errors than wording alone.

Background

The request asks for the best prompt that makes a model stop inventing facts. Hallucination means fluent text that the input or a reliable source does not support [1]. A prompt can change what the model does. It cannot supply missing knowledge [judgment].

Relevance

An unsupported answer still looks sure, so a later decision can use a false fact. A source-bound prompt makes a gap visible before that use.

Information

A survey treats hallucination as unfaithful or unsupported generation, not as a style fault [1]. Retrieval-augmented generation gives the model documents at answer time so the reply can condition on that text [2]. A line that only says "do not hallucinate" does not say what to do when evidence is absent [judgment]. Therefore the useful prompt binds each claim to attached sources and names the gap.

Use this text as the standing instruction:

Use only the sources in this message.
If the sources do not contain the answer, write: Not in the sources.
Do not use outside knowledge to fill a gap.
For each factual claim, quote the supporting sentence and name its source.
If sources conflict, report both and do not pick one.
Separate quotes from your short restatement.
If no sources are attached, ask for them before you answer.

A1. The need is a copy-paste chat instruction, not a training change. Why not measured: the material does not state it. Validate by: name the system that will receive the text. If wrong: replace Step 2 with that system's grounding control.

The strongest alternative is temperature 0 plus step-by-step reasoning. It loses because a low temperature does not add facts, and long reasoning can still invent steps [judgment]. Confidence is medium: one survey, one retrieval paper, and judgment on the wording.

End

I recommend that we take these actions.

1. Attach the source text, or retrieve it, before each factual question. Increment: one question plus its documents, in one session. Blocker: the model has no text it can quote. Test first:
Given one factual question and its source file,
When the file is placed above the question,
Then the file text is visible in the same message.
Cynefin: Complicated. Analysis of paste versus retrieval picks the practice. This is deduction from the need for citable text.

2. Install the source-bound prompt as the standing instruction. Increment: one settings change, in one session. Blocker: the model fills a silent gap. Step 2 MUST NOT start until the test in Step 1 passes. Test first:
Given a question whose answer is absent from the attached note,
When the model answers,
Then the reply is "Not in the sources."
Cynefin: Clear. Deduction from a known cite-or-refuse rule.

3. Run a capped check in parallel with Steps 1 and 2. Increment: 20 questions, budget one hour. Blocker: unknown error rate after the change. Stop if the unsupported-claim rate does not fall by half versus the no-source baseline. Test first: metric is unsupported claims per answer, baseline is the same 20 questions with no sources, pass threshold is a 50 percent drop, sample size is 20. Cynefin: Complex. Induction from trials. A changed question set can break the pattern. Leverage is a guess.

If A1 is false, replace Step 2 with the product control that attaches sources, and keep Steps 1 and 3.

Follow-up

No open question. The condition above changes Step 2.
