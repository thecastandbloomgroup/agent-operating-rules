The API returns JSON. The average body is 400 KB. The request asks whether gzip should be on.

A 400 KB body dominates transfer time on common links. Compression changes that cost before other tuning does.

JSON repeats keys and structure. Gzip targets that repetition.

A 400 KB JSON body often shrinks to about 40 KB to 120 KB. That range is a judgment, not a measure of this API. [judgment]
HTTP sends gzip through Content-Encoding when the client accepts it.

400 KB equals 3,200 kilobits. At 10 megabits per second the transfer takes 0.32 seconds. A 5 to 1 shrink cuts that to 0.064 seconds. [inference]
Compression can leak a secret when one body mixes that secret with text an attacker can change.
