## Headline

No prompt can stop hallucination, because the model samples words and can produce fluent false text even with good instructions [1]. The best result comes from a prompt that forces grounding and allows refusal, plus a check outside the prompt.

- The failure source is the generation process, not the prompt text [1].
- A prompt that restricts the model to supplied text and permits "I do not know" cuts the error rate [2].
- A separate verification step catches the errors that remain [3].

## Background

The request asks for one prompt that removes false statements from model output. The task type and model are not stated, so this answer covers factual question answering [judgment].

## Relevance

False claims enter downstream work and cost time to find. A grounded prompt with a check reduces that cost now.

## Information

Evidence:

1. Hallucination in language models arises from the generation process, so fluent false text is expected behavior, not a prompt bug [1].
2. Grounding the model in supplied passages lowers unsupported claims in retrieval settings [2].
3. Measured prompt gains depend on the model, the dataset, and the task, so a fixed pass threshold is the only way to confirm a gain [1], [3].
4. Verification against a source, done as a separate step, finds claims that a single pass leaves [3].

Best single prompt, based on [1] and [2]:

```text
Answer only from the text I provide next. Quote the exact sentence that supports each claim. If the text does not answer the question, reply "I do not know" and stop.
```

Themes from the sources: (a) restrict to supplied text, 2 sources [1], [2]; (b) allow refusal, 1 source [1]; (c) verify separately, 1 source [3]. No source states that any prompt reaches zero errors [1].
