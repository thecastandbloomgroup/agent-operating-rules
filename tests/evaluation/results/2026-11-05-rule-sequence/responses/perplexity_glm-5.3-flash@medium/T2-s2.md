**Headline**
No single prompt stops false answers. A prompt that forces grounding plus a measured test keeps them low.

1. False answers come from training data and from sampling, so prompt wording controls only part of the behavior [1].
2. A prompt that forces each fact to cite the supplied material removes most invented facts [judgment].
3. Measure the false-fact rate on a fixed question set before and after the change, so the gain is real.

**Background**
The request asks for one prompt that stops a model from inventing facts. No conversation material names the model, the product, or the source documents.

**Relevance**
Invented facts break trust in every answer from today on. The fix is one config change plus one measured check.

**Information**

Prompt to use (the text goes in the system prompt):

```text
Answer only from the material in this conversation.
For every fact, write the source: the document name or section.
If the material does not contain the answer, write "I do not know" and stop.
Do not add facts from memory.
If a step needs a guess, label it "guess".
```

Evidence:

- False answers arise from the generation process itself, not only from bad prompts [1].
- Requiring grounded, sourced answers removes most invented facts in reported tests [judgment].

Assumption log:

`A1. The product accepts a system prompt. Why not measured: the request names no product. Validate by: open the settings and look for a system or instruction field. If wrong: put the prompt text as the first user message.`
`A2. There is a fixed set of source documents. Why not measured: the request lists none. Validate by: list the project files. If wrong: use a documentation set as the source; the steps do not change.`

Alternative considered: add "do not hallucinate" to the prompt and stop there. It loses because the instruction names a goal without a rule to follow or a way to verify, so the rate stays unknown [judgment].

**End**
I recommend that we run three steps:

1. Put the prompt above into the system prompt. This removes answers that invent a fact with no source. Test first, in Gherkin form:
   ```gherkin
   Given the system prompt contains the prompt above
   When a user asks a question that the material does not answer
   Then the reply contains "I do not know" and no fact from outside the material
   ```
   Cynefin domain: Clear, because a known rule applies directly. This step is deterministic.
2. Run a measured check after Step 1 passes. Build 40 questions: 20 that the material answers and 20 that it does not. Metric: percentage of replies that contain a fact with no source in the material. Baseline: one run of the same 40 questions without the grounding prompt. Pass threshold: at most 10 percent at a sample size of 40. Stop condition: 2 hours of work or 3 runs. Cynefin domain: Complex, because the effect is visible only after a run, so the probe is small and capped. This step is stochastic.
3. Until Step 2 reaches its threshold, read each reply before the reply drives a decision. Use this rubric first: criterion "each fact has a cited section", weight 5; criterion "no invented name, number, or date", weight 5; pass threshold 10 of 10; evidence needed: the cited section text next to the claim. Cynefin domain: Complicated, because expert analysis of each reply selects the answer. This step is evaluative.

**Follow-up**
Condition that changes the recommendation: if the rate stays above 10 percent after 3 runs, add retrieval over the source documents instead of a prompt change alone [judgment].
