## Headline

No prompt stops hallucination completely, but one grounded prompt cuts it most: make the model answer only from supplied sources, quote them, and say "the sources do not say" when they are silent.

- A model invents content when it has no source and no permission to decline.
- Quotes make each claim checkable by a program.
- A test set shows whether the prompt works on your task.

## Background

Hallucination means the model states content that is false or not supported by a source [1]. You asked for one best prompt. The prompt below applies to factual question answering when you can paste in source text (assumption A1).

## Relevance

A wrong answer that sounds sure costs more than a refusal. A prompt that allows refusal and demands quotes lowers that cost today, with no new tools.

## Information

Use this prompt:

```text
Answer using only the text inside <sources> tags.
Do not use outside knowledge. Do not guess.
For each claim, quote the sentence that supports it.
If the sources do not answer the question, reply exactly:
"The sources do not say."
If a claim is only partly supported, say which part.
```

Evidence:

- Retrieval of source text before generation improves factual accuracy on knowledge tasks [2].
- Models can estimate whether they know an answer, so a refusal rule has a basis [3].
- Expected size of the gain on your task is unknown [judgment]. Step 1 below measures it.
- Only a tertiary view says a prompt alone removes the problem. No source supports that view, so treat it as false [inference].

Assumption log:

A1. You can supply source text and the task is factual Q&A. Why not measured: the material does not state it. Validate by: check that 10 real questions have answers in your sources. If wrong: replace Step 3 with a retrieval setup.

A2. A sample of 50 questions is enough to see a halving of errors. Why not measured: measuring costs more than the decision is worth. Validate by: rerun the test with a second set of 50. If wrong: raise the sample size.

Alternative considered: set temperature (the randomness setting) to 0. It loses because it makes output repeatable but does not add facts or allow refusal [judgment].
