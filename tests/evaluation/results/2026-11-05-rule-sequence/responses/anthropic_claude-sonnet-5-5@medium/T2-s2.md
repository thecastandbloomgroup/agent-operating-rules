## Headline

No prompt stops hallucination completely, but one prompt type lowers it: ground the answer in supplied sources and allow "not in the sources" as an answer.

- Hallucination (output that sounds right but is false or unsupported) comes from how models work, so a prompt reduces it but cannot remove it.
- A prompt works best when it limits the model to given text.
- A prompt works best when it permits a refusal.
- You must measure the result on your own task, because effects differ by model and topic.
