# Headline

Use the grounded prompt in the Information section. It gives fewer hallucinations, not zero.

1. The prompt limits answers to documents you supply, so the model checks claims against text, not memory.
2. It allows the answer "I do not know", which removes the reward for a guess.
3. It makes the model quote a source for each claim and then check each claim.
4. Test it on 30 of your own questions, because the size of the effect depends on your model and data.

# Background

A hallucination is model output that states a false or unsupported fact as true. You asked for one prompt that stops it. No prompt stops it fully, but a grounded prompt reduces it.

# Relevance

Unchecked hallucinations put false facts into your work. A tested prompt lets you measure the error rate before you trust the output.

# Information

**The prompt**

```text
Answer the question with facts from the documents in <sources> only.
If the documents do not answer the question, write "I do not know." Then name the missing fact.
For each claim, quote the exact sentence from the documents that supports it.
If no sentence supports a claim, delete the claim.
After the draft, list each claim with its quote.
Check that each quote supports its claim. Delete each claim that fails.
Give the final answer, then the list of claims and quotes.

<sources>
{paste the documents here}
</sources>

Question: {your question}
```

**Evidence**

The evidence falls into four themes. Each theme has one source, but each source tests a different cause of hallucination, so the themes do not overlap.

1. *Zero is not reachable for a general model.* The two sources disagree in part:
   - Xu et al. prove that hallucination is inevitable for models used as general problem solvers [1].
   - Kalai et al. state that a model can avoid errors when it abstains, that is, declines to answer [2].
   - The two sources agree if an abstention counts as no answer. So fewer errors cost fewer answers [inference].
2. *Guesses get a reward.* Kalai et al. state that training and evaluation reward a guess over an admission of uncertainty [2]. Therefore the prompt permits "I do not know" in explicit words [inference].
3. *Grounding helps.* Lewis et al. report more factual output from a model with retrieved documents than from a model with internal memory only [3].
4. *A check after the draft helps.* Dhuliawala et al. report that a draft, then independent check questions, then a revision, reduces hallucination on several tasks [4].

Confidence: medium confidence that this exact prompt reduces hallucination on your task. Basis: each of three mechanisms has one supporting study, but no study tests this exact prompt.

**Assumption log**

A1. You can supply source documents for your questions. Why not measured: the material does not state it. Validate by: check whether the task has a document set. If wrong: remove the sources block and the quote rules, and expect a smaller gain [judgment].

A2. The task needs factual answers, not creative text. Why not measured: the material does not state it. Validate by: read five real requests from the task. If wrong: the prompt adds refusals with no benefit, so do not use it.

A3. You can run the model 90 times and grade each answer. Why not measured: the user has not answered. Validate by: run 10 questions once and time the grading. If wrong: use 30 runs and accept lower confidence.

**Alternative considered**

The strongest alternative is one short line: "Do not invent facts. Say you do not know if unsure." It loses because the model has no external text to check against. It must judge its own certainty, and that self-judgment is the weak point [judgment].

# Follow-up

**Conditions that change the recommendation**

- If A1 is false, remove the sources block and the quote rules. Keep the "I do not know" rule.
- If Step 3 stops early, add a separate check call. The second call answers check questions without the draft in view [4].
- If A2 is false, do not use this prompt.
