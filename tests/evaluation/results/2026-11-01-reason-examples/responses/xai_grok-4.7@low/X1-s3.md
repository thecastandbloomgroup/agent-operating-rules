## Headline

Measure the errors before you change the summariser.

- "Sometimes wrong" can mean more than one failure type.
- A model change with no start rate cannot show a gain.
- A sample of 30 summaries can set that start rate.
- Then change only the largest measured failure.

## Background

The support tool now adds a summary from a large language model. Agents say that summary is sometimes wrong. There is no metric, and the request is to make the summary better.

## Relevance

A wrong summary can lead an agent to the wrong next step. Because there is no start rate, a model change can add cost and leave the error rate the same.
