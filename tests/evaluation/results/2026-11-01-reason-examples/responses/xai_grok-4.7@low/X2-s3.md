Headline
Check the last agreed action before any new topic, then leave with one owned change that has reserved time.

- An action that no one reviews can fail in silence.
- A long list has no single owner, so it does not finish.
- A change with no reserved time loses to the next cycle's load.
- Silence about problems is a safety issue, not an agenda issue.

Background
The team still holds retrospectives, and people still attend. The work after the meeting does not change. The request is to choose the next fix.

Relevance
Each meeting that ends with no finished change teaches the team to ignore the next one. A closed loop on one action can reverse that pattern in one cycle.

Information
The cause is likely an open action loop. The basis is the request itself: people attend, yet nothing shifts. This is not a count from this team.

The Scrum Guide says the team addresses the most useful improvement as soon as possible.
[1]

The same guide allows that improvement on the next Sprint Backlog.
[1]

A meeting that does not check its last action cannot show a result. [judgment]

Derby and Larsen treat the close as a choice to try a small change.
[2]

A1. The stall is an open action loop, not low attendance. Why not measured: the material does not state the cause. Validate by: mark the last three actions done or not done. If wrong: start with the safety probe before more process work.

A2. The team has a cycle plan that can hold one small action. Why not measured: the material does not state the planning method. Validate by: open the current board and find one free slot. If wrong: use a two-hour calendar hold instead of the board.

The strongest alternative is a new retrospective format or an outside facilitator. It loses because a new format does not finish an action that no one owns. The review test is cheaper and shows the cause in one meeting. [judgment]

End
I recommend that we take these four actions.

1. Open the next retrospective by checking only the last actions. This increment is the first 15 minutes of one meeting. It removes the blocker that failed actions stay invisible. The test comes first.
Given the notes from the last retrospective,
When the meeting starts,
Then each prior action is marked done or not done before any new topic.
This work is Clear, because cause and effect are direct: no review means no proof of change.

2. Close that same meeting with one action, one owner, and one date. This increment is the last 10 minutes of that meeting. It removes the blocker of a list that no one must finish. The test comes first.
Given the meeting close,
When the notes are saved,
Then they name one action, one owner, and one date in the next cycle.
This work is Clear, because one named owner is the known way to make an action finishable.
Step 2 runs in the same meeting as Step 1.

3. Place that action on the next cycle plan with a time box before other work fills the plan. This increment is one planning session. It removes the blocker that delivery work crowds out the change. The test comes first.
Given the next planning session,
When the plan is set,
Then the action has a time box and an owner on the plan.
This work is Complicated, because more than one board practice can hold the work, and a short look at the current board must pick the practice.
Step 3 MUST NOT start until the test in Step 2 passes.

4. If Step 1 shows that people will not name a failed action, run one safety probe. The budget is 20 minutes. Stop if no one states a fact after one prompt. Leverage is a guess. The acceptance test comes first, because the result varies by group.
Metric: share of attendees who state one concrete blocked fact.
Baseline: zero such statements in the current pattern.
Pass threshold: at least half of the attendees.
Sample size: one meeting.
This work is Complex, because the effect of a prompt shows only after the trial.
Step 4 MUST NOT start unless Step 1 shows avoidance.

Follow-up
If A1 is false, stop Steps 2 and 3 and start with the probe in Step 4.
If A2 is false, replace the board slot with a two-hour calendar hold for the owner.
