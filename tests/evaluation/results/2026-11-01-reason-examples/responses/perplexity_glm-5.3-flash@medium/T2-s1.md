# Headline

No prompt fully stops a model from inventing facts. Therefore, do not search for magic wording. A workflow with sources, abstention, and a verification pass cuts the error rate more than wording alone. Measure the rate, because only a number tells you whether a change worked.

1. Fabrication persists because training rewards a guess over an abstention [1].
2. Source grounding and a verification pass cut the rate, and a residual error stays [2], [3].
