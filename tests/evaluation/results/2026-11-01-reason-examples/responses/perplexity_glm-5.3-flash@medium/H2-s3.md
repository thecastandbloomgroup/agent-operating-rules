## Headline

Freeze all public messages now, name one decision owner within the hour, verify every claim against source records before any response, and publish one holding statement today.

- A freeze stops the damage from a second wrong statement, which costs more than hours of silence [judgment].
- One owner ends the conflict between legal, PR, and the board.
- Verified records are the only safe base for the response.
- A holding statement buys time without new claims.

## Background

A journalist published that a statement by the CEO yesterday was false. Legal, PR, and the board each send different instructions. No single owner exists. Today is Sunday, November 1, 2026.

## Relevance

Stock markets open on Monday [inference]. Journalists and regulators work weekends, so the response window is hours, not days [judgment]. Visible disarray among legal, PR, and the board invites more negative coverage [judgment].

## Information

The truth of the claim is unknown, so treat the statement as about as likely as not to be false until records confirm it [judgment]. The analysis rests on crisis practice: stop mixed signals first, then facts, then message [18].

**Assumptions**

A1. The company is publicly listed. Why not measured: the material does not state it. Validate by: check the latest exchange filing. If wrong: remove the Monday market deadline from Step 4 and keep the media deadline.

A2. The CEO statement was public, not internal. Why not measured: the material does not state it. Validate by: ask the CEO office for the release channel. If wrong: add an internal memo step before any public action.

**Alternative considered**

Respond today with a full rebuttal of the journalist. This loses because the facts are not verified, so the company risks a second false statement [judgment].

## End

I recommend that we take these five actions, in this order.

1. **Enforce a messaging freeze for one hour.** Blocker: conflicting instructions create mixed public signals. Domain: Chaotic, because no cause and effect for the coverage is visible yet. Test (deterministic):

```gherkin
Given the freeze notice is sent
When any team drafts a public message
Then the draft routes to the owner for sign-off before release
```

2. **Convene a 30-minute crisis team and name one owner in writing.** Blocker: no one can break ties between legal, PR, and the board. Domain: Confused, because the output decides how the rest is classified. This step MUST NOT start later than one hour from now. Test (deterministic):

```gherkin
Given the crisis team call ends
When minute 30 passes
Then a written note names the owner, the tie-break rule, and the next check-in time
```

3. **Verify each sentence of the CEO statement against source records.** Blocker: no verified base exists for any response. Domain: Complicated, because more than one reading of the records fits, and analysis must pick one. This step MUST NOT start until Step 2 passes its test. Test (deterministic):

```gherkin
Given all source records and logs from yesterday
When each sentence of the CEO statement is checked against them
Then each sentence carries a label, supported, contradicted, or unverifiable, with a source link
```

4. **Publish one holding statement before markets open on Monday.** The statement is a short public note. That is, it acknowledges the issue, promises a full answer, and makes no new claims. Blocker: silence lets the journalist's version define the story. Domain: Clear, because crisis practice gives one known form for this step. This step MUST NOT start until the test in Step 3 passes. Test (deterministic):

```gherkin
Given the labels from Step 3
When legal and the owner sign off
Then the statement is published before the main exchange opens on Monday
```

5. **Monitor coverage and stakeholder reaction for 24 hours.** Blocker: early reaction shows where the correction must go next. Domain: Complex, because the effect on reporters and investors shows only after a trial, so leverage is a guess. Run this probe in parallel with the follow-up work, capped at a 24-hour budget and one analyst. Stop condition: escalate to the owner if new uncorrected claims exceed the baseline count. Acceptance test (stochastic): metric is the count of uncorrected negative claims in media; baseline is the count recorded at publication time; pass threshold is zero growth over 24 hours; sample size is 12 log entries, one every 2 hours.

## Follow-up

Condition that changes the recommendation: if A1 is false, remove the market deadline in Step 4. If A2 is false, add an internal memo before Step 4.
