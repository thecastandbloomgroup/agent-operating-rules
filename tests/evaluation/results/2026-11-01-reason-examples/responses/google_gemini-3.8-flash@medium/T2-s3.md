### Headline

Ground the model with reference text and instruct it to report when evidence is absent.

- Context-bound prompts lower ungrounded assertions by restricting the model to verifiable text.
- Explicit abstention rules prevent guessing when facts are missing.
- Step-by-step verification compares each generated claim against the provided source.

### Background

Large language models predict tokens based on statistical associations rather than verified facts [1]. Users seek prompt text that completely eliminates incorrect assertions, known as hallucinations. However, prompt text alone cannot guarantee zero factual errors without grounding data [judgment].

### Relevance

Deploying models without grounding controls causes factual errors in production tasks. Adding explicit constraints now reduces error rates before users rely on false answers.

### Information

Language models generate ungrounded claims when forced to answer without context [2]. It is virtually certain that no single prompt eliminates all hallucinations on arbitrary open-domain questions [1]. Therefore, the strongest prompting method relies on three controls: grounding text, strict abstention rules, and source citation.

A benchmark prompt template:
"Answer the user request using only the text in the Context block. If the Context block does not contain the answer, output 'Information not found.' Extract direct quotes to verify each claim before writing the answer."

Assumption log:
A1. The user application can supply relevant source documents into the context window. Why not measured: The material does not state it. Validate by: Review the application architecture. If wrong: Replace context-bound prompting with self-consistency sampling and calibration probes.

Alternative considered:
Negative prompting, such as writing "Do not hallucinate", was considered. This alternative fails because models lack an internal truth-verification mechanism without reference text [1].

### End

I recommend that we:

1. Insert an explicit abstention constraint into the system prompt. This increment adds the capability to decline unknown answers.
   Deterministic test:
   Given a prompt with context lacking the answer to a target query
   When the model processes the query
   Then the output MUST equal "Information not found."
   Cynefin domain: Clear, because the instruction rule applies the single established practice for abstention prompts.

2. Restrict the generation scope strictly to supplied context blocks. This increment removes the blocker of models using unverified parametric memory.
   Deterministic test:
   Given a prompt containing reference facts A and B
   When the model is asked for fact C which is not in the reference
   Then the output MUST NOT contain fact C.
   Cynefin domain: Clear, because binding input context to target outputs follows standard prompt configuration.

3. Add a quotation and citation requirement before the final response. This increment adds automated trace capability between claims and source data.
   Evaluative test:
   Use a Pugh matrix with criteria: Claim Source Alignment (weight 50%, pass threshold 100%), Instruction Adherence (weight 30%, pass threshold 100%), and Conciseness (weight 20%, pass threshold 80%).
   Score the generated text against the source text to ensure each sentence traces to an exact quote.
   Cynefin domain: Complicated, because verifying citations across dense text requires domain analysis of the output.

### Follow-up

If A1 is false, replace Step 2 with an external retrieval-augmented generation pipeline.
