## Headline

No single prompt stops hallucination, but one prompt that limits answers to supplied sources cuts it most.

- A prompt can reduce fabrication, because it changes what the model treats as allowed evidence. It cannot remove fabrication.
- Source-grounding works best, because the model copies from text instead of recalling from memory.
- A check step and a refusal rule add a second layer.
- You must measure the result, because the effect differs by model and task.

## Background

A hallucination is a statement that the model presents as fact but that has no support. You asked for the best prompt to stop it. You gave no model, task, or source set.

## Relevance

Unsupported claims in answers cost you time and trust. A prompt costs nothing to try, so you can test it today.

## Information

Here is the prompt. Paste it as the system prompt. Put your documents in the SOURCES block.

```text
Answer using only the text in the SOURCES block.
After each claim, add a short quote from SOURCES that supports it.
If SOURCES do not answer the question, write: "Not found in the sources."
Do not guess. Do not fill gaps from memory.
Before you answer, check each claim against its quote.
Delete any claim that has no quote.
State what the sources do not cover.

SOURCES:
<paste documents here>
```

## End

I recommend that we take these steps in order.

1. Install the prompt above as the system prompt and fill the SOURCES block. This removes the main blocker: the model has no allowed evidence set. Kind: deterministic. Domain: Clear, because the rule "answer only from sources" has one known way to apply it.

   Given the system prompt and a SOURCES block with one fact

   When you ask a question that the fact answers

   Then the reply contains the fact and a quote from SOURCES

2. Build a test set of 30 questions. Make 10 of them unanswerable from SOURCES. This adds the capability to measure the result. Kind: deterministic. Domain: Clear, because each question has one known correct answer or one known "not found". This step MUST finish before Step 3 starts.

   Given a list of 30 questions with answer keys

   When a reviewer checks the list

   Then every question has a key, and 10 keys read "Not found in the sources."

3. Run the test set 3 times with the old prompt and 3 times with the new prompt (180 trials). Kind: stochastic. Domain: Complex, because the effect on your model shows only after the runs. Leverage is a guess. Treat it as a safe-to-fail probe with a budget of one hour. Metric: share of claims with no support in SOURCES. Baseline: the old-prompt rate. Pass threshold: at most 5% and at most half the baseline, at 90 trials per prompt. Stop condition: the new rate is no better than the baseline after 90 trials. Step 4 MUST NOT start until this test passes.

4. Add a human check for high-stakes answers. Read each quote against its claim before you act on the answer. This removes the residual error that the prompt leaves. Kind: evaluative. Domain: Clear, because the practice is to compare the quote to the claim.

   Rubric: criterion "quote supports claim", weight 100%, pass threshold 100% of claims, evidence is the quoted source text.

If A1 is false, replace Step 1 with a retrieval setup and keep Steps 2 to 4.
