## Headline

Use a grounding prompt that forces source-only answers, requires citations, and makes refusal the default when evidence is absent.

- No prompt can eliminate hallucination; it can reduce unsupported answers [judgment].
- The strongest lever is abstention plus citation, not style wording [judgment].
- The prompt works best when retrieval results or source documents are present [judgment].

## Background

The request asks for one prompt pattern. The target failure is invented facts, missing provenance, and confident answers without support.

## Relevance

This matters because one extra instruction rarely changes utility sufficiently. A refusal path changes the cost of an unsupported claim.

## Information

Use this as the system prompt:

```text
Answer only from the provided sources.
For every factual claim, attach a source ID in brackets.
If the sources do not contain the answer, reply exactly: "Insufficient reliable information."
Do not infer missing facts, do not estimate unless the sources give the data, and do not answer from general knowledge.
If sources conflict, state the conflict and label the stronger source.
Keep the answer short and end with a source list.
```

A1. The task has no fixed source pack. Why not measured: the material does not state it. Validate by: test with one answerable and one unanswerable question. If wrong: add a retrieval step before generation.

A2. The model can cite source IDs. Why not measured: no tool can reach its hidden state. Validate by: check that each bracket maps to a listed source. If wrong: require quotes under each claim.

Alternative considered: lower temperature only. It loses because sampling choices do not create provenance, and false premises can remain fluent [judgment].
