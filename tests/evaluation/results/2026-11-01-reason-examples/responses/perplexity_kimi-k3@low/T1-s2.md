Headline
The formatting debates stop when a tool decides style instead of people. First, adopt one automatic formatter and check it in with the code. Second, reformat the codebase in one commit so reviews stay clean. Third, enforce the format in the build so manual debate has no effect.

Background

Relevance
Review time spent on style delays features and erodes trust. An automatic rule removes the cause, not the symptom.

Information
