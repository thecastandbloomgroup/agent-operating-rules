Migrate sign-in to JWT first as a safe, reversible change, and treat sign-up conversion as a separate measured experiment.

1. Sessions and JWT are Clear to Complicated work with known practices. Conversion is Complex work. Its cause and effect show only after trials.

# Background

The request asks to replace session-based sign-in with JSON Web Tokens (JWT, signed tokens that carry user claims) in the auth service. It also asks to improve sign-up conversion. No stack, metrics, or timeline are given.

# Relevance

Auth changes touch every request, so a bad release locks users out. Conversion changes touch revenue, but only measured changes prove improvement.

# End

1. Run the JWT rollout behind a feature flag for one endpoint group (Clear, because the token flow has one standard practice). Increment: token issue and verify for one route in one session.
