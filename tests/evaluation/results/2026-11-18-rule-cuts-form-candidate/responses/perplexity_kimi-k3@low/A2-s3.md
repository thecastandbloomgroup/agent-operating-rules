## Information

Postgres renamed-column syntax takes a brief lock on the table but finishes in milliseconds, since only the catalog entry changes [judgment, standard Postgres behavior]. Every index, constraint, and view that references the column updates automatically; foreign keys and application code do not.

Run this:

```sql
BEGIN;
ALTER TABLE orders RENAME COLUMN user_id TO account_id;
COMMIT;
```
