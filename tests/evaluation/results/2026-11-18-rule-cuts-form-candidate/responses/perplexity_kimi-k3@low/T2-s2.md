# Headline

No prompt can stop hallucination in full, but the strongest single prompt adds a "cite or abstain" rule to every answer.

- Abstaining beats guessing: a prompt that orders the model to say "I don't know" cuts wrong answers the most [judgment].
- Requiring sources next: forcing a citation per factual claim exposes unsupported statements before you trust them [judgment].
- Retrieval beats prompting: giving the model the actual documents reduces hallucination more than any wording change [judgment].
- Limits remain: large language models predict text, so some error rate stays no matter the prompt [judgment].

# Background

The request is for the single best prompt to make a language model stop generating false statements. The honest answer is that prompts reduce errors but never remove them.

# Relevance

Hallucinated facts cause real harm when they look fluent. A prompt that trades some coverage for accuracy is the cheapest control available today.

# Information

The evidence here is judgment from practice, not a measured study in this session. Abstention rules and citation demands each lower unsupported claims, and combining both is standard practice in retrieval systems with observed gains [judgment].

Assumption: "the model" means a general chat model without live document access. Why not measured: the material does not state it. Validate by: apply the prompt with and without pasted documents. If wrong: add the retrieval step from the recommendation.

Strongest alternative: fine-tune or switch to a retrieval-only system. It loses here because it costs hours to days, versus seconds to paste a prompt [judgment].

Use this prompt text verbatim:

```text
Answer only what you can support. For every factual claim, either name its source or write "unverified". If you do not know, say "I don't know" instead of guessing. If the pasted documents lack the answer, say so.
```

# End

I recommend that we:

1. Paste the four-line prompt above at the start of the next session. This is a Clear-domain action (known best practice, deduced rule). It removes the "confident guess" blocker. Test (stochastic): ask 20 questions from a known-answer list. Baseline is the current error rate. Pass when wrong-but-confident answers drop by half at n=20.
2. Attach the source documents the question depends on. This is a Clear-domain action. It removes the "model has no facts" blocker. Test (deterministic):
   Given a question answerable only from the attached document,
   When the model answers,
   Then the answer names the document and section.
3. Ask the same question twice with re-wording. This is a Complex probe (cause of inconsistent answers emerges after trials, so keep it small and capped at 10 trials). It exposes unstable claims. Stop condition: any answer that changes between runs is flagged as unreliable.

# Follow-up

The recommendation changes if the question concerns a tool-connected model. In that case, document grounding (Step 2) moves to first place.
