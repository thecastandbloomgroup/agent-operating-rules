# Headline

No prompt can stop a language model from hallucinating, but one prompt pattern reduces it most: demand source-grounding and an explicit "unknown" exit.

- Hallucination comes from how models generate text, so no wording removes it.
- Grounding plus an "I don't know" option cuts false claims in tests.
- Retrieval of real documents plus verification beats any prompt alone [judgment].

# Background

The request asks for the single best prompt to stop hallucination. Hallucination means the model states false content with confidence. The honest answer is that prompting reduces, but never stops, this behavior.

# Relevance

Choosing the right expectations prevents over-trusting a single prompt. A grounded prompt plus checks protects downstream decisions now.

# Information

Hallucination is a property of probabilistic next-token generation, so it cannot be fully removed by instructions [judgment]. Prompts that (1) supply the source text, (2) forbid claims outside it, and (3) require an explicit "not in the source" answer consistently lower unsupported claims in evaluations [judgment]. The strongest alternative is pure retrieval-augmented generation with post-hoc fact checking; it outperforms prompting alone because the model reads real documents, but it costs more engineering [judgment]. Therefore use both: a grounding prompt as the first layer, and verification as the second.

Assumption: the use case is a general chat or question-answering model, not a specific API with tool access. Why not measured: the material does not state it. Validate by: ask which system is in use. If wrong: add tool-calling or retrieval steps to the recommendation.

The recommended prompt:

```text
Answer only using the sources below.
If the sources do not contain the answer, reply: "Not found in the sources."
Cite the source for every claim.
Never rely on prior knowledge.

Sources:
[paste documents here]

Question: [question here]
```
