## Headline

No prompt stops hallucination completely, but the most effective single instruction is: "Answer only from the provided material. If the material does not contain the answer, say 'I don't know'." Hallucination drops because the instruction replaces open recall with a bounded source. However, it cannot fix prompts where no source material exists. Effect size depends on the task, so the claim is about 70% likely to help for typical question-answering work [judgment].

## Background

The request asks for one prompt that stops a language model from inventing facts. There is no supplied document or tool output to draw on.

## Relevance

Hallucination is the most common failure in production language model use. A wrong answer presented with confidence costs more trust than a refused answer.

## Information

**The prompt to copy:**

> Answer only from the text below. If the text does not contain the answer, say "I don't know." Cite the line you used for each claim.

This works for three reasons:

1. It narrows the answer space to supplied material, so the model does not need to recall facts from training.
2. It gives the model an acceptable exit ("I don't know"), so refusal does not feel like failure.
3. It requires a citation per claim, which forces each statement to point at a source.

**Limits**: a prompt cannot fix retrieval of facts the model was never given. Therefore, this pattern needs you to supply source text. Without source text, the strongest option is "If you are not confident, say so," which reduces but does not remove confident errors [judgment]. Temperature settings and retrieval tools reduce hallucination more than prompt text alone [judgment].

**Alternative considered**: ask for chain-of-thought reasoning. This loses because reasoning text can itself contain invented steps, so it does not bound the source [judgment].

**Assumption**: the use case is question-answering over material the user can supply. Why not measured: the user did not state the task. Validate by: test the prompt on five real queries. If wrong: for open-ended creative tasks, ground rules on format instead of citations.
