## Headline

No prompt removes hallucination, but the prompt below lowers it when you supply source text.

- The prompt forces the model to quote a source for each claim, so unsupported claims have no place to hide.
- The prompt allows the answer "The sources do not say," which removes the pressure to guess.

## Background

Hallucination means the model states false or unsupported facts. You asked for one prompt that stops it. The cause is partly in the model, so a prompt reduces the problem but does not end it [1].

## Relevance

You will use this output to make decisions, so each unsupported claim has a cost. A short test tells you the real rate before you trust the prompt.

## Information

Use this prompt. Paste your source text after it.

```text
Answer using only the sources below.
Do not use outside knowledge. Do not guess.
For each claim, quote the sentence that supports it.
If you cannot quote a sentence, delete the claim.
If the sources do not contain the answer, write: "The sources do not say."
At the end, list each part of the question you could not answer.

Sources:
<paste text here>
```

Evidence for the design:

- Grounding means tying answers to supplied text. Grounding on retrieved documents improved results on knowledge-heavy tasks.

  [2]

- Models can often judge whether their own answer is true, so an "I do not know" option is feasible.

  [3]

- A verification step after the first answer reduced hallucination in tested models.

  [4]

- The prompt lowers the unsupported-claim rate on source-based tasks: 70% likely [judgment].
- The prompt does little for questions with no supplied source. The model then relies on memory, which is the main cause of the error [1].
