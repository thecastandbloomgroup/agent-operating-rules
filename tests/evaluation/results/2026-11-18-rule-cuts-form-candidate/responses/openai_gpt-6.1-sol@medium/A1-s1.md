## Information

A **pin** specifies one exact version, such as `package==1.2.3`. A **transitive dependency** is a package that another package requires.

For an application, use a complete, tested version list that includes both direct and transitive dependencies. [judgment] Keep your direct dependency choices separately, for example in `requirements.in`, so future updates remain manageable. [judgment]

**Alternative considered:** Pin only direct dependencies. This requires less initial work, but leaves transitive versions free to change, so it offers weaker control. [judgment]
