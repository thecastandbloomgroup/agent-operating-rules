## Background

Your support tool now includes an LLM-based summariser, which uses a language model to shorten support records. Agents report errors, but you have no metrics. [1]

## Relevance

A prompt change without a baseline cannot show whether quality improves. [judgment] Therefore, the first deliverable should be a measured error report, not a new prompt. [judgment]

## Information

**Define “wrong” before measuring it.** Use these error classes:

| Class | Definition | Example |
|---|---|---|
| Unsupported fact | The source does not support the claim | An invented refund approval |
| Contradiction | The summary conflicts with the source | “Resolved” when the issue remains open |
| Material omission | A missing fact changes the next support action | A promised callback disappears |
| Attribution error | The summary assigns a statement or action incorrectly | The customer receives credit for an agent’s promise |
| Clarity defect | The wording is hard to use but preserves meaning | Repetition or vague phrasing |

These definitions are proposed review rules, not findings about your tool. [judgment]

**Track three primary measures:**

- **Material-error rate:** summaries with at least one action-changing error divided by summaries reviewed.
- **Required-fact coverage:** required facts preserved divided by required facts identified in the source.
- **Review time:** median seconds an agent needs to verify and correct a summary.

Report counts beside percentages, for example, “8 of 50 summaries contain material errors.” [judgment]

**Assumption:** An authorised team member can access source records and generated summaries. **Why not measured:** The material does not state it. **Validate by:** Check one permitted record. **If wrong:** Start with approved, de-identified examples.

**Alternative considered:** Rewrite the prompt immediately. It loses because the reported problem provides no basis for choosing or verifying a fix. [judgment]

All sample sizes, thresholds, and time limits below are proposed starting limits, not measured properties of your tool. [judgment]
