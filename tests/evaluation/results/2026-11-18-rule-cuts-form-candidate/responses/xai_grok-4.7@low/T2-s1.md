Headline
No prompt can stop hallucination, which means a confident claim that is false or absent from the sources.
A prompt can reduce those claims when it blocks answers from memory.
The strongest wording answers only from supplied sources and requires an explicit unknown reply.
Retrieval and a scored check still beat wording alone.

Background
You asked for the best prompt to make a model stop inventing facts. Models still invent facts when the prompt is open, because the prompt does not add missing knowledge. The practical goal is fewer unsupported claims, not a perfect stop.

Relevance
A wrong invented fact can ship as if it were checked. The prompt below is the control you can apply in one session before you add retrieval.

Information
Surveys treat invented facts as a known failure, and they group mitigations into data, model, and later checks.

Retrieval that inserts source text is a separate control from prompt wording.

The size of the gain from the text below is not measured in this session.

It is likely (66 to 100%) that a source limit plus an unknown reply cuts invented facts versus an open prompt.
Basis: the method class appears in mitigation surveys, but this exact text was not tested here.

Use this system prompt.

Answer only from the sources in this message.
If the sources do not contain the answer, reply: I do not know.
Do not use memory to fill a gap.
Put the supporting source line after each claim.
If sources conflict, state both and do not pick one.
Do not invent names, numbers, dates, or citations.

Assumption: the user wants one paste-ready prompt for a general chat model, not a fine-tune. Why not measured: the material does not state the model or task. Validate by: name the model and say whether sources are already supplied. If wrong: change Step 1 to that model's system format, and skip Step 3 if grounding already exists.

Alternative considered: set temperature to 0 and keep an open prompt. It loses because a lower temperature does not add missing facts and does not force an unknown reply.

End
I recommend that we take these three actions.

1. Paste the prompt above into the system slot. This removes free answers from memory. Clear: deduction from the rule that each claim must match supplied text.
Given a question whose fact is absent from the sources,
When the model replies,
Then the reply is exactly "I do not know."

2. Score 30 held-out items before you change the stack again. This removes an unmeasured claim about the prompt. Complicated: the scores are the analysis that picks the next practice. This action is stochastic, so the acceptance test comes first.
Metric: unsupported-claim rate on 15 answerable items, plus abstention count on 15 items with no source fact.
Baseline: the same 30 items with the old prompt.
Pass threshold: unsupported-claim rate at most half the baseline, and abstention on at least 12 of 15 unknown items.
Sample size: 30 items, one run if temperature is 0. Use three runs if temperature is above 0.
Step 3 MUST NOT start until this test is scored.

3. If Step 2 fails, add retrieval for one document set and pass only retrieved lines as sources. This removes facts that never enter the prompt. Complicated: Step 2 is the analysis that selects this practice.
Given a fact that exists only in the corpus,
When the question is asked,
Then the reply quotes a retrieved line or says "I do not know."

Follow-up
If the product already inserts retrieved sources, keep the unknown reply and skip Step 3.
If the task allows answers from general knowledge, this prompt is the wrong control, because it will refuse true unsourced facts.
