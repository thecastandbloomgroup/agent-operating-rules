Information

This section covers the command, the evidence, the assumptions, and the alternative.

`RENAME COLUMN` is the `ALTER TABLE` form that changes a column name and keeps the stored rows [1].

`ALTER TABLE` acquires an access exclusive lock on the table [1].

An access exclusive lock is the mode that conflicts with every other lock. Because of that lock, other sessions wait until the command ends.

[judgment] A view that uses the column is updated with the new name in current Postgres versions. [judgment] Text inside a function body is not rewritten.
