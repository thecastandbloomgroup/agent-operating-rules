## Headline

Measure before you fix: build a labeled error sample and an agent edit rate, then run one capped improvement at a time against that baseline.

- No metrics exist, so "sometimes wrong" cannot be triaged into a fix.
- First, label 50 summaries against their tickets to find the error type.

## Background

The support tool uses an LLM to summarize tickets. Agents report that summaries are sometimes wrong. No metrics exist, and the request is to make the summarizer better.

## Relevance

Without a baseline, any prompt change is a guess, and success cannot be shown. A small labeled sample is the cheapest way to turn complaints into a ranked error list.
