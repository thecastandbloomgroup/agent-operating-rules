## Background

You ask for the best prompt to reduce model hallucination. The material does not state your use case, so this answer targets a chat model that answers general questions. "Hallucination" here means invented facts, invented quotes, or invented citations [assumption].

## Relevance

A fabricated fact looks correct and is costly to find later. A prompt is the cheapest control you can apply today, and it applies to every chat [judgment].

## Information

No single prompt stops fabrication completely. A rules prompt can cut the invented-fact rate in trap test sets, and the drop is likely to be 40% relative or more (likely, 66 to 100%) [judgment]. Three mechanisms drive this: an explicit "I do not know" path, a per-fact source demand, and a final check pass.

Here is the prompt. Copy it into the model's instructions:

```text
Follow these rules in every answer.

1. State a fact only when you are sure. If you are not sure, say so in words that state the level of sureness.
2. For each fact that is not common knowledge, add its source: a named person, work, event, or dataset. When you cannot name a source, write: "Source unsure."
3. Do not invent names, dates, numbers, quotes, titles, or citations.
4. When you do not know the answer, write: "I do not know," and stop.
5. End with a line that starts "Check:". In that line, list each key fact and mark it "sure" or "unsure". When a fact has no source and you are not sure, delete it from the answer.
```

Assumption: You use prompt-only control, with no search tool or supplied text. Why not measured: the material does not state it. Validate by: check whether your model can search. If wrong: add a rule that grounds each fact in the supplied text and quotes it.

Assumption: You accept "I do not know" as a valid answer. Why not measured: the material does not state it. Validate by: test the prompt on one question the model cannot answer. If wrong: split your questions into grounded and open ones, and update Rule 4 for each.

Alternative considered: a one-line prompt such as "do not hallucinate". It loses because it names no behavior to change and gives no test, so the model shifts wording only [judgment].
