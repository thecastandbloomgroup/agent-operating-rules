## Headline

No prompt makes a model stop inventing content, but the strongest one limits the model to supplied documents, requires refusal without them, and demands a citation per sentence.

1. Models invent facts when they answer from training memory with no source to check against [1].
2. Grounding to documents plus refusal closes most of that channel [1].
3. A second pass that checks each claim against the source removes much of what remains [2].

## Background

The request asked for the best prompt to stop hallucination. The request named no product, no task, and no source material. The answer is a prompt plus two supporting steps, because prompting alone does not reach a zero rate [1].

## Relevance

The answer decides what prompt to paste today. It also sets how much trust to place in each model answer from now on.

## Information

### The prompt

```text
Answer only from the documents I give you in this message.
If the answer is not in those documents, reply "I do not know from these documents."
End every factual sentence with the document name and the section number.
Mark every statement that is not a direct quote as "inference".
Do not add facts from training knowledge or from the internet.
```

### Why it works and where it stops

The prompt gives the model a source to compare against. Grounded answering with citations is the accepted mitigation for ownership grounded in the source because it turns one unverifiable output into many small checkable claims [1]. However, the model can still misread the source or invent a citation, so grounding alone does not reach zero [1]. A separate check pass that extracts each claim and verifies it against the source cut invented content on five test tasks [2][3]. A prompt without documents cannot bridge this gap, because nothing then exists to verify against.

For a case with no documents, weaker variant:

```text
If you do not hold a fact, reply "I do not know".
Label each factual statement with: "known from training" or "inference".
State the date at which your training ended.
```

### Assumption log

Assumption: The user can set a system prompt. Why not measured: The message does not state the product or its settings. Validate by: Look for a system-prompt or custom-instruction field in the product. If wrong: Paste the prompt as the first user message in each session, before the question.

### Alternative considered

A long instruction list that only says "do not invent content". It loses because the model cannot recognize its own invented text without an external source to compare against [1][3]. Grounding supplies that source, so the alternative fails on the same ground as bare prompting.

## End

I recommend that we anchor the model to a source and verify against it.

1. **Install the grounding prompt.** Increment: paste the prompt above into the system field this session. Blocker: it closes the channel of answering from training memory. Test (stochastic): metric, share of answers that cite a source or refuse; baseline, 0%, today nothing cites [judgment]; pass, 90%; sample, 20 fixed questions. Cynefin: Complex, because the effect shows only after runs; the probe budget is 20 questions, and the stop condition is 15 or more of 20 answers that cite or refuse.
2. **Attach the documents.** Increment: implement retrieval, one session. Blocker: answers then rest on a correct source, not on short context. Test (deterministic): Given a question with a known source document, When the retrieval step runs, Then it returns that document in the top 3. Cynefin: Complicated, because standard practice exists and a recall test selects among options.
3. **Add the check pass, in parallel with Step 2.** Increment: a second run that lists each claim and deletes claims without a source, one session. Blocker: removes misreads and invented citations from Step 1 output. Test (stochastic): metric, unsourced claims per 100 answers; baseline, the Step 1 result; pass, at most 2 per 100 [2]; sample, 50 answers. Cynefin: Complex, because the effect shows only after runs; budget, 50 answers. Step 3 MUST NOT start until Step 1 is installed.

If the system-prompt assumption is wrong, Step 1 uses the paste-per-session form above.

## Follow-up

**Conditions that change the recommendation:** (a) No documents exist for the task, so Step 2 drops and the weaker prompt applies. (b) The task reports news or fresh facts, so grounding also needs live retrieval.
