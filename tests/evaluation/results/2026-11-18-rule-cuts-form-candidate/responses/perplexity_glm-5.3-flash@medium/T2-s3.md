Headline: No prompt stops hallucination. The strongest prompt forces the model to answer only from text you give it, to label each claim with a source, and to write "not in the material" for gaps.

- Hallucination comes from how language models generate text. A prompt can reduce it, not remove it [1].
- Prompt methods that demand citations cut invented claims, but error rates stay above zero [2], [3].
- A separate check step after the first answer catches more errors than instructions alone [3].

Background: The user asks for one prompt that makes a model stop inventing facts. The request names no model, no task, and no source documents.

Relevance: The right prompt depends on whether the model has material to ground its answers. The recipe below works with none, and improves further with one.

Information:
The best answer is a pair of prompts, not one. The first constrains the answer. The second checks it.

Prompt 1, the answer prompt:
```
Answer only from the material I give you in this message.
If the material does not contain the answer, write: Not in the material.
Add a source line under every factual claim. Quote the supporting sentence, or write: no source.
Do not fill gaps with plausible text.
```

Prompt 2, the check prompt, sent after Prompt 1:
```
List every factual claim in the answer below.
For each claim, compare it to the material. Write one label: supported, wrong, or not in the material.
Rewrite the answer. Keep only claims labeled supported.
```

Why prompting cannot reach zero: models generate the most likely next word. When training rewards confident guesses, a fluent guess can beat an admission of ignorance, so the behavior persists after any instruction [2]. Surveys of the field report the same limit [1]. The check step helps because a second pass over a short list of claims makes errors easier to see [3].

Assumption: The user works with a general chat model and has no fixed source documents. Why not measured: the user has not answered and the material does not state it. Validate by: read the model name and task type in the next message. If wrong: Prompt 1 gains a clause that namechecks the real documents.

Alternative considered: Fine tuning or retrieval tools lower error rates more than prompting. It loses because the request asks for a prompt, and both alternatives need tooling and data [inference].
