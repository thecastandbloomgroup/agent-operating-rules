Headline
No prompt can stop every false claim, so use this source-limit instruction and test it.
First, answer only from source text in the same message.
Second, write Unknown when that text lacks support.
Third, keep a claim list that names the supporting sentence.
Fourth, compare results with a no-instruction baseline before wider use.

Background
Models predict likely words. They do not check facts unless a system retrieves those facts. A prompt can cut unsupported claims, but it cannot remove them.

Relevance
A false claim can mislead a user in the next answer. Therefore a short tested instruction is safer than a long untested one.

Information
Surveys describe false text as a known failure of generation models.
[1]
Retrieval-augmented generation supplies documents before the model writes.
[2]
A rule to use only source text makes a false claim easier to see. [judgment]
This session has no measurement of a prompt with zero errors. [no source]
So the recommendation does not promise a zero error rate.

A1. The reader wants one general instruction, not a full retrieval build. Why not measured: the material does not state it. Validate by: score 10 real task questions. If wrong: change the instruction to that task's source rules.

A2. Source text can sit in the same message. Why not measured: the material does not state the interface. Validate by: paste one short source and read the claim list. If wrong: fetch the source before the answer.

The strongest alternative is a long self-check prompt. It loses because extra steps can still invent support, and the added length is harder to test. [judgment]

End
I recommend that we do these four steps.

Step 1. Test first.
Given a question whose answer is absent from the source
When the instruction below is applied
Then the output says Unknown and adds no missing fact
Kind: deterministic.
Increment: one instruction block in one session.
Blocker: answers that invent missing facts.
Domain: Clear. A known limit to source text blocks invented facts, so deduction applies.
Work: put this instruction at the top of the message.
Use only the source text in this message.
If the source does not support a point, write Unknown.
Do not add facts from memory.
End with one line per claim.
Name the source sentence that supports the claim.
If no sentence supports it, write Unknown.

Step 2. Step 2 MUST NOT start until the Step 1 text is in the message.
Test first.
Given the instruction from Step 1
When the source text sits under it
Then each supported claim can name one source sentence
Kind: deterministic.
Increment: one source block in the same session.
Blocker: no text to cite.
Domain: Clear. The claim list needs a sentence in the message, so deduction applies.
Work: paste the source under the instruction.

Step 3. Step 3 MUST NOT start until Step 2 is in place.
Test first.
Metric: share of answers that invent a fact absent from the source.
Baseline: the same 10 questions with no instruction.
Pass threshold: fail rate at most half the baseline.
Sample size: 10 questions, one run each.
Kind: stochastic.
Increment: one capped probe of 10 questions.
Blocker: an untested instruction.
Domain: Complex. The pattern appears only after trials and can break on a new task type.
Budget: 10 questions. Stop if 4 of 10 still invent facts.

Step 4. Step 4 MUST NOT start until Step 3 is scored. Skip Step 4 if the Step 3 threshold passes.
Test first. Rubric: invented-fact share, weight 70, evidence is the 10 scores. A fetchable source exists, weight 30, evidence is one sample document. Pass threshold: score at least 70 and the invented share is above half the baseline.
Kind: evaluative.
Increment: one retrieval call for the failed questions.
Blocker: facts that are not in the pasted source.
Domain: Complicated. Fail cases show which facts lack a source, so analysis picks the fix.
Work: fetch that source before the answer, then repeat the Step 1 instruction.

Follow-up
If A2 is false, do not paste in Step 2. Fetch the source first.
If the baseline fail rate is already 0, keep the shorter message with no extra instruction.
