## Background

You ask for the single best prompt to stop hallucination. Hallucination means the model states false things as facts.

## Relevance

A wrong prompt choice gives false trust in model output. Choosing correctly now prevents rework later.

## Information

Three findings, all [inference] or [judgment], because no session sources exist here:

1. Instruction prompts that require "answer only from the given text" and "say 'I do not know' otherwise" cut hallucinations in grounded tasks. This is a known pattern, not a guarantee.
2. Asking for verbatim quotes from a supplied source makes unsupported claims visible.
3. No wording stops hallucination when the model has no source data. Confidence on this point: likely (66 to 100%), basis: the model predicts text, it cannot verify facts it never received.

The strongest alternative is "no prompt, use retrieval only." It loses as a sole answer because a prompt plus retrieval outperforms either alone. [judgment]

A2. Your task has source documents the model can read. Why not measured: the material does not state it. Validate by: run the prompt once with no sources attached. If wrong: add retrieval of source text as the main fix.

```

1. If the CONTEXT does not contain the answer, reply exactly: "Not in context."

CONTEXT:
<paste sources here>

<your question>
```

Test (deterministic):

- Given a question whose answer is absent from pasted context,
- When the model responds,
- Then it outputs "Not in context." and nothing else.

2. **Attach real source text to every factual question** (Clear domain, because retrieval is a known practice). Test as Step 1, plus: answer contains at least one verbatim quote. This removes the "no knowledge" blocker, the largest cause of hallucination.

3. **Careful reading: never ask the model to verify facts it has no source for** (Clear). Test: questions without context get re-routed to Step 2, not answered.

Claimed effect of prompts without sources is a guess. If A2 is false, Step 2 becomes Step 1.
