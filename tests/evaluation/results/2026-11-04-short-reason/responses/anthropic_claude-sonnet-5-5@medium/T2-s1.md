## Headline

No prompt stops hallucination fully, but a grounding prompt reduces it more than any other single prompt.

- The prompt must supply source text, because the model cannot check facts it does not have.
- The prompt must allow a refusal, so the model has a safe answer when the source is silent.
- The prompt must require a quote per claim, so unsupported claims are easy to find.
- Test the prompt on your own questions, because results vary by model.

## Background

Hallucination means output that sounds right but is false or not supported by a source. You asked for the best prompt to stop it. The material gives no model name, task, or source text.

## Relevance

A false answer that sounds sure costs more than a refusal. A prompt that makes the model show its support lets you catch errors before you act on them.

**Prompt to use**

```text
Answer using only the SOURCE text below.
For each claim, add a short quote from the SOURCE in brackets.
If the SOURCE does not answer the question, reply: "Not in the source."
Do not use outside knowledge. Do not guess.
If the question is unclear, ask one question before you answer.

SOURCE:
<paste text here>

QUESTION:
<paste question here>
```
