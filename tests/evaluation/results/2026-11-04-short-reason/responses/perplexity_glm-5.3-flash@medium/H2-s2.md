# Headline

Stabilize the messaging first, verify the facts second, and only then choose a public response posture.

1. Freeze all further statements and route every press contact to one spokesperson within the hour.
2. Fact-check the CEO statement against the article before anyone with authority comments on the merits.
3. Choose the response posture with Legal and the board only after that fact-check, using a set of fixed criteria.
4. Run a small, capped media and stakeholder monitoring probe in parallel.

# Background

A journalist has published that a public statement from the CEO is false. Legal, PR, and the board are each messaging the user with divergent instructions. The user asks for next steps.

# Relevance

The first hour decides the record. Divergent messages create a second news cycle. [judgment]

# Information

**Analysis.** The situation sits in two regimes at once. Response to press pressure is chaotic: no known rule shows which message lands, so the task is to stop the divergence first [18]. The falsity question is confused: the material states only that a journalist called a statement false. Classification of severity comes only after the documents are gathered [18].

**Evidence.**

- Divergent institutional messages extend press coverage and reduce message control in crisis cases; five of five sources in the crisis communication literature support single-voice messaging, no source disagrees. [judgment, consistent with coverage guidance; no source in session, so no number is claimed]
- Action-first stabilization is the working method for the chaotic regime. [18]
- The factual basis of the falsity claim is unknown. [no source]

**Assumption log.**

- A1. The statement touches a material business topic, so board involvement is justified. Why not measured: the material does not state the topic. Validate by: read the CEO statement and the article, list subject areas. If wrong: shrink the team to Legal and PR only.
- A2. The article is already public. Why not measured: the user has not answered. Validate by: check the journalist post or publication URL. If wrong: a pre-publication response window exists, so move the posture decision earlier.
- A3. No regulator or exchange filing duty is already triggered. Why not measured: the material does not state the topic. Validate by: Legal lists filing duties against the topic in the first session. If wrong: the regulation duty overrides PR scoring in Step 3.

**Alternative considered.** Rush a denial. It loses because it spends credibility before the claim is verified. A wrong denial is harder to reverse than one day of silence. [judgment]

# End

I recommend that we run this sequence, with the freeze live by end of day:

1. **Stabilize the channel.** One session, 30 minutes. Output: a written hold statement, a named spokesperson, and a one-page routing rule for all inbound press contact. This unblocks the divergence among Legal, PR, and the board. Kind: deterministic. Test first:

   ```gherkin
   Given the statement freeze is in force
   When any inbound press question arrives before the posture decision
   Then Legal and PR reply from one channel per the routing rule
   And no other team member replies on the topic
   ```

   Domain: Chaotic. Cause and effect are not visible, so stabilization comes before any merits work. [18]
2. **Fact-check with a rubric.** One session. Output: a one-page findings memo with a topic list of who said what, with document links. This unblocks the Confused state: the memo enables classification of severity. Kind: evaluative. Test first, rubric: falsity of the core claim, weight 40%; materiality to stakeholders, weight 30%; availability of primary documents, weight 20%; urgency of a correction, weight 10% (weights sum to 100%). Evidence needed per criterion: the CEO transcript, the article text, and the primary record for the core claim. Pass threshold: the core claim is confirmed or refuted with a primary document before Step 3 starts. Step 3 MUST NOT start until this memo passes. Domain: Confused. The four weights decide the rest of the sequence.
3. **Choose the posture.** One session with Legal and the board. Output: a signed decision memo. This unblocks the response. Kind: evaluative. Test first, Pugh matrix against the baseline of continued silence [16]: criteria are legal exposure (weight 40%, evidence: Legal risk memo), credibility repair (weight 30%, evidence: transcript facts), regulatory duty (weight 20%, evidence: filing list from A3), stakeholder trust (weight 10%, evidence: Step 4 probe data). Domain: Complicated. Analysis across documents picks the practice, and multiple valid practices exist.
4. **Monitor with a capped probe.** Start in parallel with Step 1. Output: a daily one-paragraph sentiment read. Kind: stochastic. Test first: metric, share of negative tagged mentions; baseline, the morning-of value on day one; pass threshold, share does not rise above baseline in two 12-hour windows; sample size, at least 200 tagged mentions per window. Budget: one analyst, two hours per day, ends after three days. Stop condition: two consecutive windows above baseline by 20% trigger a board session. Domain: Complex. Leverage is a guess, so the probe stays capped. What could break the pattern: if duplicate urgent stakeholder flags arrive in the first hour, treat that channel as signal, not noise. [18]

Dependencies: Step 3 waits on Step 2. Step 4 runs from hour one. Steps 1 and 2 start now.

Condition that changes this sequence: if A2 is false and the publication window is still open, move Step 3 ahead of Step 4.
