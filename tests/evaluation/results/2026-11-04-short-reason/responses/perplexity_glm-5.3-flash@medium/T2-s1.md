## Headline

No prompt makes a model stop hallucinating. Prompt controls reduce invented facts, and they reduce them partially, not fully. The best prompt combines three controls: refuse without a source, cite sources for claims, and check the answer before sending.

## Background

You asked for one prompt that stops a model from inventing facts. This response gives that prompt and the evidence behind its rules.

## Relevance

Invented facts cost rework and erode trust in outputs. The change here takes minutes and needs no code.

## Information

Evidence, one claim per line:

Hallucination is a property of how models generate text, so no prompt removes it fully [2].

Scores improve when prompts force refusal and source discipline, yet published studies report partial reduction only [1].

Grounding answers in retrieved passages with citations outperforms prompt-only control in studies of grounded question answering [4].

A verification pass, where the model answers, writes check questions, and answers them separately, reduces factual errors on benchmarks [3].

Models can learn to call tools such as search, so tool access beats a prompt that cannot add missing facts [5].

The prompt:

```text
Answer rules

1. Use only the sources given in this conversation for factual claims.
2. Next to each factual claim, quote or name its source.
3. If a fact has no source and you cannot verify it, reply only:
   "No source. Find one for: <fact>."
4. Mark every claim generated without a source with the label "Guess:".
5. Do not invent names, numbers, citations, or quotes.
6. Keep facts and guesses in separate sections, with labels.
7. Before you send, list each factual claim and its source.
   If a claim has no source, downgrade it to "Guess:" or delete it.
8. If a search or tool result is available, check the answer against
   it and correct errors before sending.
```

Alternative considered: fine-tuning or retraining the model. That alternative loses on cost and time for a single user, because a prompt takes minutes and training takes money and data [1].
