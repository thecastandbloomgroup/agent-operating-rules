## Headline

No prompt stops hallucination fully; the strongest prompt makes the model answer only from sources that you supply, refuse instead of guess, and cite a source for each claim. Three points support this: (1) prompts reduce errors but do not remove them, because the causes sit in training data and generation, outside the prompt [1][3]; (2) the effective prompt-side methods are grounding, abstention, and claim-level verification [2][3]; (3) the effect on your own model is chosen only by a measured test, so the plan includes a sample-size test.

## Background

The request is a single prompt that makes a model stop inventing facts. The conversation supplied no model, no interface, and no source documents. A prompt can only steer generation; it cannot change what the model does or does not know.

## Relevance

This matters now because an invented answer can be acted on as fact before any check happens. A grounding prompt plus a small test is the cheapest control available today.

## Information

**Evidence.**

1. Prompt-only methods cannot eliminate errors. Theme: hallucination has causes in training data and sampling that a prompt does not touch, and it is most visible on open, ungrounded questions. Two survey sources support this theme [1][3]; no source in this session disagrees.
2. Restricting the model to supplied text cuts unsupported content. Theme: grounding plus abstention is the top prompt-side control. Two sources support this theme [1][3].
3. A second pass that re-checks each claim against the source adds a further cut. A measured comparison on hallucination benchmarks reports lower hallucination frequencies after the verification pass [2].
4. Effect size varies by model and task, so a local measured test is the acceptance method [3]. This is why each action below carries a stochastic test with metric, baseline, threshold, and sample size.
5. Basis for the reduction claim: likely (66 to 100%), grounded in three secondary sources. Elimination: very unlikely (0 to 10%), grounded in the same sources [1][2][3].

**Assumption log.**

A1. The model accepts a long persona or system prompt. Why not measured: the material does not state the interface. Validate by: paste the block in Step 1 and confirm it renders. If wrong: use the three core lines of the block as a user message.

A2. Source documents exist for the questions you ask. Why not measured: the material does not state it. Validate by: map three past questions to a document each. If wrong: keep abstention and verification, and drop the grounding line.

**Alternative considered.**

A blunt instruction alone, for example "Do not invent facts." It loses because surveys rank bare constraint prompting below grounding, abstention, and verification [3] [judgment].

## End

I recommend that we

1. Add this prompt block before every answer. Increment: one block, one session (one hour). Blocker it removes: unsupported content on grounded questions. Test, written before the work: stochastic. Metric: share of claims with direct source support, and correct refusal rate. Baseline: the same questions without the block. Threshold: 90% of the sample. Sample size: 20 answerable and 10 unanswerable questions. Budget: two hours or 30 questions, whichever ends first. Domain: Complex, because the effect shows only after runs, so this is a capped probe and the leverage is a guess.

```text
You answer only from the SOURCES that I give you with this question.
If the SOURCES do not contain the answer, write exactly: Not in the sources.
Do not guess.
After each claim in your answer, add the source title and section in brackets.
```

2. Add a verification pass that runs after the first answer. Increment: one follow-up instruction, one session. Blocker it removes: claims left unsupported by the first pass. Test: stochastic, same form as Step 1, compared against the Step 1 baseline. Threshold: refusal wording stays exact, and the source-support metric rises by at least 5 points. Sample size: 20 plus 10 questions. Domain: Complex, a capped probe; step 2 MUST NOT start until the step 1 test produces a baseline number, because safety comes from pass protecting from consistent across data elicitation.
3. Spot-check one answer per session against its cited source. Increment: a five-minute check. Blocker it removes: undetected errors reaching the reader. Test: evaluative. Rubric first: accuracy (weight 0.5), sourcing (weight 0.3), exact refusal wording (weight 0.2), pass threshold 0.8, evidence is the answer next to its sources, layout per a Kepner-Tregoe scoring table [15]. Domain: Complicated, because the rubric is the analysis that picks pass or fail.

Hedge: if A2 is false, drop the first line of the block and keep lines two to four.

## Follow-up

Conditions that change this recommendation: an interface that rejects long system prompts (see A1), or questions that have no source document (see A2). No open questions.
