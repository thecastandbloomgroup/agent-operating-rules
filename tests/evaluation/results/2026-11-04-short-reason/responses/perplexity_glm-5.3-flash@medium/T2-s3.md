## Headline

A prompt alone cannot make a model stop inventing content; the best prompt ties each claim to a source and permits refusal.

- Prompt-only fixes reduce the error rate; they do not remove it [1], [2].
- The root cause sits upstream: training and grading reward a wrong guess over a valid abstention [1].
- The full fix is prompt, refusal policy, supplied evidence, and a measured test.

## Background

The query asks for the best prompt to make a model stop hallucinating. "Hallucinating" here means producing fluent text with false content. This response gives that prompt and the surrounding practice it needs.

## Relevance

Invented facts enter answers today, on every turn. You can apply the prompt within minutes, because it only replaces the current system prompt.

## Information

**Evidence**

- Binary scorers reward a wrong guess over a clean abstention, so models learn to guess rather than refuse [1].
- Hallucinations arise across data, training, and inference; known mitigations combine grounding in supplied context with uncertainty handling [2].
- Grounding plus refusal reduces the factual error rate, likelihood about as likely as not to high, but does not reach zero [inference].

The mitigation levers do not overlap and cover the whole: (a) prompt constraints, (b) refusal policy, (c) supplied evidence, (d) measurement of the result.

**Assumption log**

A1. The model is a general assistant reached by chat or API, with no fixed domain. Why not measured: the material does not state it. Validate by: send the model name and the typical task. If wrong: Step 3 changes the sources it retrieves.

**Alternative considered**

The strongest alternative is a longer prompt with threats, such as "you will be penalized for errors". It loses because it does not change the scoring incentive that favors guessing [1], and its effect has no measured support [judgment].

**The prompt**

```text
Answer only from the supplied context and from common facts you can source.
After each claim, add its source.
If the context lacks the answer, write: "Not in the supplied context."
Do not guess numbers, names, dates, or citations.
Do not invent quotes.
If a question has known and unknown parts, answer the known parts and mark the rest.
```

## End

I recommend that we take three actions, in this order.

1. **Replace the system prompt** with the text above. This removes the unsourced fact stream and adds refusal as an allowed reply. Increment: one edit plus a check on 20 questions. Test, written first, in Gherkin form (Given, When, Then) [14]:

   ```gherkin
   Given 20 past questions, 10 answerable and 10 not
   When the model runs with the new prompt
   Then no block contains an unsourced fact, and each unanswerable reply contains "Not in the supplied context"
   ```

   Domain: Clear, because it applies a known pattern of grounded output with refusal [2]. Kind: Deterministic, the prompt text either passes the check or does not.

2. **Measure the result.** This removes guesswork about whether the prompt works. Increment: collect 30 questions with known answers, run old prompt and new prompt, count factual errors and refusals. Test, written first: n = 30 per arm; pass when the error count falls below the old-prompt count and the refusal rate stays below 50% [judgment thresholds]. Domain: Complicated, because a fixed measurement protocol selects between the two prompts. Kind: Stochastic, the sample size and threshold are set before the runs. Step 2 MUST NOT start until the edit in Step 1 is done.

3. **Run a retrieval probe if errors stay above 5 of 30.** This adds supplied evidence for answerable questions. Increment: find or write the source documents for 10 of the 30 questions, add the relevant paragraphs to the context, rerun. Stop condition and budget: 2 hours and 10 questions; stop if the error count on those 10 does not fall to half or less [judged threshold]. Domain: Complex, because cause and effect show only after the probe; leverage is a guess. Kind: Stochastic, the metric, baseline, and threshold are stated above. Step 3 MUST NOT start before the counts from Step 2 exist.
