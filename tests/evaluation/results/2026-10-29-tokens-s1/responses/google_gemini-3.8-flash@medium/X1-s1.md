## Background

Your support tool uses a large language model to summarise support tickets.
Support agents report that the summaries contain factual errors.
However, the system lacks metrics and telemetry to measure these failures.

## Relevance

Inaccurate summaries cause agent mistakes and slow down ticket resolution.
Therefore, establishing measurement now prevents wasted engineering effort on ineffective prompt changes.

## Information

This section covers the evidence, assumptions, and alternatives.

Factual errors in summaries directly harm task efficiency per recent benchmarks [1].
Agent feedback loops reduce factual errors in production summarisation systems by an estimated 40% [judgment].
It is likely (66 to 100%) that agent dissatisfaction stems from hallucinated details rather than poor grammar.
