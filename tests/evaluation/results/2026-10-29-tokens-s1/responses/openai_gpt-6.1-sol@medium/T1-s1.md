### 2. Publish a short agreement and enforce it consistently

**Dependency:** Step 2 MUST NOT start until Step 1 names an owner.

**Kind:** Deterministic. **Domain:** Clear, once ownership exists.

**Test first:** Given a compliant SQL change, when someone requests a personal format preference, then that request does not block approval.

**Action:** In one session, adopt this agreement:

> - Use the existing enforced standard, if one exists.
> - Otherwise, the owner selects compatible formatter defaults after hearing concrete objections.
> - Automated checks enforce format wherever the tool supports it.
> - Reviewers label optional preferences as suggestions.
> - Reviewers can block defects and violations of agreed rules.
> - Discuss proposed standard changes outside the current review.
> - Record exceptions with a reason.
> - Apply the rule to senior and junior colleagues alike.

This removes ambiguity about legitimate review requests. [judgment]

Avoid a repository-wide reformat during the trial; keep that decision separate from the culture change. [judgment]
