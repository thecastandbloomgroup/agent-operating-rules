## Headline

No single prompt stops hallucination, but a grounding prompt with a refusal rule cuts it most, so use the prompt in Section End, Step 2.

- The prompt limits the model to supplied sources and gives it a safe answer when the sources are silent.
- A prompt alone does not remove errors, so you must measure the result on your own questions.
- Supplying the sources (retrieval) and adding a check pass reduce errors further.

## Background

You asked for one prompt that stops a model from inventing facts. Models produce fluent text whether or not they know the answer. The request has no task, model, or source material, so the prompt below is general.

## Relevance

An invented fact looks the same as a true one. You pay for each one you fail to catch.

## Information

**Evidence**

- Retrieval-augmented generation (RAG) means the system fetches documents and the model answers from them. The original RAG paper reports better factual output on knowledge tasks than a model without retrieval. [1]
- A "verify your own draft" pass reduced invented facts in the tested tasks. [2]
- Hallucination appears across many language tasks and has no single cause. [3]
- No prompt removes hallucination completely. [judgment]
- Confidence: moderate. Two papers support the methods, and no run on your model exists yet.

## End

I recommend that we take these steps in order:

1. **Build a test set and measure the baseline.**
   - Increment: write 50 questions, 25 of them with no answer in the sources, and run them once with your current prompt.
   - Blocker removed: no way to tell whether any change helps.
   - Kind: stochastic. Test first: metric is the share of answers with an unsupported claim. The baseline is the Step 1 result. The pass threshold is half the baseline, at n = 50. Fifty is small, so treat the result as a signal. [judgment]
   - Cynefin: Complicated. An expert can design the set by analysis.

2. **Add this grounding prompt.** Step 2 MUST NOT start until Step 1 is done.

   > Answer only from the sources below. Do not use outside knowledge. For each claim, quote the sentence from the sources that supports it. If the sources do not contain the answer, write: "Not in the sources." If you are unsure, say what you are unsure about.

   - Increment: paste the prompt into the system message and run the 50 questions three times.
   - Blocker removed: the model fills gaps with guesses.
   - Kind: stochastic. Test: the same metric meets the Step 1 threshold, and the model refuses at least 90% of the 25 unanswerable questions.
   - Cynefin: Complex. This is a probe with a budget of one session. Stop if the rate does not fall after three runs. The leverage is a guess.

3. **Supply the sources.** Step 3 MUST NOT start until the Step 2 test passes or the stop condition fires.
   - Increment: attach the one document that answers your top five questions.
   - Blocker removed: the model cannot quote text it does not have.
   - Kind: stochastic. Test: on those five questions, the unsupported-claim rate is lower than in Step 2, over three runs each.
   - Cynefin: Complicated. Analysis picks which documents to attach.

4. **Add a check pass.** Run this in parallel with Step 3, with a budget of one session.
   - Increment: send the draft back with the prompt "List each claim. Mark each as supported or unsupported by the quoted source. Delete the unsupported claims."
   - Blocker removed: errors that survive Step 2.
   - Kind: stochastic. Test: the unsupported-claim rate falls below the Step 2 result at n = 50. Stop if the answers get worse or the cost doubles.
   - Cynefin: Complex. This is a safe-to-fail probe.
