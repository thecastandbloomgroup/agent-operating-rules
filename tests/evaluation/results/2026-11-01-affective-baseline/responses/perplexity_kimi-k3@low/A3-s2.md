Yes. Turn on gzip for JSON API responses averaging 400 KB, because text compresses well and the bandwidth saving usually outweighs CPU cost.

Use gzip level 5–6, or Brotli quality 4–5 if clients support it. Compress only responses above about 1–4 KB. Exclude already compressed media and event streams. Measure p95 latency, CPU per request, and bytes out before and after one week of traffic. Expected result: JSON often falls to 20–30% of original size, so 400 KB may become roughly 80–120 KB [judgment]. The main risk is added CPU and small latency at high request rates; keep level moderate and bypass compression when response time degrades.

If your clients are modern browsers or controlled SDKs, prefer Brotli where accepted; otherwise gzip is the safe default.
