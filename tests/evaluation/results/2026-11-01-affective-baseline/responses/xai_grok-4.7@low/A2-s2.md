Use one statement to rename the column: `ALTER TABLE orders RENAME COLUMN user_id TO account_id`.

Postgres renames the column and does not copy the table rows.

Indexes and constraints on that column keep their link to it.

## Background

You need `orders.user_id` renamed to `account_id` before you board. The request is a Postgres rename, not a data copy. This note gives the statement and the checks that keep it safe.

## Relevance

A wrong name or a long lock can block writes while you are offline. Therefore run the checks first, then the rename.

## Information
