## Information

### What to measure

Use these proposed definitions and targets. They are initial acceptance criteria, not measured results. [judgment]

| Measure | Definition | Proposed target |
|---|---|---|
| Material error rate | Summaries with an error that changes an agent’s understanding or action, divided by summaries reviewed | At least 50% below the current version |
| Harmful errors | Invented commitments, wrong customer identity, incorrect financial details, or unsafe advice | Zero observed |
| Required-fact coverage | Correctly included required facts, divided by required facts in the source | At least 95% |
| Review time | Seconds needed to check and correct a summary | Median no higher than the current version |

Count unsupported claims, contradictions, and incorrect attribution as factual errors. Count absent required facts separately. Treat awkward text as a style defect unless it changes meaning. [judgment]

For each case, record the source conversation, summary, model version, prompt version, agent correction, error category, severity, and review time. This creates a record that links defects to changes. [judgment]

Use two case sets:

- **Development set:** 10 agent-reported failures to diagnose and repair.
- **Evaluation set:** 40 randomly selected recent cases, hidden from whoever changes the summariser.

These sample sizes support a first pilot, not a broad reliability claim. [judgment] Confidence in any diagnosis is currently low because the available evidence contains no examples or measurements. [1]
