### Headline

No single prompt stops all model hallucinations because language models generate text using probabilities rather than factual retrieval.

Grounding the prompt in verified reference text provides the largest measurable drop in hallucination rates.
Enforcing a refusal constraint instructs the model to state when information is missing.

### Background

The user asks for a prompt that prevents a language model from hallucinating. Language models generate tokens based on statistical associations rather than verified facts [1]. Therefore, prompt engineering reduces factual errors but cannot eliminate them entirely [judgment].

### Relevance

Deploying generative models in production requires predictable factual accuracy. Relying on a prompt alone creates false confidence and allows unverified claims into production workflows [judgment].

### Information

Research demonstrates that prompt constraints reduce but do not eliminate hallucinations [2]. Ji et al. show that hallucinations stem from training data noise, parametric memory limits, and generation strategies [1]. Therefore, system architecture must pair prompts with grounding data [judgment]. 

A direct prompt with a refusal constraint lowers hallucination rates compared to unconstrained generation [2]. For example, adding "Answer only using the provided text; say 'I do not know' if the text lacks the answer" cuts unsupported claims [judgment].
