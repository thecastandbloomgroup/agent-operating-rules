## Headline

No single prompt stops hallucination, but a grounding prompt with a permitted "Unknown" answer lowers it the most.

- Hallucination is a known property of language models, so a prompt reduces it but does not remove it [1].
- Answers tied to supplied sources contain fewer invented facts than answers from memory [2].
- A rule that allows the model to say "Unknown" removes the pressure to guess [judgment].
- A short test on your own questions shows whether the prompt works.

## Background

You asked for one prompt that stops a model from inventing facts. The material gives no model name, task, or source documents. This answer therefore targets general question answering.

## Relevance

An invented fact looks the same as a true fact. A prompt that blocks guesses lowers the cost of checking every answer.

## Information

Use this prompt:

```text
Answer only from the sources provided.
Do not use outside knowledge.
Quote the source text that supports each claim.
If the sources do not contain the answer, reply: Unknown.
Do not guess names, numbers, dates, or links.
State your confidence: high, medium, or low.
```

Evidence:

- Hallucination is documented across many language generation tasks, and no method removes it [1].
- Retrieval of source text before generation improves factual accuracy on knowledge tasks [2].
- It is likely (66 to 100%) that this prompt lowers the error rate. It is very unlikely (0 to 10%) that it reaches zero [judgment].
