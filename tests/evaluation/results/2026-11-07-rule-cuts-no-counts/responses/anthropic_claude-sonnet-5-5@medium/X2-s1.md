## Relevance

   - Increment: list every action from them in 30 minutes.
   - Blocker removed: the cause is unknown.
   - Kind: evaluative. Rubric, written first: the criteria are specific (weight 30), owner named (25), date set (15), and done (30). Score each action 0 or 1 per criterion.
