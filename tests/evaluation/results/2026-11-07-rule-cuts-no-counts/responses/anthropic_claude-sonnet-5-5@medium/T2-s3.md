## Headline

No prompt stops hallucination fully, but a grounding prompt with a permitted "no answer" reply cuts it most.

- Models guess because training and tests reward a guess more than an abstention [1].
- A prompt that allows "the sources do not say" removes that reward.
- Supplied source text gives the model facts to use instead of memory [2].
- A test on your own questions shows whether the prompt works.

## Background

A hallucination is a model output that sounds right but is false or unsupported [3]. You asked for one prompt that stops it. No single prompt does that, so this answer gives the best-supported prompt and a way to test it.

## Relevance

The prompt costs nothing to try. Without a test, you cannot tell whether it works on your tasks.

## Information

**The prompt** (paste it into the system message, then add your source text):

```text
Answer only from the SOURCES below. Do not use outside knowledge.
If the sources do not contain the answer, reply exactly: "The sources do not say."
Support each claim with a short quote from the sources, in quotation marks.
Do not guess any number, date, name, or link. If it is missing, say it is missing.
If the question is unclear, ask one clarifying question before you answer.

SOURCES:
<paste text here>
```

**Evidence**

- Models guess because most tests score a wrong guess the same as "I don't know". This favors guessing over abstaining [1]. The source is a single paper, so confidence is moderate.
- Retrieval of source text improves factual accuracy on knowledge tasks [2].
- Surveys list unsupported output as a standing problem that no single method removes [3]. Therefore a full stop is very unlikely (0 to 10%).
- The prompt lowers the hallucination rate on grounded tasks: likely (66 to 100%). [judgment] The basis is the three points above, not a measurement on your tasks.
