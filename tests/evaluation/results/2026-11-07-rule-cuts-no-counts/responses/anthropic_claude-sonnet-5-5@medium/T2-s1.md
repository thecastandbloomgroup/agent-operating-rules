## Headline

No prompt stops hallucination fully, but a grounding prompt with a refusal option cuts it most.

- Hallucination comes from how models generate text, so a prompt reduces it and does not remove it.
- The best prompt limits answers to supplied sources, requires quotes, and permits "Not in the sources."
- A test on your own questions shows whether the prompt works.

## Background

You asked for one prompt that stops a model from stating false facts. Models predict likely text, so they can produce fluent claims that no source supports [1].

## Relevance

A wrong claim in a report, code, or advice costs more than a refusal. A prompt is the cheapest control to change today.

## Information

Evidence:

- Surveys define hallucination as output that is unfaithful to the source or to fact, and they find it in all tested tasks [1].
- Grounding answers in retrieved text improved factual output in knowledge tasks [2].
- A second pass that checks each claim lowered false claims in tests [3].
- Models can partly judge when their own answers are right, so a confidence field has some value [4].
- A prompt alone removes all hallucination: very unlikely (0 to 10%) [judgment].

The prompt (paste your source text where marked):

```text
Answer only from the text between <sources> tags.
Do not use outside knowledge.
For each claim, quote the sentence that supports it.
If a claim has no quote, delete the claim.
If the sources do not answer the question, reply: "Not in the sources."
End with a confidence level (high, medium, or low) and the reason.

<sources>
[paste text here]
</sources>

Question: [your question]
```
