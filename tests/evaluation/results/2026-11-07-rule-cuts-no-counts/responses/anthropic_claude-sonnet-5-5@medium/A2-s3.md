## Headline

Run `ALTER TABLE orders RENAME COLUMN user_id TO account_id;` in a transaction, but only after you confirm that no code still reads `user_id`.

- The rename is a metadata change, so it finishes fast [1].
- Postgres updates indexes, constraints, and views for you [1].
- Application queries and function bodies do not update, so they break at once [inference].
- Do not run it right before you board, because nobody could fix a break.

## Background

You want to rename the column `user_id` to `account_id` in the `orders` table. The database is Postgres. You are about to travel.

## Relevance

The rename takes effect at commit. Any query that still names `user_id` then fails. A failure while you are in the air has no owner.
