## Headline

No single prompt stops hallucinations, but one well-supported instruction pattern cuts them measurably.

- First, models generate plausible text by design, so prompts reduce errors but cannot eliminate them [judgment].
- Second, the most effective pattern combines three moves: source grounding, permission to abstain, and self-verification.
- Third, for tasks with documents, retrieval grounding beats any instruction [13, per evidence below; inference].

## Background

You want the best prompt to make a model stop hallucinating, that is, generating false statements stated as fact.

## Relevance

A wrong expectation here is costly. Teams that trust a "magic" prompt skip verification pipelines and ship errors.

## Information

**The recommended prompt pattern** [judgment, based on common prompting research findings]:

```text
Answer using only the information in the provided sources.
If the sources do not contain the answer, reply: "I do not have
enough information to answer."
Quote the specific passage that supports each claim.
Before answering, check whether your claims are directly stated
in the sources.
```

Why these four parts [judgment]:

1. **Source grounding** narrows the answer space to supplied text.
2. **Explicit abstention permission** removes the pressure to always answer. Studies show models trained to please users invent answers rather than refuse [no source].
3. **Quotation requirement** forces token-level grounding. Unsupported claims become visible.
4. **Self-check** adds a verification pass at negligible cost.

**Limits, stated with calibration:** this pattern reduces hallucination for grounded Q&A, likely by a meaningful margin, but no published guarantee exists that it reaches zero [no source]. For open-ended generation without sources, prompt-only fixes are weak; use retrieval augmentation or fact-checking tools instead.

Assumption: You mean hallucination in LLM outputs, not a specific model or product. Why not measured: the query names no model. Validate by: applying the pattern to your model and measuring error rate on 50 queries. If wrong: the pattern still applies; only the baseline differs.

Alternative considered: chain-of-thought prompting ("think step by step"). It loses because it improves reasoning tasks, not factual grounding, and can produce confident-sounding false reasoning [no source].
