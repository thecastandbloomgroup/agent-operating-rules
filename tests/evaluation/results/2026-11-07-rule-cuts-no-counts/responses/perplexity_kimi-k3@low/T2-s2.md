## Headline

No prompt stops hallucination completely; the best single prompt is one that forces the model to ground every claim in provided material and to say "unknown" otherwise.

1. Grounding in supplied sources removes the main cause: the model inventing facts when it has no data [judgment].
2. An explicit "state unknown" rule replaces silent guessing with a visible flag [judgment].
3. A citation requirement makes each claim checkable, so errors surface quickly [judgment].

## Background

The request is for one prompt that makes a model stop hallucinating. Hallucination means confident output unsupported by facts. No prompt can fully prevent it, because the model always generates plausible text [judgment].

## Relevance

A good grounding prompt cuts error rates sharply in practice and makes remaining errors easy to catch [judgment]. This matters now because the cost of a wrong answer usually exceeds the cost of a refused one.

## Information

Assumption: The user can paste reference material or links into the chat. Why not measured: the material does not state it. Validate by: try the prompt with and without sources. If wrong: the prompt still helps, but weaker.

Alternative considered: chain-of-thought or self-critique prompts. They lose because they improve reasoning, not factual grounding; the model can reason fluently about invented facts [judgment].

The recommended prompt:

> Answer only from the sources I provide below. For every factual claim, quote the exact source line. If the sources do not answer the question, reply "The sources do not say" and list what additional information would help. Do not use outside knowledge. If you are not certain of a number, date, or name, say so and give your confidence as a percentage.

## End

1. Paste the source text, then send the grounding prompt above. Blocker removed: unsupported claims. Test: Given a question outside the sources, When the model answers, Then it replies "The sources do not say". Deterministic; Clear domain, a known best practice.
2. Attach one real task question and check each claim against its quoted line. Blocker removed: unverifiable output. Test: Given the model's answer, When each claim is compared to its quote, Then 100% of claims match a source line. Deterministic; Clear domain.
3. For high-stakes topics, ask for sources first, then answer in a second turn. Blocker removed: reliance on model memory. Test: Given a high-stakes question, When no sources exist, Then the model lists needed sources instead of answering. Deterministic; Clear domain.
