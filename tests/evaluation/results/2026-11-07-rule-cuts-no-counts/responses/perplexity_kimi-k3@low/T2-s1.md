## Headline

Use a grounded-or-abstain prompt; no wording alone can guarantee zero hallucination.  
The prompt must force source use, require abstention when evidence is missing, and ban invented citations.  
Lower temperature and retrieval help more than style alone [judgment].

## Background

The request is for one prompt that reduces fabricated answers. Hallucination is a model and setup problem, not only a wording problem [judgment].

## Relevance

A weak instruction can still produce fluent false claims. A strict instruction can reduce fabrication when the task has sources or tools.

## Information

Assumption: the model has no browsing or retrieval tool in this setup. Why not measured: the material does not state it. Validate by: run the same prompt with and without provided sources. If wrong: add retrieval before relying on the prompt.

Alternative considered: “Be accurate and do not hallucinate.” It loses because it states the goal but gives no behavior for missing evidence [judgment].

Copy this prompt:

```text
Answer only from the provided sources or verified tool output.
If the answer is not supported, write exactly: "I do not have enough reliable information."
Do not invent names, dates, numbers, quotations, citations, URLs, or legal/medical/financial facts.
Before final, list each factual claim and the source passage that supports it.
Delete any claim without support.
```

Use temperature near 0 for factual tasks when the API allows it [judgment].

## End

I recommend that we:
1. Add the prompt block above to the system message for factual tasks. Test: Given an unsupported question, When the model answers, Then it outputs the exact abstention sentence. Clear domain: the rule is explicit.
2. Provide sources before asking factual questions. Test: Given a source pack, When the model answers, Then each claim maps to one passage. Clear domain: citation checking is mechanical.
3. Set temperature near 0 and disable sampling tricks for factual runs. Test: Given one fixed question, When run 10 times, Then answers are stable and sourced. Stochastic domain: outputs vary, so use repeat trials.
4. Log abstentions and false-claim rates weekly. Test: Given 50 representative questions, When scored against sources, Then unsupported claims fall versus the prior baseline. Stochastic domain: accept only at the preset sample size.

## Follow-up

Conditions that change the recommendation: if retrieval is available, move source fetching before generation; if the task is creative, relax the grounded-or-abstain rule.
