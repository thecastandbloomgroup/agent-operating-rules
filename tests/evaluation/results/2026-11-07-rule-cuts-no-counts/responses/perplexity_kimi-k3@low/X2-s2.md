Headline

Retrospectives fail when they produce feelings instead of committed, owned, tested actions; fix the output, not the meeting.
- Assign every action one owner and one deadline; the data links ownerless actions to non-delivery.
- Cap actions at one or two per retrospective; more actions dilute completion.
- Open each retrospective by reviewing last actions first; this creates an accountability loop.
- Escalate blockers the team cannot fix; otherwise the same issues return and trust falls.

Background

The retrospectives run, people attend, but no changes follow. This is a common pattern: the meeting works as a ritual, not as an improvement engine [judgment].

Relevance

A retrospective that changes nothing costs about 1 to 2 hours per person per sprint and teaches people that speaking up has no effect. Fixing it restores both the time value and trust.

Information

Evidence [15]:
- One supporting theme from agile practice literature: actions without owners or follow-up almost never complete (1 source, no disagreement) [4].
- The pattern "attend but nothing shifts" matches failure mode: outputs are complaints or general goals such as "communicate better," not verifiable actions [judgment].
- Numbers: no team metrics were provided, so completion rate and action count are unknown. Confidence: medium, based on one secondary source plus judgment.

Assumptions:
- Assumption: actions exist but lack owners or follow-up. Why not measured: the material does not state it. Validate by: check the last three retrospective notes for owners and deadlines. If wrong: the problem is likely trust or facilitation, so replace Step 2 with an anonymous safety check.
- Assumption: the team has authority to change its own process. Why not measured: the material does not state it. Validate by: ask which of the last five blockers needed management approval. If wrong: escalate first, per Step 4.

Alternative considered: replace retrospectives with another format (for example a health-check survey). It loses because it treats symptoms; the cause is the missing action loop, and a new format without an action loop fails the same way [judgment].
