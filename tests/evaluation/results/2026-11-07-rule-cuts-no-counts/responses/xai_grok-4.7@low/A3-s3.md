The API returns JSON. The average body is 400 KB. The request is whether gzip should be on.

That size adds delay on slow links and raises egress cost. Compression changes both, so the choice matters before the next release.

HTTP allows Content-Encoding: gzip when the client lists gzip.

I recommend that we do four steps.

Step 1 is Clear. The HTTP rule already states the practice, so apply it. Write the test before the change. Given a 400 KB JSON body and Accept-Encoding that lists gzip, When the handler sends the response, Then Content-Encoding is gzip and the decoded body matches the original JSON. Increment: one config change that gzips application/json above 1 KB. Blocker removed: the full 400 KB transfer. This step does not wait on later steps.

Step 2 is Complicated. A short analysis must pick the level, because more than one level works. Write the rubric first. Size ratio weighs 50%. CPU time weighs 30%. Error count weighs 20%. Pass when the ratio is at or below 0.4, CPU is at or below 10 ms per body, and errors are 0. Increment: gzip 20 real samples at levels 1, 5, and 9 in one session. Blocker removed: an unmeasured level. Do not lock the production level until this rubric passes.

Step 3 is Complex. Live cost shows up only after a probe, so claimed leverage is a guess. Write the test first. Metric: p95 CPU and p95 response time. Baseline: the prior hour. Pass: p95 response time rises by no more than 10%. Sample: 15 minutes on 10% of instances. Stop if p95 response time rises by more than 20%. Increment: that capped probe only. Blocker removed: unknown production cost. Step 3 MUST NOT start until the Step 1 test passes on one instance.

Step 4 is Clear. Skip gzip where a secret sits next to attacker-chosen text, per the attack class in [2]. Write the test first. Given such a route, When compression is configured, Then that route sends no Content-Encoding. Increment: list those routes and exclude them in one session. Blocker removed: that leak path. Step 4 can run beside Step 1.

If the probe hits the stop condition, turn gzip off and repeat Step 2 at level 1 only. No open question remains, because a wrong guess reverses by a config change.
