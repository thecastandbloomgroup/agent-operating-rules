## Headline

No prompt eliminates hallucination, because the error comes from how the model was built, not from prompt wording [1]. Three points support this:

1. Prompts that force verbatim quotes and refusal when evidence is absent cut false-claim rates in published trials [2].
2. A grounding prompt with a required source quote is the highest-value single prompt available [2].
3. A check after generation catches the errors that any prompt leaves behind [1].

## Background

The user asks for one prompt that makes a model stop producing false statements. The context includes no named model, tool, or task.

## Relevance

Prompt changes take one session, so the cost is low. Building retrieval or fine-tuning takes weeks, so a prompt is the first lever to test.

## Information

**Evidence**

A hallucination is a statement that is not supported by the source or by fact. Surveys show it comes from training data gaps and from training objectives that reward fluent text over true text [1]. So prompt text alone cannot remove the error mode. Prompt-level controls can lower the rate:

1. Requiring the model to quote the supplied document for each claim, and to answer "not in the documents" when no quote exists, is the core grounding control [2].
2. Chain-of-Verification, where the model writes questions, answers them alone, and then revises the draft with those answers, lowered factual error rates in trials [2].
3. Models estimate their own checks with some accuracy, so asking for a confidence score before the answer improves the refusal rate [3].

Assumption of limits: no prompt that I know of reaches a zero false-claim rate on open factual questions [no source].

**Alternative considered**

Retrieval plus a fine-tuned model beats a prompt alone on error rate [1]. It loses for this first step because it needs engineering and data. A prompt needs one session.

## End

I recommend that we adopt a grounding prompt and a verification pass, and test the drop with a measured baseline. Four steps, and the sequence is explicit.

1. **Adopt a draft-first rule.** Treat every model answer as a draft until a check passes. Blocker it removes: silent trust in output. Test (deterministic):
   ```gherkin
   Given a model answer with an unsupported statement
   When the reviewer checks each claim against the source
   Then the answer returns as a draft with that claim flagged
   ```
   Domain: Clear, because the rule is one step and needs no analysis.

2. **Measure the baseline.** Take 20 real questions. Grade each answer as true, partial, or false with a rubric weighted 3, 1, 0. Record the share of answers with at least one false claim. Blocker it removes: no number to compare against. Test (evaluative): rubric with criteria "fact check per claim" (weight 0.7) and "source match" (weight 0.3), pass threshold of 90% of claims verified, evidence = the graded set. Domain: Complicated, because the grading is analysis that produces the number all later steps need. Steps 3 and 4 MUST NOT start until this step passes.

3. **Deploy the grounding prompt.** Use this text: "Answer only from the attached documents. Quote the document for each claim. If no quote supports a claim, answer: not in the documents." Run a probe on the same 20 questions with documents attached. Stop condition: stop if the false-claim share does not drop at all. Budget: 1 hour and 20 samples. Test (stochastic): metric = share of answers with at least one false claim, baseline = the Step 2 number, pass threshold = 50% below baseline, sample size = 20. Domain: Complex, because the effect of prompt wording shows only after the run; the pattern could break on other question types.

4. **Deploy the verification prompt, in parallel with Step 3.** For questions without documents, use this text: "Draft the answer. List two check questions on its claims. Answer each question alone. Revise the draft." Test (stochastic): same metric, same baseline, pass threshold = 30% below baseline, sample size = 20. Domain: Complex, because trials show a drop but the size depends on the task [2]; the budget caps the spend.

If Step 3 or 4 misses its threshold, replace that step with retrieval from your document set, because the prompt-only path has then reached its ceiling.
