# Headline

No prompt can make a model stop hallucinating. The best prompt forces the model to quote a source or write "I do not know". Prompt wording reduces fabrication, but it does not remove it [judgment, based on 1 and 2]. Grounding the answer in your own documents removes more errors than any wording [3].

# Background

You asked for one prompt that stops a model from inventing facts. Hallucination means output that states false or unsupported facts as true [1]. The request names no tool and no task, so this answer covers chat use in general.

# Relevance

You will act on answers from this model, so a fabricated fact becomes a wrong decision. A prompt plus a small test lowers that risk in one working session.

# Information

**What the evidence shows.** Prompt studies report scores that swing by up to 76 accuracy points between paraphrases of the same prompt [2]. Therefore no wording is universal, and each wording needs a local test [2]. Studies of grounding report that answers built from retrieved documents contain fewer fabrications than answers built from memory alone [3]. So the largest gain comes from sources, not from warnings.

**The prompt.** Put this block in the system prompt, or paste it before your first question:

```text
You answer only from the sources given in this conversation.
For every claim, do one of two things:
1. State the claim, then cite the source and section that supports it.
2. Write: "The sources do not answer this."
If you use a fact outside the sources, mark it with [outside knowledge]
and ask the user to verify it.
Never fill a gap with a guess.
```

**Assumption log.**

- Assumption: you can edit the system prompt, or paste text at the start of a chat. Why not measured: the material does not state your tool. Validate by: look for a system-prompt or custom-instruction field. If wrong: use a tool that has a citation or retrieval feature instead.
- Assumption: hallucination here means invented facts, not stale data or poor style. Why not measured: the material does not define it. Validate by: run one question set with known answers. If wrong: the test below must measure freshness, not fabrication.

**Alternative considered.** Add only warnings such as "do not invent facts". It loses because wording swings results by large margins in both directions [2], and a warning supplies no source to quote. Prompt-only remains the backup when sources are impossible.

# End

**Step 1. I recommend that we add sources before the model answers.**
- Increment: attach your documents, database results, or pasted source text to each task. Fits one session.
- Blocker: removes the largest blocker, which is the model forced to guess with no source [3].
- Test (write it first). Metric: fabricated-claim rate. Baseline: answers today with no sources. Threshold: below 5% fabricated claims. Sample size: 50 questions.
- Cynefin: Complicated. Published results pick the practice [3], and the local trial confirms it for your data.

**Step 2. I recommend that we adopt the quote-or-refuse prompt above.**
- Increment: paste the prompt block into the system prompt. Fits one session.
- Blocker: adds a required citation or an explicit "I do not know", so a guess cannot pass unnoticed.
- Test. Metric: fabricated-claim rate and refusal rate. Baseline: Step 1 output. Threshold: fabrication below 5%, and refusal on at least 90% of 20 unanswerable questions. Sample size: 50 questions. Budget: one session. Stop condition: if the rate does not drop, delete the extra wording and keep the sources.
- Cynefin: Complex. The effect appears only after trials, and wording alone can swing results [2]. Run it as a capped probe, not a commitment. This step MUST run after Step 1, because the prompt cites the sources added there.

**Step 3. I recommend that we add a verification pass in parallel with Step 2.**
- Increment: send each draft answer back with "list every claim that lacks a citation in the sources". Fits one session.
- Blocker: catches unsupported claims that pass the first pass.
- Test. Metric: share of planted errors caught before delivery. Baseline: 0%, because no check exists today. Threshold: at least 80% caught on a 20-question set with planted errors.
- Cynefin: Complex. A model checking its own output misses some errors, and the trial sets the true rate [judgment]. Run it in parallel with Step 2, each capped by its test budget.

The chance that any prompt alone removes all fabrication is very unlikely (0 to 10%) [1]. Treat every uncited claim as unverified, and the residual error is manageable [judgment].
