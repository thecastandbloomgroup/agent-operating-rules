## Headline

Freeze all external statements today, verify the factual record within one day, then agree one stance through one channel.

1. Stabilise first, because a three-channel conflict makes every statement unpredictable [1].
2. Verify the claim against the record before any response, so no second false statement is issued [judgment].
3. Decide the stance from the verified record, not from channel pressure [1].

## Background

A journalist reports that the CEO's statement from yesterday is false. Legal, PR, and the board now message the owner of this question with different advice. No aligned response exists.

## Relevance

The next message from anyone on the team becomes public record. An unverified denial can create a second false statement under the same headline.

## Information

**Evidence.** The decision domain is Chaotic: cause and effect between statements and outcomes are not visible yet, so the first duty is to stop the churn and stabilise [1]. After stabilisation, the case moves through analysis of documents, which is the Complicated domain [1]. No conversation material contains the statement text, the article text, or the source documents that prove either side, so all stance advice at this point is unverified [judgment].

**Assumption log.**

- Assumption: the journalist's claim has a factual basis. Why not measured: the article text is not in the material. Validate by: a claim-by-claim check of the article against the source documents. If wrong: pivot to a correction demand to the outlet.
- Assumption: the statement was public and was recorded in full. Why not measured: no transcript is in the material. Validate by: pull the transcript, video, or filing from the communications archive. If wrong: the correct response includes completing a full public transcript first.
- Assumption: no regulator, exchange, or court is already engaged. Why not measured: the user has not answered. Validate by: a 15-minute check with legal this morning. If wrong: add a legal hold step before any public response.

**Alternative considered.** Respond immediately with denial before verification. It loses because a denial contradicts nothing and risks a second false statement if the record supports the journalist [judgment].

## End

I recommend that we take four actions in this order.

1. **Issue a statement hold today.** Increment: one notice that names a single spokesperson and directs legal, PR, and the board to route every external message through that person. This removes the blocker of three unaligned channels. Test (deterministic), written before the notice:
   - Given a media inquiry reaches legal, PR, or the board,
   - When any member responds,
   - Then the response contains only a referral to the named spokesperson.
   Domain: Chaotic, because no pattern between statements and outcomes exists yet, so the action is stabilize-first [1].

2. **Build the claim table within one day.** Increment: a table that lists each claim in the article beside the matching claim in the CEO statement, with a document reference for each. Step 1 MUST finish before this step starts, because a frozen channel limits new exposure while the table is built. This adds the capability to answer "who is right" with documents instead of opinions. Test (deterministic), written before the review:
   - Given the article text and the full statement record,
   - When each article claim is compared against the source documents,
   - Then each claim is marked "supported" or "not supported" with one document reference.
   Domain: Complicated, because deduction from documents settles the factual question [1].

3. **Choose the stance with a decision matrix on day two.** Increment: a scored choice among four options: correct only, correct plus apology, clarify without correction, no comment. Step 3 MUST NOT start until the claim table in Step 2 is complete. Rubric (written before scoring): criteria and weights are factual accuracy 0.4, legal exposure 0.3, stakeholder trust 0.2, timing 0.1, all on a 1 to 5 scale [judgment]. Pass threshold: the winning option scores at least 3.5 weighted, and no criterion scores 1. Evidence each criterion needs: the claim table for accuracy, legal's written view for exposure, and board member statements for trust. Domain: Complicated, because the verified record determines the option through analysis with the Kepner-Tregoe method [2].

4. **Run a 72-hour coverage probe in parallel from today.** Increment: two people check all new published coverage every 12 hours. Metric: count of new inaccurate statements in coverage per day. Baseline: 1, the current article. Pass threshold: 0 new inaccurate statements in any 24-hour window. Sample size: all published coverage in the window. Stop condition: if coverage grows to a second outlet or the count rises, escalate to a board-level statement within 12 hours. Domain: Complex, because cause and effect between our response and coverage are visible only afterward, so this runs as a capped probe and does not commit the full response [1].

## Follow-up

Conditions that change the recommendation:

- If the claim table shows the statement was true, replace Step 3 with a documented correction demand to the outlet.
- If a regulator, exchange, or court is engaged, add a legal hold step before Step 3 and give legal veto power in the matrix.
- If no full transcript exists, add a Step 2a to complete the record before stance choice.
