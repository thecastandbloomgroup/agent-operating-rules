## Headline

No prompt can stop hallucination; a prompt can only cut its rate [1]. The best prompt does three things: it limits answers to supplied material, it demands a quote for each claim, and it orders an exact "I do not know" when the material runs out.

1. Hallucination comes from how the model was trained and sampled, so prompt text alone cannot remove it [2].
2. A three-rule prompt cuts fake facts more than warning text alone refrains from guessing when the model sees no source.
3. You must test the prompt with a known-answer question set, because the gain varys by model and task [2].

## Background

You asked for one prompt that stops a model from inventing facts. This is a chat with no attached documents, no tools, and no named model.

## Relevance

Fake facts in answers cost you later review work. A short prompt plus a test gives a measurable change within one session.

## Information

**Evidence.**

1. Hallucination is a known failure mode of language models, not a prompt bug. A survey lists its causes in training data, decoding, and knowledge limits [1] [S].
2. Analysis from OpenAI states that models keep hallucinating because training rewards guessing over abstaining. This makes prompt-only removal unlikely, so abstention instructions act as a patch, not a cure [2] [S].
3. A prompt that demands quotes from named material works because it converts "is this claim plausible" into "is this claim present in the source", which the model can check at inference time [judgment].
4. The gain in error rate cannot be predicted before a test. Reported reductions from instruction changes range widely across models, so measure on your own model [inference].

**Prompt.** Use this text as system instructions, or as the first message:

```text
Answer only with facts that appear in this conversation.
For each factual claim, name the message or section you use as source.
If the material does not contain the answer, write exactly: I do not know.
Do not guess. Do not invent names, numbers, or references.
```

**Assumption log.**

- `Assumption: you control system instructions, not only chat replies. Why not measured: the request does not state it. Validate by: try the prompt in a system slot; if you cannot, put it first in each chat. If wrong: the cut in error rate shrinks, because user-turn text carries less weight than system text.`
- `Assumption: you have no retrieval tools and no source documents to attach. Why not measured: the request names none. Validate by: check whether your interface allows file upload or web search. If wrong: replace rule 1 in the prompt with "answer only from the attached file", and the error rate drops more.`

**Alternative considered.** Retrieval-augmented answers and fine-tuning on abstention data beat a prompt on error rate [1] [S]. They lose here because they need tools, data, and cost beyond what one prompt request implies.

## End

I recommend that we install the three-rule prompt, then measure it. Steps in order:

1. **Add the prompt block above to the system instructions.** This removes silent guessing, the largest blocker. Test, deterministic, Clear domain, because the rule and its effect are known: 
   ```
   Given a question that the conversation does not answer
   When the model replies
   Then the reply contains the exact string "I do not know"
   ```
2. **Add a quote rule per claim: each factual claim names its source message.** This adds a capability: you can check every claim by hand. Test, deterministic, Complicated domain, because analysis of past replies picks the wording, and the check is a deduction from one rule: 
   ```
   Given a reply with a factual claim
   When a reviewer matches the named source
   Then the quote appears in that source message
   ```
3. **Build a 50-question set with known answers, half answerable and half outside the material.** This measures the gain; the rate is unknown before the run, which is what could break the pattern. Test, stochastic, Complex domain, because the effect shows only after the run: the metric is the error count, the baseline is the model's score without the prompt, the pass threshold is at least a 50 percent lower error count, the sample size is 50 questions, and the stop condition for tuning is two failed rounds at the 2 hour budget. Step 3 MUST NOT start until the test in Step 2 passes.
4. **Keep the abstention rule when you change models.** This protects the pattern against drift. Test, deterministic, Clear domain, because checking for the exact string is one step: run the test in Step 1 on the new model before regular use.
