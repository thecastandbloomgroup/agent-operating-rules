Yes, turn on gzip for these responses. JSON of this size compresses to roughly 20 to 30 percent of its original size, so a 400 KB response drops to about 80 to 120 KB. The server CPU cost is small, and most HTTP clients send "Accept-Encoding: gzip" by default [judgment].

**Why it matters now**

A 400 KB body is 3.2 Mbit. At 50 Mbit/s it takes 64 ms on the wire alone. Compressed to 80 KB, it takes 13 ms [inference]. So the average response gets faster by roughly 50 ms per call, before any queueing or mobile-network effects. Compression is a one-line config change in most servers and proxies.
