## Information

### Define what “wrong” means

Use these review labels. A summary can receive several labels, but each label describes a separate failure. [judgment]

| Label | Definition |
|---|---|
| Unsupported claim | The conversation does not support a statement. |
| Contradiction | A statement conflicts with the conversation. |
| Material omission | The summary excludes information needed for the next support action. |
| Usefulness problem | The facts pass review, but the summary does not help the agent. |

Mark an error **severe** when it changes a payment, security, account-access, or resolution decision. These are proposed review criteria, not measured findings. [judgment]

Record the ticket, source messages, model version, prompt version, summary, labels, and reviewer correction. This creates evidence for each reported error. [judgment]

### Measure three outcomes

1. **Factual failure rate:** summaries with an unsupported claim or contradiction, divided by summaries reviewed.
2. **Material omission rate:** summaries with a material omission, divided by summaries reviewed.
3. **Usable unchanged rate:** summaries an agent accepts without correction, divided by summaries reviewed.

Track severe errors separately. Otherwise, one small wording error and one false refund commitment receive the same weight. [judgment]
