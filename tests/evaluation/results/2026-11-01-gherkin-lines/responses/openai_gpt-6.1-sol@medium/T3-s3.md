## Relevance

The request does not define which session behaviors must survive the migration. It also lacks a conversion baseline, so success needs a measurable definition.

## Information

A JSON Web Token (JWT) is a format for claims between parties, not a complete auth design. [2] Therefore, choosing JWT alone does not define token storage, logout, renewal, or access removal. [judgment]

The first review should cover two separate areas:

- **Auth:** clients, session checks, permissions, token storage, expiry, renewal, logout, and account access removal.
- **Sign-up:** funnel steps, completion rate, validation errors, verification delivery, and time to completion.

These are review targets, not findings about the service.
