Headline
Adopt one formatter for Structured Query Language (SQL) and stop format disputes in review.
- One shared style removes the repeated dispute over layout.
- A machine check applies that style on every change.
- Reviewers then spend time on query logic only.
- A short trial shows whether people bypass the check.

Background
The team does not share one SQL format. The split appears in every review. The request is to fix that culture problem.

Relevance
Each review repeats the same format comments. A shared check removes that repeat before the next cycle.
