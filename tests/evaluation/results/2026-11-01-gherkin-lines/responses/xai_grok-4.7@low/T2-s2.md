Headline
No prompt can stop invented facts.
First, allow an answer only when a given source states the fact.
Second, tie each claim to a citation or to Unknown.
Third, delete any claim that fails a support check.
Fourth, add retrieval, because a prompt cannot supply missing facts.

Background
Language models produce fluent text even when they lack a fact.
Hallucination means a fluent claim that the source does not support.
The request asks for one prompt that stops this behavior.
A prompt can change what the model emits.
It cannot add knowledge that the model does not have.

Relevance
Unsupported answers waste review time and can spread false claims.
A tight prompt cuts those answers before a reader sees them.

Information
This section covers the evidence, the assumptions, and the alternative.

Surveys define hallucination as text that is unfaithful to a source or to known facts.
This definition comes from a survey, so the source is tertiary.
[1]

Chain-of-Verification drafts an answer, checks it, and then revises it.
The authors report fewer hallucinations on their test tasks.
[2]

Retrieval-augmented generation means the model reads fetched text before it answers.
Lewis and others report better results on knowledge-heavy tasks than generation without retrieval.
[3]

A line that only says "do not hallucinate" gives the model no test it can apply.
[judgment]

Therefore the strongest instruction combines a refusal to guess, a citation, and a check.
It does not replace retrieval.
[inference]

A1. The user wants one reusable instruction, not a search pipeline. Why not measured: the material does not state it. Validate by: confirm whether a tool can fetch sources. If wrong: run retrieval before the instruction.

A2. The product accepts a system message. Why not measured: the material does not state the product. Validate by: open the system-message field. If wrong: paste the same text at the top of the user message.

A3. The product has a randomness control. Why not measured: the material does not state the product. Validate by: open the model settings. If wrong: skip Step 4.

The strongest alternative is the line "Never hallucinate."
It loses because it has no refusal rule, no citation rule, and no check.
[judgment]

Use only facts from sources in this chat or from tool results.
If a needed fact is absent, answer Unknown.
Do not fill a gap from memory.
After each claim, name the source.
Quote the line that supports that claim.
Delete a claim when you cannot quote support.
Before the final answer, mark each claim Supported or Unknown.
Send Supported claims only.
Also send Unknown when the user asked for that fact.
Do not invent names, numbers, dates, or citations.
