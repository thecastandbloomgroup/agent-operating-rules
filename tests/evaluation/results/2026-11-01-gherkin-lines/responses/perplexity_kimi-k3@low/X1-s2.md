## Headline

Turn "sometimes wrong" into a measured error rate, then fix the largest error class first. First, build a 100-summary sample with human ratings to get a baseline. Second, classify the errors into non-overlapping types. Third, fix the top error type with a targeted change and re-measure.

## Background

The support tool uses an LLM summariser. Agents report it is sometimes wrong. There is no metric, no error log, and no definition of "wrong". The request is to improve it.

## Relevance

Without a baseline, changes cannot be shown to help. A small sample converts anecdote into a number and ranks the fixes by effect. This avoids spending effort on rare error types.

**Assumptions.**
