## Headline

No single prompt stops hallucination, but the strongest one forces the model to cite evidence or say "unknown" for every claim. Prompts reduce the rate, not remove it, because hallucination comes from how models generate text, not from instructions alone [inference]. Combining the prompt below with retrieval of source documents cuts errors far more than any prompt alone [judgment].

## Background

The request is for one prompt that prevents a language model from inventing facts. The answer must reflect what prompts can and cannot change about model behavior.

## Relevance

Hallucinated content causes real harm when it enters decisions or documents. A prompt that costs nothing and reduces false claims has immediate value.

## Information

Evidence on prompt effects is limited. No retrieved studies are in this session, so the claims here rest on judgment about known model behavior [inference].

**The recommended prompt:**

"Answer only from information you can verify. For each factual claim, state the source or write 'unknown, needs checking'. If you do not know, say so. Do not guess numbers, dates, names, or citations."

**Why this wording:**
1. "Say so if you do not know" gives the model a permitted exit, which reduces confabulation [judgment].
2. "State the source" forces a checkable artifact per claim [judgment].
3. "Do not guess numbers, dates, names, or citations" targets the claim types where invented content is most frequent [judgment].

**A1. The user asks a general model, not a specific deployed system.** Why not measured: the material does not state it. Validate by: asking which model. If wrong: the prompt still applies, since it is model-neutral.

**Alternative considered:** "Think step by step" style prompts. They help arithmetic and logic, but they do not stop invented facts, so they lose for this goal [judgment].

## End

I recommend that we:

1. Adopt the prompt above as a system or first user message. Increment: paste it in one session. Blocker removed: unbounded guessing. Test (deterministic):
   - Given a question outside the model's reliable knowledge,
   - When the model answers with this prompt active,
   - Then the answer contains "unknown, needs checking" rather than an invented specific claim. Cynefin: Clear, because the practice is a known best practice.
2. Add source material when accuracy matters. Increment: attach the relevant document to the same session. Blocker removed: the model must answer from memory. Test (deterministic):
   - Given a question answerable from the attached document,
   - When the model answers,
   - Then each claim traces to a passage in that document. Cynefin: Clear, because retrieval grounding is a known practice.
3. Verify every citation the model produces. Increment: check the citations in one output. Blocker removed: fabricated references pass unnoticed. Test (evaluative): rubric criteria are existence (weight 0.5) and correct content match (weight 0.5); pass threshold is 100% of citations exist. Cynefin: Complicated, because checking requires looking up each source.
