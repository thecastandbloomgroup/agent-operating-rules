## Headline

No prompt stops hallucination; a verified source-plus-citation prompt reduces it, so the best prompt asks the model to answer only from given sources and to say "I do not know" otherwise.

- Prompts shape behavior but cannot remove hallucination, because the model always generates probable text.
- The strongest prompt combines a knowledge limit, a citation demand, and an exit rule for unknowns.
- Retrieval and output checks cut errors more than wording alone [judgment].

## Background

The request asks for one prompt that makes a language model stop hallucinating. Hallucination means the model states false content with apparent confidence.

## Relevance

A direct answer saves the reader trial and error. A wrong expectation about prompts leads to false trust in output.

## Information

No prompt eliminates hallucination, because generation is probabilistic and models cannot verify truth internally [1].

High confidence, consistent finding across technical literature.

Recommended prompt text:

> Answer only from the sources below. Cite the source for every factual claim, with a quote. If the sources do not contain the answer, reply exactly: "I do not have enough information." Do not guess, and do not use outside knowledge.
> Sources: [paste text here]
> Question: [question here]

This works because it sets a knowledge boundary, forces traceability, and gives a defined fallback. Without provided sources, add: "State 'uncertain' after any claim you cannot verify." That version is weaker, because self-reported uncertainty is unreliable.

**A1.** The reader uses a general-purpose chat model without retrieval tools. Why not measured: the material does not state it. Validate by: ask the setup once. If wrong: add a retrieval step before prompting.

**A2.** The task is factual question answering, not creative work. Why not measured: the material does not state it. Validate by: check the first real use. If wrong: relax the "sources only" rule.

**Alternative considered:** using sampling settings, such as temperature near zero, instead of prompt wording. It loses alone because low randomness still produces confident wrong facts; combine both for the best result [judgment].

## End

I recommend that we take these actions:

1. Test the source-based prompt on 10 real questions that have known answers. This removes the blocker of unverified trust. Deterministic test:
   - Given the prompt and sources for 10 questions,
   - When the model answers each,
   - Then every answer cites a source or returns the fallback line. Cynefin domain: Clear, because the practice is established and repeatable.
2. Set temperature to 0 to 0.3 for factual use. This adds output stability. Deterministic test: Given one fixed question, when it runs 5 times, then answers are identical. Cynefin domain: Clear, because best practice is known.
3. Compare the prompted output with the unprompted baseline on the same 10 questions, and measure supported claims per answer. Evaluative rubric: criteria are factual support (weight 60%) and citation coverage (weight 40%); pass threshold is 9 of 10 answers fully supported. Cynefin domain: Complicated, because analysis of results picks the final setup.

Step 3 MUST NOT start until Step 1 passes.

## Follow-up

If answers stay inaccurate after Step 3, add retrieval of documents first and restrict the model to those documents. Confidence: high that this prompt reduces hallucination; zero probability that it eliminates it.
