# Headline
No prompt can stop hallucination by itself; use a constrained prompt plus an output check.

- Restrict answers to given sources or retrieved evidence.
- Require an “insufficient evidence” reply when support is absent.
- Measure failures on a fixed sample before and after changes.

# Background
The request asks for one prompt that makes a model stop inventing facts. The usable answer is a prompt pattern, not a guarantee.

# Relevance
This matters now because wording alone cannot verify facts. The gain comes from forcing source use and refusals.

# Information
Evidence: source restriction and explicit refusal reduce unsupported output [judgment].  
Evidence: measurement is required because prompt effects vary by task and model [judgment].

A1. The model can access or receive reliable sources. Why not measured: the material does not state it. Validate by: run ten known-answer questions. If wrong: add retrieval or lower confidence.

Alternative considered: a longer “be accurate” prompt loses because it adds instruction text but no evidence gate [judgment].

Copyable prompt:
```text
Answer only from the provided sources. Quote the exact supporting lines. If the sources do not contain the answer, state: "insufficient evidence". Do not use outside knowledge. Do not guess. End with "Sources used:" followed by source names, or "none".
```

# End
I recommend that we adopt these steps.

1. Deterministic, Clear: add the prompt template to one workflow. Blocker removed: unsupported answers. Write this check first:  
Given two source notes,  
When the answer is absent,  
Then output exactly "insufficient evidence".  
Cause and effect are known for the template change.

2. Stochastic, Complicated: run 50 fixed questions with known sources. Blocker removed: unknown baseline. Write the acceptance test first: metric is unsupported-claim rate; baseline is last run; pass is 30% relative reduction; sample size is 50. Analysis: compare before and after rates by task type.

3. Evaluative, Complex probe: test retrieval on 10 hard questions within one session. Blocker removed: missing evidence. Budget: one hour. Stop if fewer than six retrieved items are relevant. Measure: relevant sources per answer; pass threshold is eight of ten.
