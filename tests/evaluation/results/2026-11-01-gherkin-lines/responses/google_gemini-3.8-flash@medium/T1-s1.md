### Headline

We will remove SQL style disputes by adopting an automated SQL formatter in the code review pipeline.
Automated formatting removes subjective judgment from pull request reviews.
An agreed configuration file defines one standard style for all SQL files.

### Background

The team lacks an agreed standard for SQL code formatting.
Engineers debate styling choices during every code review.
This ongoing debate creates friction and slows down pull request approvals.

### Relevance

Subjective style debates consume engineering time and harm collaboration today.
Therefore, an automated rule set resolves the dispute without ongoing personal debate.
