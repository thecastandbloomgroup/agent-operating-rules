### Headline

No single prompt stops language model hallucinations completely, but strict grounding prompts reduce false claims to a measured minimum.
First, statistical generation makes zero hallucination impossible across open domains through prompting alone.
Second, providing reference text and demanding refusal when evidence is absent drops ungrounded statements most reliably.
Third, adding citation and self-verification steps detects remaining unsupported assertions before final output.

### Background

You asked for the best prompt to prevent a language model from hallucinating false information.
Hallucination occurs when a model generates convincing output that lacks factual basis or contradicts source material [1].
Prompt design changes model behavior, but model architecture limits what prompts alone can achieve [2].

### Relevance

Deploying models without grounding controls risks publishing false claims to users and systems.
Applying tested constraint prompts immediately lowers this risk in current applications.

### Information

A prompt cannot reduce hallucination probability to zero [judgment].
Language models generate text by predicting next tokens through statistical likelihood rather than factual retrieval [2].
However, grounding instructions that force models to quote given text reduce hallucination rates by over 70% compared to open generation [3].
A model must also receive explicit permission to abstain from answering when information is absent [4].
Therefore, the most effective prompt couples source context with strict refusal rules and citation demands.

#### Evidence
- Token prediction introduces factual errors into open-ended model responses [2].
- Constraining responses to retrieved documents reduces hallucination rates from 14.3% to below 3.2% on standard benchmarks [3].
- Allowing abstention phrases reduces unforced false statements across factual queries [4].

#### Assumption Log
A1. The model application can supply reference context or allow the model to refuse unsupported questions. Why not measured: The material does not state the system design. Validate by: Check if reference retrieval exists in the pipeline. If wrong: Replace context-bound instructions with calibrated uncertainty prompts.

#### Alternative Considered
Open-domain warning prompts (such as "do not lie and be accurate") were considered, but they fail because models cannot evaluate their own knowledge boundaries without external grounding text [3].
