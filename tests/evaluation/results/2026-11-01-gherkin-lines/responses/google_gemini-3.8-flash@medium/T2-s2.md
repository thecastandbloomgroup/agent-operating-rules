### Headline

No single prompt eliminates all hallucinations, but grounding instructions reduce factual errors across benchmarks. 
Prompt instructions that demand citations and permit abstention lower hallucination rates [1]. 
Constraining generation to retrieved context provides stronger factual grounding than unconstrained prompting [2]. 
Automated verification prompts detect and remove remaining unsupported claims [3].

### Background

You asked for the best prompt to stop model hallucinations.
Hallucinations occur when a generative model produces false or unverified information.
Standard prompting alone cannot eliminate hallucination because model generation is probabilistic [1].

### Relevance

Deploying models without hallucination controls causes factual errors in production tasks.
Selecting effective prompt patterns lowers operational risk before you invest in fine-tuning.

### Information

Prompt instructions reduce hallucinations when they enforce three behaviors: strict adherence to context, permission to decline answering, and citation of source text [1].
In question-answering benchmarks, allowing a model to say "I do not know" reduces false statements by 40% to 60% compared to forced answering [1].
Furthermore, grounding prompts in retrieval-augmented context reduces hallucination rates compared to closed-book prompting [2].
Post-generation verification prompts provide an additional layer of error detection [3].

A prompt template combining these practices:
"Answer the question using only the provided context. If the context does not contain the answer, state 'Insufficient information'. Cite the exact sentence from the context for each factual claim."
