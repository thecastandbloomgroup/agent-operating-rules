## Headline

No prompt stops hallucination, but a grounding prompt with a refusal rule cuts it most.

- Hallucination means the model states something that no source or fact supports.
- The prompt below forces answers to come from supplied text and allows "not found".
- A prompt alone does not prove the result, so a test on your own questions is required.

```text
Answer only from the sources between <sources> tags.
For each claim, quote the supporting sentence.
If the sources do not answer the question, write: "Not found in the sources."
Do not use outside knowledge. Do not guess.
After the answer, list each claim that has no quote.
```

## Background

You asked for one prompt that stops a model from inventing facts. Models produce fluent text, even when they lack the facts [1]. Prompts change that behavior in part, not in full.

## Relevance

A false answer that reads well is hard to detect. It costs you more when you act on it without a check.

## Information

**Evidence**

- Hallucination appears across many tasks and model types [1].
- Retrieval of source text before generation made output more factual in the original retrieval-augmented generation (RAG) work [2].
- Asking the model to write and answer check questions about its draft reduced false claims [3].
- A prompt removes all hallucination: 5% likely. [judgment]
- A prompt with sources and a refusal rule lowers the rate: likely (66 to 100%). Moderate confidence: three secondary sources, no measurement on your model.

**Assumption log**

A1. You use a chat model that accepts pasted text. Why not measured: the material does not state it. Validate by: paste a short source and run the prompt. If wrong: use a tool with file or search access.

A2. Your questions are factual, not creative. Why not measured: the user has not answered. Validate by: list five typical questions. If wrong: drop the refusal rule for creative tasks.

**Alternative considered**

The alternative is a short rule such as "do not make things up". It loses because it gives the model no source to rely on and no output to check. [judgment]
