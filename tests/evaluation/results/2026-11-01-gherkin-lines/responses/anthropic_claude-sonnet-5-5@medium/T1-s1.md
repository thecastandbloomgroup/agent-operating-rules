## Headline

Replace the style debate with one team-chosen formatter, enforced by automation, because the friction comes from an unmade decision and manual enforcement.

- The team has no agreed standard, so each review reopens the argument.
- A tool can apply a standard in seconds, so reviewers do not need to enforce it.
- A time-boxed decision with a default ends the debate and stops it from returning.
- A measured trial shows whether the friction drops.

## Background

The team formats SQL in different ways. Each review includes arguments about style. The request is to end this friction.

## Relevance

Style comments take review time from logic and correctness. They also create personal conflict, so the friction grows with each review.
