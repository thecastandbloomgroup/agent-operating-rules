## Headline

No prompt stops hallucination fully, but the prompt below cuts it most when you also supply source text.

- A prompt that limits answers to supplied sources and allows "the sources do not say" removes the pressure to guess.
- A claim-level source check catches errors the first answer leaves in.
- Measurement beats trust, because the effect varies by model and task.

## Background

You asked for one prompt that stops a model from inventing facts. Hallucination means fluent output that is false or unsupported by the input [1]. The prompt text is in Section End, Step 2.

## Relevance

A wrong answer that looks right costs you a decision or a correction later. A tested prompt gives you a known error rate instead of a guess.

## Information

**Evidence**

- Hallucination is a documented, general problem in text generation, so no prompt removes it [1]. This source is secondary.
- Models often judge well whether their own answer is true, so asking for a confidence level is useful [2]. This source is secondary.
- Grounding answers in retrieved text lowers invented content in knowledge tasks [3]. This source is secondary.
- A draft, verify, revise loop lowered hallucination in the cited experiments [4]. This source is secondary.

Confidence: the prompt likely (66 to 100%) lowers your error rate. It is very unlikely (0 to 10%) to bring the rate to zero. Basis: four secondary sources agree. No primary measurement on your model exists yet.

## End

I recommend that we take these steps in order:

1. **Build a test set.** Write 50 questions in one session: 30 answerable from your text, 20 not answerable. This removes the blocker that you cannot measure the error rate. Kind: deterministic. Domain: Clear, because the task has a known good practice.

   Given a file of 50 questions with a marked answer or the marker "none"
   When the file is loaded by a script
   Then the script counts 30 answerable and 20 unanswerable questions

2. **Run the prompt as a probe.** Put this text in the system prompt, then run all 50 questions three times each.

   > Answer only from the sources in this conversation. If the sources do not contain the answer, write: "The sources do not say." Do not guess. Do not invent names, numbers, quotes, or links. Quote the exact text that supports each claim. Mark any claim without a quote as [no source]. When you are unsure, state your confidence as a percentage. Before you send, check each claim against the sources. Delete each claim that fails.

   Kind: stochastic. Domain: Complex, because the effect on your model shows only after you run it. Leverage is a guess. Budget: one session, 150 runs. Stop if the rate does not fall.

   Metric: share of answers with an unsupported claim. Baseline: the rate with no prompt, measured on the same 150 runs. Pass: at least a 50% relative drop at 150 runs. Step 3 MUST NOT start until this test passes or you accept the result.

3. **Supply the sources.** Add the relevant document text to each question, by hand or by retrieval. This removes the blocker that the model answers from memory. Kind: stochastic. Domain: Complicated, because an analysis of your document size and format picks the method [3]. Metric: unsupported-claim rate. Baseline: the Step 2 result. Pass: a further 25% relative drop at 150 runs.

4. **Add a verification pass.** Ask the model to list checks on its own answer, answer each check alone, then revise [4]. Cap the trial at one session and 150 runs. Kind: stochastic. Domain: Complex, because the gain varies by task. Run it in parallel with Step 3. Metric and baseline: as in Step 3. Pass: a further 25% relative drop. Keep it only if the extra cost per answer is acceptable to you.

If A2 is false, skip Step 3 and expect more "the sources do not say" replies.
