## Headline

No prompt can make a model stop hallucinating; the prompt below reduces it by grounding every claim in text that you supply [1].

- The reduction comes from two rules: ground in supplied text and refuse when the text has no answer.
- The refusal rule fails without a source to check, so supplying text is the first action.
- No prompt writes hallucination out of the model, because the causes sit in training and decoding [1].
- Therefore, measure the effect on your own task before you trust it.

## Background

The request asks for one prompt that stops invented facts from a language model. Ji et al. define hallucination as generated text that conflicts with the source or with world knowledge [1]. Its causes sit in training objectives, data, and decoding, so prompt text can reduce it but not remove it [1].

## Relevance

A wrong fact that reads as an answer enters your work with no warning. A grounded prompt turns each claim into a checkable quote, so errors become visible.

## Information

### Evidence

- Hallucination arises from training decisions, data gaps, and generation processes, and mitigation methods therefore act around these causes rather than at them [1].
- Suppressing insecure generation patterns is one listed mitigation family, and its effects need per-task evaluation [1].
- Grounding plus refusal reduces fabrication on a given task: [judgment], based on the design logic that every claim must point to a checkable sentence.

### The prompt

```text
Answer only from the SOURCE text below.
For every claim, copy the supporting sentence from the SOURCE in quotation marks.
If the SOURCE does not contain the answer, write exactly: "Not in the SOURCE."
Do not add facts that the SOURCE does not state.
Before you answer, compare each sentence with the SOURCE and delete the sentences that fail the comparison.
SOURCE: <paste your text here>
```

### Assumption log

- A1. The setup is prompt-level, with no fine-tuning and no change to retrieval. Why not measured: the user has not answered. Validate by: read the product or API settings. If wrong: a retrieval step replaces Step 1 as the first fix [judgment].
- A2. The task is question answering over text the user can supply. Why not measured: the user has not answered. Validate by: one reply from the user. If wrong: a task with its field has no SOURCE, so the refusal rule does not apply.

### Alternative considered

A prompt that asks the model to print a confidence score per sentence. It loses because such scores are not calibrated measures; they add a failure mode without removing fabrication [judgment].
