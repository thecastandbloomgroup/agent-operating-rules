## Headline

Enforce one SQL formatter with a committed config, and ban style comments in review. The debate then loses its cause, because a tool applies the same rules on every file. This removes the friction without a culture campaign.

## Background

The team debates SQL format in every code review. The request is to remove this friction. Formatting is a mechanical task, so a tool can apply one rule set every time [1].

## Relevance
