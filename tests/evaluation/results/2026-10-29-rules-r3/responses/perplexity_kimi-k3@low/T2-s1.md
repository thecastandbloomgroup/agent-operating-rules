## Headline
Use a source-bound prompt that forces quotation, citation, and explicit insufficient-evidence replies; it reduces hallucination but does not remove it.

- No prompt can guarantee zero hallucination [inference].
- The strongest prompt limits claims to supplied sources and requires evidence for each claim [judgment].
- Human verification or retrieval is still needed for high-risk facts [judgment].

## Background
You want one prompt that makes a model stop inventing facts. The practical target is lower hallucination rate, not perfect truth.

## Relevance
This matters because fluent false claims can pass review unless the output exposes its evidence. A source-bound format makes unsupported claims easier to catch.

## Information
Copyable prompt:

```text
Answer only from the sources provided below.
If the sources do not contain the answer, say: "Insufficient evidence."
For every factual claim, include:
1. the claim,
2. an exact quote from the source,
3. the source name and section or line.
Do not invent names, dates, numbers, citations, URLs, APIs, or quotations.
If a claim is uncertain, label it "uncertain" and state what evidence would resolve it.
Before the final answer, list every claim without a quote and delete it.

Sources:
[paste sources here]
```
