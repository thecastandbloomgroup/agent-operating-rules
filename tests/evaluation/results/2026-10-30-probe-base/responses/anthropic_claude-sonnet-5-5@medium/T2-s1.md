## Headline

No single prompt stops hallucination, but a prompt that limits the model to supplied sources and permits "I don't know" lowers it most.

- A model invents facts when it has no source and no permission to decline.
- A grounding prompt fixes both gaps at low cost.
- A test set tells you whether the prompt works for your task.
- Retrieval and a verification pass add protection that a prompt cannot give.

## Background

You ask for one prompt that stops the model from stating false facts. Hallucination means output that is fluent but unsupported by fact or by the given source. The cause sits in how the model works, so a prompt can reduce the problem but cannot remove it.

## Relevance

You will likely use the output for decisions or for work shared with others. A false claim in that output costs more than a refusal does.

The prompt (replace the brackets):

```text

Do not use outside knowledge.
After each claim, quote the SOURCE text that supports it.

Do not guess names, numbers, dates, or citations.
```
