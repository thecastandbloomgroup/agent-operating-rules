### Headline

No prompt completely stops hallucinations, but a grounded context-refusal prompt reduces factual errors to the lowest observed baseline.
First, generative language models sample probability distributions, so prompt phrasing alone cannot reduce hallucination frequency to zero percent.
Second, restricting generation to supplied reference documents with a mandatory refusal rule suppresses ungrounded assertions.
Third, combining this grounded prompt with validation checks detects residual fabrications before deployment.

### Background

The user asks for a prompt that prevents a language model from hallucinating factual claims. Hallucination occurs when an autoregressive system generates statements that contradict real-world facts or source materials [19]. Because transformer models predict token sequences probabilistically, prompt text alone cannot guarantee full factual precision [19].

### Relevance

Relying on prompt text alone exposes downstream systems to silent factual errors. You need an evidence-based prompt template and verification controls to mitigate this operational risk.

### Information

A prompt cannot eliminate hallucinations entirely because models lack an internal truth function [19]. However, grounding the prompt against supplied source text decreases error rates substantially [20]. 

For example, instructing the model to declare missing information reduces fabrications compared to open-ended generation [judgment]. The prompt must force the model to cite given text directly.

Use this prompt template for grounded tasks:
"You are a factual assistant. Answer the question using only the provided context below. If the context does not contain the answer, state 'Information not found.' Do not use external knowledge or assume facts not directly stated."
