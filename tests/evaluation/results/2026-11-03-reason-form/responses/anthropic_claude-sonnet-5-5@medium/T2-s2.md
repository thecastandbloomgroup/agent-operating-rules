## Headline

Use the prompt in the Information section, but expect fewer hallucinations, not zero.

- The prompt lets the model say "Not known" instead of guessing.
- It forces each claim to point to a source line.
- It asks the model to list claims it could not support.
- Grounding in real documents works better than any wording alone.

## Background

The request is for one prompt that stops a language model from stating false facts. This failure is called hallucination: fluent output that is not supported by facts or sources. Research treats it as a built-in limit of text generation, not a bug that one prompt removes [1].

## Relevance

A false name, number, or quote that looks correct can cause wrong decisions. A tested prompt lowers that risk at no cost.

## Information

**The prompt** (paste it as the system message or at the top of the chat):

```text
Answer only from the sources provided in this chat or from facts you know with high confidence.
If a fact is not in the sources and you are not sure, write "Not known".
Do not guess names, numbers, dates, quotes, or links.
Quote the source line behind each claim.
After the answer, list each claim you could not support.
Give a confidence level (high, medium, low) for each claim.
```

**Evidence**

- Hallucination is a documented, general problem across text generation tasks, so no wording gives a guarantee. High confidence, one survey of the field [1].
- Large models judge the truth of their own answers better than chance when asked to do so. This supports the "confidence level" line. Medium confidence, one study [2].

- A draft, check, and revise loop lowered false statements in tests. This supports the unsupported-claim list. Medium confidence, one study [3].

- Giving the model retrieved documents improved factual output on knowledge tasks. This supports the "only from sources" line. Medium confidence, one study [4].
- The exact effect size of this prompt on your model is unknown. [no source]

**Alternative considered**

Fine-tuning or a retrieval system instead of a prompt. It loses because it costs days of work, not minutes [judgment].
