## Headline

No single prompt stops hallucination, but a grounding prompt cuts it, and you can measure the cut.

- Hallucination is a known property of language models, so the target is fewer false claims, not zero [1].
- The best prompt restricts the model to supplied sources, requires quotes, and allows the answer "the sources do not say".
- Retrieval and a verification pass add more protection than wording alone [3].
- A small test set shows whether the prompt works for your task.

## Background

You asked for the best prompt to stop a model from stating false facts. The request gives no task, model, or source material. This answer therefore gives a general prompt and a way to test it.

## Relevance

A false claim that looks confident costs you time or trust. A tested prompt tells you if the fix works before you rely on it.

## Information

**Why no prompt reaches zero.** A model that predicts text well must still produce some false statements about rare facts. Kalai and Vempala prove this for calibrated models:

[2]

The survey of hallucination types supports the same point:

[1]

Confidence: high, two independent peer-reviewed sources.

**What reduces it.** Retrieval gives the model real text to use:

[3]

A second pass that checks each claim lowers false claims further:

[4]

**The prompt.** Put your source text after it.

```text
Answer only from the SOURCES below.
1. First, quote the exact sentences that support your answer.
2. Write the answer using only those quotes. Mark each claim with its quote number.
3. If the quotes do not answer the question, write: "The sources do not say."
4. Do not use outside knowledge. Do not guess names, numbers, dates, or links.
5. End with your confidence as a percentage.
```

The quote-first order is my design choice, not a result from a cited source. [judgment]

**Assumption log**

A1. You can supply source text for the task. Why not measured: the material does not state it. Validate by: check if your questions have a document behind them. If wrong: Step 4 moves first, and retrieval replaces the source block.

A2. The goal is fewer false claims, not zero. Why not measured: the user has not answered. Validate by: state the error rate you accept. If wrong: the threshold in Step 3 changes.

A3. A 50% relative drop in unsupported claims is enough. Why not measured: measuring costs more than the decision is worth. Validate by: compare the cost of one error with the cost of one refusal. If wrong: raise or lower the threshold.

**Alternative considered.** Fine-tune the model on correct answers. It loses because it costs more and needs data you have not shown. A prompt test takes one session. [judgment]
