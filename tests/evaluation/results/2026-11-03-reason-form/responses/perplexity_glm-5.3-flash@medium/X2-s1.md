## Headline

Do fewer, owned actions: end each retrospective with exactly one action item, and show it finished at the start of the next one.

1. The meeting fails at follow-through, not at the discussion.
2. One owned item per session beats five unowned items.
3. One team metric next to opinions keeps items honest.
4. Rotate the format as a small probe, not as a redesign.

## Background

The team holds retrospectives. People attend, but no behavior changes afterward. The request asks what to do now.

## Relevance

Each retro that ends without change teaches the team to expect no change. Attendance will likely drop next, and the habit is costly to rebuild once lost.

## Information

**Evidence.** Theme 1, the follow-through gap: two independent secondary sources support it. Derby and Larsen state that a retrospective ends with an actionable plan, and that the plan needs named owners for each item; without them, nothing ships [1]. Accelerate reports that high performers respond to signals with actions that are tracked to done [2]. A source that disagrees with theme 1 did not appear in this session; that is a gap, not a confirmation. Theme 2, routine breeds habituation: Derby and Larsen support it with one source; the retrospective phases and varied facilitation exist to counter it [1]. Theme 2 rests on a single secondary source next to the claim [1].

**Baseline.** The stated baseline is the current state: zero action items completed from the last sessions [judgment, from the request].

**Assumptions.**

A1. Recent retro notes list items without owners or dates. Why not measured: the request does not state it, and no notes are present. Validate by: read the last three retro notes, or ask two attendees. If wrong: the failure is item load or item value, so replace Step 1 with a stall review.

A2. Attendance is present, but honest input is limited. Why not measured: no pulse data exists. Validate by: one anonymous three-question pulse before the next retro. If wrong: drop the format probe in Step 4 and work on safety first.

**Confidence.** Moderate confidence for the diagnosis, based on two secondary sources and a stated baseline. High confidence that the change is cheap to test.

**Alternative considered.** Stop the retrospectives and review only when work blocks. It loses because the team then loses the recurring signal that surfaces small costs early, and rebuild of the habit costs more than the meeting [judgment].

## End

I recommend that we run four actions. Steps 1 and 2 are Clear: the practice is known and leverage is reliable [3].

1. **Carry one item to done.** At the next retrospective, pick the oldest open item, and close the session with exactly one action, one named owner, and one date. This removes the ownership gap, the largest blocker, per A1. Kind: deterministic. Cynefin: Clear, because the rule is known to everyone, so the inference is deduction.

   ```gherkin
   Given a retrospective with participants present
   When the session closes
   Then the notes list one action with one owner and one date
   ```

2. **Review the item before ideas.** Start each retro with the action board for five minutes: the previous item is shown done, moved, or explained. Step 2 MUST NOT start until the item from Step 1 exists. This adds the follow-through loop. Kind: deterministic. Cynefin: Clear, deduction from the same rule.

   ```gherkin
   Given a retrospective that starts
   When the idea phase begins
   Then the previous action is marked done, moved, or explained
   ```

3. **Bring one metric to each retro.** Pick the metric by rubric first: impact on the actual problem, weight 0.5; data available this month, weight 0.3; team trust in the number, weight 0.2. Pass threshold: 3.0 of 5.0. Each score needs a named evidence source. Discussion then names causes against the data, so items connect to effects. Kind: evaluative. Cynefin: Complicated, because analysis picks the practice.

4. **Probe the format in parallel.** Rotate the facilitator and try one new activity per session, for four sessions, with a 15 minute cap per session. Measure the share of actions completed at four weeks. Baseline: 0 percent. Pass threshold: 60 percent of actions done at sample size 4. Stop condition: attendance falls below the prior average, or completion stays below 30 percent after four sessions. This tests whether the routine itself blocks candor, per A2. Kind: stochastic, so the acceptance test above comes before the trials. Cynefin: Complex, because cause and effect appear only after the probe, so leverage is a guess, and the budget caps the commitment.

## Follow-up

Conditions that change the recommendation: if A1 is false, replace Step 1 with a stall review of why existing items do not finish. If A2 is false, drop Step 4 and address safety before format.
