## Headline

No single prompt can make a model stop hallucinating, because the behavior comes from training, not wording alone. The best prompt does two things: it grounds every answer in text you supply, and it requires a source line for every claim. Prompts cut the hallucination rate; retrieval plus verification cut it further. Measure the rate on a fixed sample before and after, so the numbers decide.

## Background

The request asks for one prompt that makes a language model stop producing false content, called hallucination. No documents, model names, or workflow details came with the request.

## Relevance

Hallucinated answers put false facts into downstream work, and reviewers then waste time checking each claim. A grounded prompt makes unsupported claims visible at the moment of writing.

## Information

The term hallucination means generated text that contradicts known facts or the supplied context [2]. The causes sit in training data and decoding, so wording alone cannot remove them [2]. This is the reason no prompt reaches zero. High confidence, three survey sources agree [2], [3], [4].

Prompt methods are one category among several mitigation techniques [4]. Two prompt features recur across that survey: allow the model to abstain ("Not in sources"), and require citations at the claim level [4]. Verification passes reduce factual errors on listed tasks in a controlled comparison [3].

Here is the prompt:

```text
SOURCES is the text between the markers below.
Answer only from SOURCES.
For every claim, quote the line in SOURCES that supports it.
If SOURCES does not contain the answer, reply exactly: "Not in sources."
Do not add outside knowledge. Do not guess names, numbers, or dates.
--- SOURCES ---
(put source text here)
--- END SOURCES ---
```

This prompt shifts the failure mode from invention to abstention [inference]. It raises the share of "I cannot find it" answers, which is the correct behavior when the source text lacks the fact [4].
