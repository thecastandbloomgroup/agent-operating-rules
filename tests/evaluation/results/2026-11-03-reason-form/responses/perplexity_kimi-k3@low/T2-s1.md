# Headline

No prompt can make a model stop hallucinating, so the best prompt constrains it instead. Use a prompt that forces the model to say "unknown" and to cite sources. Then verify claims outside the model, because no text prompt fixes the underlying behavior.

## Background

You want a prompt that prevents a language model from inventing facts. Hallucination comes from how the model generates text, so prompt text can reduce it but not remove it.

## Relevance

A good prompt lowers the rate of invented claims. This saves you review time, but only if you add a check after the output.

## Information

Evidence is mixed. Prompt wording cuts hallucination in controlled tests, but no wording removes it [1].

Use this prompt:

> Answer only from the sources below or from knowledge you are certain of. If you are not certain, write "NOT ENOUGH INFORMATION". Do not guess. Do not invent names, dates, numbers, quotes, or citations. After every factual claim, add the source in brackets, or write "[uncertain]". List your assumptions at the end. Keep the answer under 300 words.

Assumptions:

A1. You want a copy-and-paste prompt, not a system change. Why not measured: the material does not state your setup. Validate by: ask which model and interface you use. If wrong: the prompt still works, but system-prompt placement would work better.

Alternative considered: fine-tuning or retrieval over your own documents cuts hallucination more than a prompt does [judgment]. It loses because you asked for a prompt, and it costs engineering time.

## End

I recommend that we:

1. Paste the prompt above at the top of your conversation, plus your source documents. This removes the biggest blocker: the model guessing without boundaries. Test: Given a question with no answer in the sources, When the model responds, Then it writes "NOT ENOUGH INFORMATION" instead of an invented answer. Stochastic test: 20 trial questions, baseline of your current rate, pass when zero invented answers appear. Clear domain: known cause and effect, a standard practice applied.

2. Ask the same question twice at different times and compare answers. This adds detection of unstable claims. Test: Given the same input twice, When answers differ on a fact, Then flag that fact for manual check. Stochastic: 10 paired runs, flag rate above 0 means manual check required. Clear domain.

3. Verify each cited source by opening it. This adds the external check that no prompt can replace. Test: Given a claim with a citation, When you open the source, Then the claim appears there word-for-word or paraphrased correctly. Deterministic per claim. Clear domain: follow a known verification practice.

## Follow-up

If you can change system settings, retrieval from your own documents lowers hallucination further. Ask if you want that setup.
