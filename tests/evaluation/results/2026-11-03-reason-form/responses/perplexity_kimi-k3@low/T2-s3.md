# Headline

There is no prompt that guarantees zero hallucination; use a source-bound abstention prompt plus retrieval and tests [judgment].  
The strongest copy-paste rule is: answer only from provided sources, cite each claim, and write “Not in sources” when support is absent [judgment].  
This reduces unsupported text, and it cannot remove errors inside bad sources or weak retrieval [inference].

# Background

The request asks for one “best” prompt to stop a model from inventing facts. Hallucination means fluent text without support from sources or tools. A prompt can set output rules, but model behavior still varies by run.

# Relevance

A strict contract is useful when wrong facts cost time, money, safety, or trust. It also gives reviewers a simple pass or fail check.

# Information

Copy-paste prompt:

```text
Answer only from the provided sources and tool results.
If a required fact is not present, write exactly: "Not in sources."
For every factual claim, give the source title and line or quote in brackets.
If more than one source conflicts, state the conflict and stop.
Do not infer missing values. Do not guess dates, numbers, names, laws, code behavior, or citations.
Before final, make a hidden checklist: claim, evidence, source location. Remove any claim without evidence.
```

This works because it converts fluency into an evidence task [judgment]. It fails when the source set is empty, stale, biased, or not reachable [judgment]. “Stop hallucinating” alone loses because it names a goal but gives no evidence rule, no abstention string, and no test [judgment].

Assumption log:

A1. The model can receive source text or tool results. Why not measured: the material does not state the setup. Validate by: run one prompt with a two-line source. If wrong: add a retrieval step before generation.

# End

1. Write the deterministic test first, then wrap every answer in the contract prompt. Increment: add the prompt above to one request template. Blocker removed: unsupported claims have no explicit failure state. Test: Given a prompt with a two-line source, When the answer asks for a fact outside that source, Then the output is exactly “Not in sources.” Cynefin: Complicated, because local analysis shows which fields need citations.

2. Add retrieval before generation, after Step 1 passes. Increment: attach one document store or file excerpt to the same request. Blocker removed: the model lacks source material. Test: Given a question whose answer exists only in the attached excerpt, When the model answers, Then the answer cites that excerpt and contains no uncited fact. Cynefin: Complicated, because recall quality is knowable by checking retrieved lines.

3. Run a stochastic regression check with the test written first. Increment: run 20 fixed questions, 10 answerable and 10 unanswerable. Blocker removed: one manual pass cannot show repeat behavior. Acceptance test: metric is unsupported-claim rate; baseline is current prompt; pass threshold is 0 supported-source misses on answerable items and at least 90% exact “Not in sources” on unanswerable items; sample size is 20. Cynefin: Complex, because output varies by run, so use a capped probe with a stop condition at 20 runs.
