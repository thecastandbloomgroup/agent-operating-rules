## Headline

No single prompt stops hallucination, but the most effective one forces the model to cite sources or say "I do not know".

- Hallucination falls when the model must ground each claim in supplied material.
- An explicit permission to abstain cuts confident wrong answers.
- Retrieval and verification steps beat prompt wording alone [1].

## Background

You want a prompt that makes a language model stop inventing facts. The request assumes one prompt can do this.

## Relevance

A better prompt reduces errors now. However, prompt wording alone will not eliminate them, so the recommendation adds a check step.

## Information

Evidence: models trained to predict fluent text have no built-in fact check, so pure prompting cannot guarantee truth [1] [judgment]. Giving the model source text and an abstain option lowers fabricated answers in question answering tests [1].

A1. The use case is general chat, not a fixed pipeline. Why not measured: the user did not state it. Validate by: ask which task fails most. If wrong: adapt the prompt template to that task.

A2. No retrieval system is available. Why not measured: the user described prompt-only control. Validate by: confirm whether documents can be supplied. If wrong: add retrieval, which helps more than wording [1].

Alternative considered: sampling settings such as low temperature reduce variety but do not remove confident falsehoods, so wording plus abstain wins [judgment].

## End

I recommend that we:

1. Adopt this prompt template, Clear domain, known rule from grounding studies:
   "Answer only from the text I provide, or from facts you can state with high confidence. For each claim, give the source. If you cannot support a claim, write: I do not know. Do not guess dates, numbers, citations, or names."
   Kind: stochastic. Test written first: run 50 questions with known answers, baseline is your current error rate, pass when unsupported claims drop by half at n = 50.

2. Ask one clarifying question inside the prompt: "If my question is ambiguous, ask before answering." Kind: stochastic, same 50 question test, Clear domain.

3. Add a verification step: "After your answer, list the claims you are least sure of." Kind: stochastic, same test, Complicated domain, analysis of which claims fail.

## Follow-up

Conditions: if you can supply source documents, retrieval plus this prompt outperforms the prompt alone [1].
