Headline
No prompt fully stops hallucination, so use a source-bound refusal prompt.
It answers only from text supplied in the message.
It requires a source name and a short quote for each claim.
It deletes any claim that has no quote.
It says "Not in the sources" when the fact is absent.

Background
Language models can write fluent text that is false.
Researchers call this output hallucination.
So the request asks for one prompt that stops it.

Relevance
A false answer can still look confident.
Therefore a source rule matters before you trust a factual reply.

Information
A survey defines hallucination as text that is unfaithful to the source.
[1]
Lewis and coauthors add retrieval before generation for knowledge-heavy tasks.
[2]
A check after the draft reduces unsupported claims in their tests.
[3]
No cited paper shows a prompt that removes every false output.
[judgment]
Confidence is high that a prompt alone is not enough.
The basis is those three papers plus the absence of a removal result.

Use this prompt:

```text
Answer only from the sources in this message.
If the sources do not contain the fact, write: Not in the sources.
Do not invent names, numbers, dates, quotes, or citations.
For each claim, give the source name and a short quote.
If sources conflict, state both sides and do not pick a winner.
Before the final answer, list any claim that lacks a quote.
Remove each claim that lacks a quote.
Then give the final answer in plain text.
```

Follow-up
If you cannot supply sources, this prompt will refuse most facts.
If the task is fiction, drop the source rule.
