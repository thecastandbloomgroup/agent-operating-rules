### Headline

No single prompt stops all model hallucinations because language models generate tokens by probability rather than fact verification [judgment].
You reduce hallucinations when you restrict the model to supplied reference text [19].
You also reduce hallucinations when you explicitly permit the model to say that it does not know [20].
Prompt constraints lower false claims, but retrieval systems or external verification tools provide stronger guarantees [21].

### Background

You asked for the best prompt to stop hallucinations in language models.
A hallucination occurs when a model generates unfaithful or false content as fact [19].
Research shows that prompt phrasing lowers hallucination rates, but prompt design alone cannot eliminate them entirely [20].

### Relevance

Hallucinations cause errors in production tasks and damage user trust.
Therefore, choosing effective prompt patterns prevents false statements before you invest in complex infrastructure.

### Information

Language models predict the next token from training distributions [19].
Consequently, models state incorrect facts with high confidence [judgment].
Studies show that grounding prompts in retrieved context reduces unfaithful text by 30% to 60% compared to open generation [21].
Furthermore, instructing models to state "I do not know" reduces false answers by 40% on out-of-domain questions [20].

This analysis considers three prompt techniques:
First, add strict negative constraints, such as "Answer only using the text below."
Second, require quotes from the source text before the final answer [19].
Third, allow explicit refusal when the text lacks the answer [20].

A prompt template that applies these findings is:
"Answer the question using only the facts in the Context section. If the Context does not contain the answer, reply with 'Information not found'. Quote the exact sentence from the Context that supports your answer."
