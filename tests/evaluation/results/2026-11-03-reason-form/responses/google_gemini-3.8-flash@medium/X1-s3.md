# Headline

Build a measurement benchmark from agent feedback before you tune the model.
First, a gold dataset of support tickets creates an objective baseline for error rates.
Second, an agent feedback button in the tool captures specific failure cases during daily work.
Third, prompt adjustments run against the gold dataset to verify factual accuracy gains.

# Background

Support agents report that the new summarisation tool produces incorrect information at times. The engineering team currently tracks no quality metrics for these summaries. Therefore, the team cannot measure error rates or verify improvements.

# Relevance

You need reliable summaries now because inaccurate summaries cause agent mistakes and customer churn. Measuring baseline accuracy prevents wasted engineering time on untracked prompt adjustments.

# Information

Summarisation errors in support workflows divide into factual hallucinations and missing key details [judgment]. Customer service benchmarks show that untuned models reach factual consistency scores between 70% and 85% [1]. Furthermore, human evaluation of 100 tickets provides sufficient signal to detect major prompt errors [judgment].
