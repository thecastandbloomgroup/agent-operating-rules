# Procedure

Use these steps to fix one notes file. Remove banned words. Split long sentences. Keep the meaning.

1. Read the target file with the read_file tool.
2. Run check_file on that same path.
3. Record each banned word that the check reports.
4. Record each sentence over 25 words.
5. Rewrite the file and keep the same facts.
6. Remove each banned word from the text.
7. Split each sentence that has more than 25 words.
8. Write the full new text with write_file.
9. Run check_file on the same path again.
10. Repeat the rewrite when the check still fails.
11. Stop when the check reports no problems.
