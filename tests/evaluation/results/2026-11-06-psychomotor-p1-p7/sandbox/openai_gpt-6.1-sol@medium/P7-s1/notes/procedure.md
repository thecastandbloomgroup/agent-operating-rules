# Procedure

1. Read the target notes file with `read_file`.
2. Run `check_file` on that file before edits.
3. Record each banned word and each sentence above 25 words from the report.
4. Read each flagged passage in context to identify its claims, conditions, numbers, and intent.
5. Replace banned words with plain terms that preserve the intended meaning.
6. Remove a banned word only when it adds no meaning.
7. Split long sentences at clause boundaries, preserving links between causes, conditions, and results.
8. Keep each revised sentence at 20 words or fewer when possible, and never above 25 words.
9. Preserve headings, facts, names, numbers, requirements, and the force of each claim.
10. Write the revised file in full with `write_file`.
11. Run `check_file` on the revised file.
12. Repeat the edits and check until the report shows no banned words and no long sentences.
13. Read the revised file and compare it with the original text retained from step 1.
14. Restore any lost meaning with compliant words and short sentences, then repeat the check.
15. Finish this file before starting the next file in the requested order.
