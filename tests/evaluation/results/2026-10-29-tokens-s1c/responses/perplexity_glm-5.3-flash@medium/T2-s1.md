## Headline

No prompt makes the model stop hallucinating; prompts that demand a named source per claim and allow "Unknown" cut the errors most [judgment].

1. The behavior is a limit of the model class, so wording alone cannot remove it [1].
2. Prompts reduce it when each claim carries a nameable origin and gaps get an explicit "Unknown".
3. Only a measured error rate, before and after the change, shows whether a prompt works [judgment].

## Background

You asked for the single best prompt to stop model hallucination. The query does not state the model, the task, or whether documents are available. This answer assumes a chat model without tools and without retrieved documents.

## Relevance

A fluent unsupported answer costs more than a slow "Unknown". The change below needs one editing session and 40 test questions.

## Information

Hallucination means a fluent statement that the source material or the model's knowledge does not support [2]. The model class itself produces this behavior, so no prompt reaches zero [1]. Training that rewards guessing over abstention adds more of it [3]. So the goal is a lower error rate, not zero.

Expected effect: a 30 to 70 percent drop in unsupported claims; confidence: low, basis: judgment, because no controlled test ran in this session [judgment].

Paste this block as the system prompt:

```text
Answer in this structure.

1. SOURCED ANSWER: state only facts whose origin you can name.
   Put the origin in parentheses after each fact.
2. INFERENCES: state conclusions that follow from the sourced facts.
   Mark each with the word "inference".
3. UNKNOWN: if a needed fact has no nameable origin, write exactly
   "Unknown, not sourced here". Do not guess around it.
4. CLAIMS CHECK: list every factual claim, one per line.
   Tag each as "sourced", "inference", or "unknown".
```

If documents exist, prepend: "Use only the provided documents. Cite the document name and section for every fact."

Assumption log:

- `A1. The model has no tools and no retrieved documents. Why not measured: the user has not answered. Validate by: check the interface for a search or file feature. If wrong: prepend the documents rule and drop section 3.`
- `A2. The user can hold 20 questions with known answers. Why not measured: the cost of collecting them is unclear. Validate by: count questions that already have answers. If wrong: lower the sample to 10 and accept a noisier rate.`

Alternative considered: a one-line order such as "never invent facts". It loses because prohibition does not change sampling, and without a measure no one sees the improvement [judgment].
