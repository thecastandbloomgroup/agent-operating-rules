## Headline

The friction is not a culture problem: it is a missing machine rule, so automate SQL formatting with a pinned formatter and let the tool, not people, hold the standard.

1. Formatting disputes are taste conflicts; taste conflicts do not resolve by debate [judgment].
2. A shared, pinned formatter removes the disagreement at the source, so each review sees the same output.

## Background

The team disagrees on SQL format, and the disagreement surfaces in every code review. The request is to remove the friction without naming a winner by authority.
