## Headline

- No error message, system, or frequency data exists in the request, so the root cause is unknown right now.

## Background

The user reports that the build is flaky. Flaky means a build or test that fails without a code change and passes on a new run. [1] The request gives no pipeline name, log, or sample, so triage starts from scratch.

## Relevance

A flaky build erodes trust, so teams start to ignore all failures. [1] Restoring trust quickly limits that damage this week.
