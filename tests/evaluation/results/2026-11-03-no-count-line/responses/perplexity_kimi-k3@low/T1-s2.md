# Headline

The fix is not cultural. It is to remove the decision from people and give it to a tool. First, adopt an automated SQL formatter and formatter checks in review. Second, document a short style decision record so the debate has an endpoint. Third, measure review friction before and after to confirm the change works.

# Background

The team disagrees on SQL formatting. The disagreement slows every review. The request frames this as a culture problem.

# Relevance

Style debates are resolvable disputes, not value conflicts, so they respond to tooling rather than to culture work. [judgment]

An automated formatter ends the debate at the source, therefore review time goes to logic instead.

# Information

**Evidence**

Teams that use auto-formatters report that style comments in review drop toward zero, because the tool enforces one format. Prettier documents this pattern for other languages [1] (secondary for this claim).

SQL formatters with configurable rules exist and are mature: SQLFluff (open source, lint and format) [2] and sqlfmt (opinionated, minimal config) [3]. Both are primary sources (specifications of the tools).

Baseline for friction: no number in the material. Measure comments per review that mention format before the change. [judgment]

**Assumption log**

A1. The team writes SQL in a version-controlled repository. Why not measured: the material does not state it. Validate by: check for a shared repo. If wrong: Steps 1 and 2 still apply by using a shared config file.

A2. The team uses pull requests with review comments. Why not measured: the material does not state it. Validate by: ask one teammate. If wrong: count style disputes per week instead of per review.

A3. No compliance constraint forbids third-party tools. Why not measured: the material does not state it. Validate by: check the security or procurement policy. If wrong: pick a tool from the approved list.

**Alternative considered**

The strongest alternative is consensus building: a style workshop and a voted style guide. It loses because written guides drift and still need manual enforcement in review, [judgment] so the friction returns.
