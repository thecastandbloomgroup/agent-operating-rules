## Headline

Use a prompt that feeds the model your sources and orders it to refuse when the sources lack the answer.

- No prompt removes hallucination on its own; grounding, that is, source text inside the prompt, is the main lever [1].
- An explicit refusal line makes "unknown" an allowed answer, and models carry usable signals of what they know [2].
- A per-sentence citation rule turns each claim into a one-step check, so leftover errors cost less to catch [judgment].

## Background

The request asks for one prompt that stops a language model from inventing facts. Invented content, called hallucination, is an unsolved problem in language generation [3]. This answer gives the prompt first, then the evidence, the limits, and the test.

## Relevance

The same wording shapes every future reply, so a weak instruction repeats its errors at scale. Two extra lines now avoid that repeated cost.

## Information

The prompt:

```text
Answer the question using only the sources below.

Rules:
1. If the sources do not contain the answer, reply with exactly this line:
   "The sources do not contain this answer."
2. Do not add facts that are not in the sources.
3. After every factual sentence, cite its source, for example [S1].
4. If no sources are given, reply: "No sources were provided."
   Do not answer from memory.

Sources:
[S1] <paste document 1>
[S2] <paste document 2>

Question: <the question>
```

Why each part works:

- Grounding produced the best published results on three open-domain question-answering tasks, and human raters scored the answers as more factual than a closed-book baseline [1].
- Large models carry internal signals of what they know [2]. A named refusal gives them an output path for that signal [inference].
- The citation rule lets a human or a script audit each claim against the real source [judgment].

Limits, with calibrated uncertainty:

- A broad survey reports no method that removes hallucination completely [3].
- Confidence is high that this pattern cuts the error rate, three independent sources in agreement [1].

A2. Source documents exist for your questions. Why not measured: the request does not state it. Validate by: check whether one typical question has an answering document. If wrong: skip Step 2; the refusal rule still cuts invention on unanswerable questions.

Alternative considered: a bare instruction such as "never invent facts", with no sources. It loses because the model gets nothing to check against and no allowed exit, so gap filling continues [judgment].

## End

I recommend that we take these three steps, in order.

1. Adopt the prompt. Increment: paste the template into the system prompt or first message, one edit in one session. Blocker removed: the model has no allowed refusal, so it fills gaps. Kind: deterministic, test written first. Given a question whose answer is absent from the sources. When the model replies. Then the reply is the exact refusal line. Then it contains no other factual claims. Domain: Clear, because a known best practice exists and the work is one edit.
2. Attach sources. Increment: for one use case, attach the answering documents at call time. Choose paste, file upload, or search after a one-paragraph analysis of where the facts live. Blocker removed: the prompt has no ground truth. Kind: deterministic, test written first. Given a question whose answer sits in the attached sources. When the model replies. Then each factual sentence names a source. Then that source contains the claim. Domain: Complicated, because picking the source path needs analysis of your data.
3. Measure the effect. Increment: write 30 test questions, 20 answerable and 10 not, and run each three times before and after. Blocker removed: no evidence that the change works. Kind: stochastic, acceptance test written first. Metric: share of claims not supported by their cited source. Baseline: the rate before the change. Threshold: 50% below baseline, plus refusal in at least 27 of the 30 unanswerable runs. Sample: 90 runs. Domain: Complicated, because eval design is knowable through analysis.

Step 3 MUST NOT start until the tests in Steps 1 and 2 pass.
