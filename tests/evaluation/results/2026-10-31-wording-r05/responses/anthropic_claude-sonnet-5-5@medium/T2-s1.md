## Headline

Use a prompt that limits the model to supplied sources and allows it to say "Not found". No prompt removes hallucination entirely.

- A prompt can lower the rate of invented facts, but it cannot set the rate to zero.
- The largest gain comes from supplying source text, because the model then copies from evidence instead of recalling from memory.
- You must measure the result on your own questions, because the effect varies by model and task.

## Background

You asked for one prompt that stops a model from hallucinating. Hallucination means output that is fluent but unsupported by facts or sources. This answer assumes a factual question-and-answer task (A1).

## Relevance

An unsupported answer that looks correct is costly because readers trust it. A tested prompt gives you a known error rate instead of a hope.
