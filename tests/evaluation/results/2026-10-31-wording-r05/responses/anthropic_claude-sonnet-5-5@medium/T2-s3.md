## Headline

No single prompt stops hallucination, but one grounded prompt cuts it, and you must measure the effect.

- A prompt lowers the error rate. It does not remove it, because the model still generates text by prediction [1].
- The prompt works best when it limits the model to supplied sources and permits a refusal.
- A second pass that checks each claim adds further gain [2].
- A test on your own questions shows whether the prompt works for you.

## Background

You asked for the best prompt to stop a model from stating false facts. A false statement that the model presents as true is a hallucination. The model type and task are not stated.

## Relevance

Each false claim that reaches a user costs trust and rework. A tested prompt gives you a known error rate instead of a guess.

## Information

Use this prompt. It works for factual questions with source text.

```text
Answer using only the sources below.
Quote the sentence that supports each claim.
If the sources do not contain the answer, write: Not in sources.
Do not use outside knowledge.
Do not guess numbers, names, dates, or links.
Before you finish, check each claim against its quote.
Delete any claim without a quote.

Sources:
<paste text here>

Question:
<paste question here>
```

Evidence:
- Grounding the model in retrieved text reduces false output on knowledge tasks compared with memory alone [3].
- Asking the model to plan and run checks on its own draft reduced false claims in the cited experiments [2].
- A hallucination has several causes, so one instruction cannot cover all of them [1].
- The size of the gain on your task is unknown. Expect a drop in error rate: likely (66 to 100%), based on the three studies above.
