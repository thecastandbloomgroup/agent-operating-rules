## Headline

No prompt stops hallucination fully, but one prompt cuts it: restrict answers to supplied sources, allow "Not known", and add a check pass.

- A prompt only changes behavior. It does not add knowledge the model lacks.
- Permission to abstain removes the pressure to guess.
- Source grounding gives each claim something to check.
- A test set shows whether the prompt works on your tasks.

## Background

Hallucination means the model states something as fact that is false or not supported. You asked for the best prompt to stop it. The material gives no model, task, or source documents.

## Relevance

A false answer that sounds sure costs more than a refusal. A tested prompt gives a measured gain instead of a guess.

## Information

Evidence:

- Surveys define hallucination as output that is unfaithful to the source or to fact, and they list mitigation methods. [1]
- Supplying retrieved documents to the model improves factual accuracy on knowledge tasks, compared with the model alone. [2]
- A plan-then-verify pass, where the model checks its own draft with separate questions, lowers false claims in the paper's tests. [3]
- It is very likely (90 to 100%) that no prompt removes hallucination fully. [judgment]
- The size of the gain depends on the model and the task. Confidence in any exact figure is low, because the material has no test data.

The prompt:

```text
Answer only from the sources I give you. If no source is given, use only facts you are sure of.
If you are not sure, write "Not known" and say what is missing.
Do not guess names, numbers, dates, or quotes.
For each claim, quote the source line that supports it.
Before you answer, check each claim against its quote.
Remove any claim that has no quote.
Mark each answer: High, Medium, or Low confidence, with one reason.
```
