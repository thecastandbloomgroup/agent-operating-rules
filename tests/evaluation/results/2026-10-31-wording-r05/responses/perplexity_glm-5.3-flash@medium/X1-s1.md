Headline
Decision: build measurement before changing the summariser, because without it you cannot tell which output errors matter or prove any fix. Supporting points:

1. Sample and rate 30 summaries against a rubric to classify the failures [judgment].
2. Use those ratings to build a labeled test set of 100 support transcripts.
3. Change one thing at a time: add quote-based constraints, then retest with a fixed acceptance test.
4. Run a weekly sample so the score stays visible and regressions show within days.

Background
The support tool now includes an LLM summariser. Agents report that it is "sometimes wrong". There are no metrics, no error categories, and no baseline.

Relevance
Every future prompt or model change is unverifiable until a baseline exists. A measurement loop turns "sometimes wrong" into a countable list with an owner.

Information
Planned evidence gathering: rate 30 stored summaries, group the failures into themes, count sources per theme, and check for disagreement between raters [3]. The numbers then set the baseline for an acceptance test.

Rubric for the evaluative steps (Section 6.4, evaluative kind):
- Factual consistency: weight 0.4. Evidence: each sentence traces to a transcript line.
- Completeness: weight 0.3. Evidence: a rated checklist of required facts.
- Attribution: weight 0.2. Evidence: entities and owners match the transcript.
- Brevity: weight 0.1. Evidence: read time against a 60 second target.
Pass threshold: weighted score at or above 0.8 with zero hallucinations. A hallucination is a claim not present in the transcript.

Stochastic acceptance test, written before the work: metric = hallucination rate. Baseline = result from Step 1. Threshold = 50% relative reduction. Sample size = 100 summaries. Accept only when the threshold holds at n = 100.

A2. Transcripts and summaries are stored and retrievable for at least 3 months back. Why not measured: the request does not state it. Validate by: query the history retention. If wrong: start logging now and delay Step 2 by one log-backfill week.
A3. No human-labeled ground truth exists. Why not measured: not stated anywhere. Validate by: ask two agents or check for a QA queue. If wrong: reuse the existing labels and skip half of Step 2.
