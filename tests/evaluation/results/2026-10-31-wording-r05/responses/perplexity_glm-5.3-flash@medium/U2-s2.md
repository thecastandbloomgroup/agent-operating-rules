## End

I recommend that we run a three step check once the Q3 report and its source data are attached.

1. **Trace each headline figure to its inputs.** Increment: recompute the total from line items for each headline figure; this fits one working session. Blocker removed: the unknown origin of the published totals. Test, written first (deterministic):
   ```gherkin
   Given a headline figure in the Q3 report
   When the checker sums its line items with the stated method
   Then the result equals the published figure, or the gap is logged with its size
   ```
   Cynefin: Clear, because the sum check is one known procedure for every figure.
2. **Compare the figures across periods.** Increment: build a table of Q3, Q2, and prior year Q3 for each figure, and flag changes above a tolerance; set the tolerance at 10% for the first pass [judgment]. Blocker removed: the figures that look off stay unnamed. Test, written first (deterministic):
   ```gherkin
   Given Q3, Q2, and prior year Q3 values for a figure
   When the checker computes the percent change for each period
   Then every figure above the tolerance appears in the anomaly list
   ```
   Cynefin: Complicated, because the choice of baseline and tolerance needs analysis. This step waits on step 1, because the trace lists the figures to compare.
3. **Classify each flagged figure.** Increment: assign one cause per flagged figure from the outputs of steps 1 and 2. Blocker removed: the check ends with findings but no cause, so no one can fix the report. Rubric, written first (evaluative): each figure gets a score of 0 or 1 per criterion, with evidence from steps 1 and 2; the cause with score 1 on the best supported criterion wins:
   - arithmetic error: the sum check in step 1 fails (weight 0.4)
   - category error: a line item sits in the wrong account or segment (weight 0.3)
   - timing change: an entry shifts period between Q3 and Q2 (weight 0.3)
   
   Pass threshold: one criterion scores 1 with cited evidence, and the other two score 0 or have no support.
   Cynefin: Complicated, because each cause is knowable, but only with the analysis from steps 1 and 2.

Order: step 2 MUST NOT start before the trace in step 1 lists the figures. Step 3 uses the outputs of steps 1 and 2. If the report contains no line items, replace step 1 with a request for the source extract, and keep steps 2 and 3 unchanged.
