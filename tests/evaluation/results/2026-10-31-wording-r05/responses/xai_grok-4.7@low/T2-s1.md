Headline
Use a source-bound prompt that abstains when the source has no answer. It limits facts to text in the message. It stops when that text has no support. It requires a quote so a bad claim is easy to reject. A short trial still has to measure remaining errors.

Background
The request asks for one prompt that makes a model stop inventing facts. No prompt can guarantee that result, because a model can still ignore its instructions [judgment]. Therefore this response gives a source-bound prompt and the checks that keep it honest.

Relevance
Invented facts can leave the chat before a person checks them. The prompt lowers that risk only when a missing quote or an abstention is treated as a failed answer [judgment]. Abstain means the model states that the sources lack the answer, then stops.

Information
This section covers the prompt, the evidence, one assumption, and the alternative.

Use this prompt:

```text
Use only the sources in this message.
If those sources do not contain the answer, reply with this sentence only: Not in the sources.
Do not add facts from memory.
For each factual claim, quote the supporting span and name its source.
Label each inference as inference.
Do not invent names, numbers, dates, quotes, or citations.
If two sources conflict, state both and do not pick a winner.
```

Hallucination remains a documented failure in natural language generation [1].
Conditioning answers on retrieved passages beats generation from model memory alone on knowledge tasks [2].
Retrieval means the system fetches source text before the model writes.
A required quote is the fail signal in this prompt, because a missing quote is visible without a second model [judgment].
Therefore the prompt applies the grounding result from [2] and fails closed when the source is absent [judgment].

A1. The user wants one system prompt for chat with no retrieval tool. Why not measured: the material does not state it. Validate by: confirm whether each question includes source text. If wrong: retrieve a source first, then keep the same abstain rule.

Alternative considered: A prompt that only says "be accurate" is the strongest alternative. It loses because it adds no retrieved passage, and [2] shows that external text is what improves knowledge answers.

End
I recommend that we take these steps.

1. Clear: this applies a known instruction pattern, so cause and effect are already known.
Test first: Given a question and a note that lacks the answer. When the model replies. Then the reply is only: Not in the sources.
Paste the prompt into the system slot in one session.
This removes the blocker that there is no standing rule to abstain or to quote a source.

2. Complicated: a claim must be matched to a passage, so this step names that check.
Test first: Given an answer that states a fact. When the reviewer searches the attached text. Then each fact has a quoted span from that text.
Attach the source text in the same message as the question, in one session.
This removes the blocker that the model has no bounded source to quote.
Step 2 MUST NOT start until the prompt from Step 1 is saved.

3. Complex: cause and effect show up only after a trial, so this is a safe-to-fail probe, and its leverage is a guess.
Test first: The metric is unsupported claims per answer. The baseline is the current prompt with no abstain rule. The pass threshold is 0 unsupported claims. The sample size is 10 questions.
Run those 10 questions in one session.
Stop if 2 answers contain an unsupported claim.
Cap the budget at one session.
This adds a measured rate instead of an untested hope.
This probe can run after Step 2. It is not ordered by claimed leverage.

Follow-up
If questions have no source text, this prompt will abstain on most items. In that case, retrieve a source before Step 2 and keep the same abstain rule.
