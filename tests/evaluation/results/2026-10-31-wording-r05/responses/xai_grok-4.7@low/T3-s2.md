Headline
Do not cut over to long-lived tokens. First record the session contract, then ship a short access token with refresh rotation in httpOnly cookies, and run one separate sign-up probe.

The inventory comes before any token code.
Access tokens expire in minutes, and refresh tokens rotate.
Browser tokens stay in httpOnly cookies, not in local storage.
The sign-up change waits for a baseline and stays outside the auth cut.

Background
The request is a move from server sessions to JSON Web Token (JWT) auth, plus a higher sign-up completion rate.
The material does not name the stack, the clients, or the drop-off.
Therefore the plan treats clients as cookie browsers and treats form friction as the conversion issue until the inventory says otherwise.

Relevance
The next auth change can lock in a token store that is costly to reverse.
A form edit in the same release can hide which change moved completion.

Information
A JWT is a signed set of claims, not a server session [1].
RFC 7519 sets that encoding.
However, it does not set logout or a deny list [1].

RFC 6265 defines the httpOnly cookie flag [2].
An httpOnly cookie is a cookie that page script cannot read [2].
Page script can read local storage [judgment].
Therefore browser JWTs belong in httpOnly cookies.
Secure means the browser sends the cookie only on encrypted transport.

Client type is about as likely as not a browser (33 to 66%).
The basis is an empty client list in the material [no source].

A1. Clients are browsers that already send cookies. Why not measured: the material does not state it. Validate by: list client apps in the inventory. If wrong: use bearer headers in Step 3.

A2. Logout and account lock must revoke access within minutes. Why not measured: the material does not state it. Validate by: read the product logout rule. If wrong: keep short expiry and skip the deny list.

A3. Sign-up loss comes from form friction, not bad traffic. Why not measured: the material does not state a funnel. Validate by: compare completion by step for 7 days. If wrong: stop the form probe.

The strongest alternative is a long-lived JWT in local storage.
It loses because logout then needs a server check, and script can copy the token [judgment].
See the httpOnly rule above.
