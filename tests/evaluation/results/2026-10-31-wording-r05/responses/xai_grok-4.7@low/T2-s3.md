Headline
No prompt can make a model stop hallucinating.
The strongest prompt binds every claim to sources in the same message.
It uses one refusal line when those sources lack the answer.
A scored test is still required, because the model cannot verify facts.

Background
The request is for one prompt that stops false or unsupported answers.
Hallucination means a confident statement that the given sources do not support.
This response gives that prompt and the smallest test that shows whether it works.

Relevance
Unsupported answers can ship as facts in the next session.
The prompt cuts that path only when sources sit in the same message.

Information
This section covers the prompt, the evidence, and the rejected option.
One survey documents hallucination as an open problem in large language models [1].
A second survey documents the same error class in generated text [2].
Therefore a prompt can only constrain output, not prove a fact. [judgment]
However, the prompt fails when the message has no sources.

Use this prompt:

```text
Answer only from the sources in this message.
If the sources lack the answer, write exactly: Not in sources.
For each claim, quote the supporting words and name the source.
Do not invent facts, numbers, names, dates, or citations.
If sources conflict, report both and do not choose.
Mark any step past the sources as Inference.
Delete any claim that has no quote before you answer.
```
