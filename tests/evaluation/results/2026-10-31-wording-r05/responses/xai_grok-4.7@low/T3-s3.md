Run sessions and tokens together until tests pass, and test a smaller sign-up form beside that work.
First, the request does not describe the current design, so the first step records it.

Background
The request asks for two changes. Move the auth service from server sessions to JSON Web Token (JWT) auth. Also raise the share of visitors who finish sign-up.

Relevance
A fast cutover can lock users out or leave tokens you cannot cancel. The form test can start after a baseline, because it does not wait on the token choice.

Information
A JWT carries signed claims and is not a server session row.
[1]
Therefore cancel and logout need a short life or a deny list, because the signature stays valid until expiry.
[1]
