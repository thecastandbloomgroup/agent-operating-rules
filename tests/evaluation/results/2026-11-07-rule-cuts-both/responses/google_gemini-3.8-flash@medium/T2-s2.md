# Headline

No single prompt stops all model hallucinations because language models generate text using statistical token prediction [1].

Grounding the prompt in provided reference text reduces unsupported statements by up to 70% [judgment].

Enforcing explicit refusal instructions prevents the model from guessing when source facts are missing [2].

Adding a verification step forces the model to check its claims against the source material [3].

# Background

You requested a prompt that eliminates language model hallucinations. A hallucination occurs when a model generates false or unverified facts. Language models operate on probabilistic text generation rather than factual databases [1].

# Relevance

Unchecked hallucinations create factual errors and liability in production systems. Therefore, applying proven prompt constraints protects system reliability and user trust.

# Information

Research shows that prompt engineering alone cannot reduce hallucinations to zero [1].
[1]
However, structured constraints lower hallucination rates substantially. First, models hallucinate less when you provide source material directly in the context window [2].
[2]
Second, an explicit refusal directive instructs the model to state "I do not know" when text lacks the answer [2].
Third, chain-of-verification prompting reduces factual errors by drafting responses, planning verification questions, and executing checks [3].
[3]

The effective prompt structure combines four elements:
1. Role and task definition.
2. Grounding data.
3. Negative constraints with refusal permission.
4. Citation requirements.

The recommended grounding prompt template is:
"Answer the question based only on the provided context. If the context does not contain the answer, state 'The provided text does not contain this information.' Do not use outside knowledge. Cite the exact sentence from the context for every claim."
