## Headline

No prompt stops hallucination, because the error starts in the model, not in the instruction. The best prompt cuts the error rate and makes each error easy to catch. Three rules do most of the work: answer only from a given source, write NOT FOUND when a fact is absent, and check each claim before you send it. Zero errors is unlikely with any prompt (unlikely, 0 to 33%) [judgment].

## Background

The request asks for one prompt that makes a model stop producing false facts. The request assumes that wording alone controls the error. That assumption is false [judgment].

## Relevance

False facts flow straight into decisions, so the fix has value now. A prompt costs minutes to test.

## Information

A hallucination is text that reads well but states a false fact. Because the cause sits in training and sampling, wording can reduce the rate but cannot set it to zero [judgment] [no source].

A prompt based on three rules helps:

```
Answer only with facts from the provided documents.
For each fact, name the document and the section.
If a needed fact is absent, write NOT FOUND. Do not guess.
After the answer, list every claim without a source, then stop.
```

Why each rule helps:

- **Source only**: the model copies facts instead of producing them. Removal of free generation removes most false facts [judgment].
- **NOT FOUND**: a permitted escape removes the pressure to invent [judgment].
- **Check pass**: a second look catches claims that the first pass invented [judgment]. Because the model checks its own words, the check also fails sometimes. A human or a separate model pass then catches the rest (Likely: 66 to 100%) [judgment].

**Alternative considered**

## End

I recommend that we deploy the three-rule prompt and measure it. The steps:

1. **Add the three-rule prompt.** Increment: edit the system prompt in one session. Blocker removed: facts without a source. Test (stochastic): run this acceptance test first:
   - Given a task set of 20 questions with known answers
   - When the model answers with the new prompt
   - Then the false fact rate drops under the current baseline, measured at 20 tasks
   - Domain: Complex. Reason: the effect shows only after trials, so this is a safe-to-fail probe with a stop condition at 20 tasks [judgment].
2. **Add a check pass.** Step 1 MUST be in place first. Increment: a second call that checks each claim against the source. Blocker removed: errors that pass the first attempt. Test (stochastic): metric is caught errors per 20 tasks, baseline is the Step 1 rate, threshold is 50% of errors caught, sample size 20 [judgment]. Domain: Complex. Reason: the check pattern breaks if the model repeats the same error in both passes, so measure rather than commit.
3. **Log every NOT FOUND for one week.** Increment: a file of missed answers. Blocker removed: gaps in the source material. Test (deterministic):

   - When each NOT FOUND is read
   - Then each one maps to a missing document or a real gap in the prompt
   - Domain: Clear. Reason: reading a log is one step with a known method [judgment].
