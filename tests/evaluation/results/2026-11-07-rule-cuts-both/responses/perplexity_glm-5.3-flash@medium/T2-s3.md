## Headline

No single prompt stops hallucination; the strongest prompt forces a source for every claim and permits the answer "I do not know".

1. Hallucination, meaning fluent text with invented facts, comes from generation and training, so prompt wording alone cannot remove it [1].
2. A source rule cuts the error rate and makes each error visible [judgment].
3. Attached documents or search do more for accuracy than any prompt wording [judgment].
4. Measure the error rate before and after the change, because a prompt without a measure cannot be judged [judgment].

## Background

A chat model sometimes states facts it cannot support. The query asks for one prompt fix and names no model, task, or tools. Research treats prompt rules as one partial control among several, not a cure [1].

## Relevance

False answers cost trust and create rework. A source rule and a short trial cost minutes and show their effect at once.

## Information

First, the cause. A model predicts likely next words and has no fact store to check. When no check exists, wrong fluent text reaches the reader [1]. One 2025 analysis argues that scoring often rewards guessing over refusal, so some errors persist past any prompt change [2].

Second, the control. Use this prompt in the system message:

```text
For every claim, give a source: a section, a quote, a number, or a link.
Write "I do not know" when you lack a source for a claim.
When a claim goes beyond the sources, start it with "inference".
When a fact is not certain, write the probability next to it.
```

With attached material, replace line 1 with: "Source only from the attached material, and give the section for each claim."

A drop in the error rate from this rule is likely (66 to 100%) [judgment].

Assumption: the setup is a chat model with no attached documents and no tools. Why not measured: the query does not state the setup. Validate by: check the model and interface before Step 1. If wrong: use the attached-material form of line 1 and skip the general version.

Alternative considered: tool grounding or fine-tuning without a prompt change is the strongest alternative. It loses here because it needs changes the query does not request, and it leaves the same unsourced claims when the tool fails [judgment].

## End
