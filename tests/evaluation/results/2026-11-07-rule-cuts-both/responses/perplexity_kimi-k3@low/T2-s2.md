**Headline**

Use a prompt that forces source names, marks uncertain claims, and permits "I don't know" answers.
- No prompt eliminates hallucination completely, because language models generate plausible text, not verified facts [judgment].
- Requiring named sources raises accuracy, because fabricated answers must survive an explicit check [judgment].
- Giving an exit option ("I don't know") reduces forced guesses, because the model no longer must fill every gap [judgment].
- Verification outside the chat, that is, fact-checking the sources, is still required.

**Background**

The request is a single best prompt that stops a model from producing false claims. Current prompting methods reduce hallucination but do not remove it.

**Relevance**

A reusable prompt saves review time on every answer. Wrong facts still cause harm if the output is not checked.

**Information**

The prompt, tested in form against the failure modes above [judgment]:

```text
Answer the question below. Apply these rules:
1. Answer only from sources you can name.
2. For each factual claim, name the source: title, author, year.
3. If you cannot name a source for a claim, write "[unsure]" next to it.
4. If you cannot answer the main question with a named source, reply: "I don't know."
5. Do not invent citations, quotations, statistics, or URLs.

Question: <your question here>
```

Assumption: the model is a general chat model without live search. Why not measured: the material does not state the model or tool access. Validate by: run the prompt on five questions with known answers, then verify the cited sources. If wrong: add a step that forces citation of only retrieved documents, or enable a search tool.

Alternative considered: asking the model to "think step by step and double-check facts." It loses because self-check without named sources is 50 to 70% likely to confirm the same error [judgment].
