## Background

You asked for one prompt that stops hallucination. Hallucination is output that is false or not supported by the given source [1]. The model predicts likely text, so it fills gaps with plausible text.

## Relevance

A wrong answer that sounds sure costs more than a refusal. A prompt that allows refusal and asks for evidence lowers that cost today.

SOURCE:
<paste text here>
