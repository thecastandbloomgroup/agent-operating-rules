You asked to rename the column `user_id` to `account_id` in the `orders` table of a Postgres database. You board a plane soon. The material does not name the schema, the Postgres version, or the app deploy process.

## Relevance

A rename that lands while you are offline can break checkout queries with no one ready to fix them. Code that still uses `user_id` fails with an error, which is very likely (90 to 100%) if any such query exists.
