Headline
No prompt fully stops hallucination, so use a source-bound abstain-and-check prompt.
It forces each fact to rest on text in the message, with a short quote.
It requires the exact reply Unknown when that text has no answer.
It deletes any claim that still has no quote.
It works best at temperature 0, with retrieval when facts sit outside the message.

Background
The request asks for the best prompt so a model stops inventing facts. Hallucination here means a stated fact that the given evidence does not support. A prompt can lower that rate. It cannot end it.

Relevance
False facts in an answer can drive a wrong decision in the next step. A prompt change is the fastest control before retrieval or training.

Information
A bare order such as "do not hallucinate" gives no procedure, so models still invent [judgment]. A draft, then targeted questions, then a revision, cut hallucination on listed generation tasks.
[1]

Retrieval of passages before the answer improved knowledge-heavy question answering against a no-retrieval baseline.
[2]

Models show partial knowledge of their own uncertainty, so an explicit Unknown rule is still required.
[3]

Use this system prompt:

"Use only sources inside this message. For each factual claim, add a source id and a quote of 15 words or fewer. If the sources do not contain the answer, reply only: Unknown. Do not add outside knowledge. Then remove every claim that has no quote."

Assumption: The goal is one system prompt for a general chat model. Why not measured: The message does not name the model or task. Validate by: Run the same 20 questions on that model. If wrong: Swap in a task template that names the allowed fields.

Alternative considered: Train the model to abstain. That loses for this request because training costs more and the request asks for a prompt.

If more than half of the errors are missing documents, do Step 3 before any further prompt edits. If the model cannot see a system role, put the same text as the first user message.
