Headline
No prompt makes a model stop hallucinating.
A source-bound prompt with an abstain rule reduces unsupported claims more than a ban on hallucination.
That gain needs the source text in the same message, because wording does not add facts.
A missing or wrong source still yields a wrong answer.

Background
Language models choose likely next tokens and can state unsupported claims, called hallucination.
They do not verify facts unless the setup forces a check.
The request seeks one prompt that ends hallucination.

Relevance
Unsupported claims cause rework and bad decisions in the current task.
A prompt change is the fastest control available before a model change.

Information
First, use this prompt above the question and the pasted sources.

```text
Use only the sources pasted in this message.
If the sources do not contain the answer, write: Not in the sources.
Do not add facts from memory.
After each claim, quote the supporting span and name its source.
If sources disagree, report both quotes and do not choose.
```
