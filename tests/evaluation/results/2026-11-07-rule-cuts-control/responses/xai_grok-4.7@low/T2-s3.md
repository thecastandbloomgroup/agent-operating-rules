Headline
Use a source-bound prompt, then delete claims the sources do not support.
First, bind the model to the supplied sources.
Next, require a citation on each claim.
Then run a second pass that drops unsupported claims.
Last, measure the error rate on a fixed set.

Background
The request is for one prompt that stops hallucination.
Hallucination means a fluent claim with no support in the sources.
A prompt can lower that rate.
However, it does not end it.

Relevance
A false answer can look sure, so people may act on it.
Therefore, put the prompt in place before a live task.

Information
Use this prompt.
That is, put it in the system slot.

```text
Use only the sources in this message.
If a fact is not in those sources, write: Not in the sources.
Do not add facts from memory.
Cite the source name and section after each claim.
Do not guess a missing name, number, or date.
List each claim.
Mark each claim Supported or Not supported.
Delete each claim marked Not supported.
Write the final answer from the remaining claims only.
```

Closed models still state unsupported facts after a warning prompt [judgment].
Retrieval of source text cuts knowledge errors versus a model with no retrieval [1].
A verification chain also cuts hallucination in reported tests [2].
A lower error rate is likely (66 to 100%).
The basis is the two secondary studies in the References list.

Assumption: the task is question answering with source text on hand.
Why not measured: the material does not state the task.
Validate by: run the prompt on ten real questions.
If wrong: change the source rule to match the task.

Fine-tuning for factual answers is the strongest alternative.
It loses because it costs more and still leaves errors [judgment].

End
I recommend that we use this order.

1. Deterministic.
Given a question whose source lacks the answer,
When the prompt runs,
Then the text is: Not in the sources.
Paste the nine-line prompt into the system slot.
This removes the blocker that memory counts as a source.
Domain: Clear.
Reason: deduction from a known source rule.

2. Deterministic.
Given one question and its source text,
When the model answers,
Then each claim cites a section in that text.
Paste the source under the prompt for one question.
Step 2 MUST NOT start until the test in Step 1 passes.
This removes the blocker that the prompt has nothing to cite.
Domain: Complicated.
Reason: analysis of source spans picks what to paste.

3. Stochastic.
Metric: invented facts per 10 answers.
Baseline: the same 10 answers with no check pass.
Pass threshold: at most 2 invented facts.
Sample size: 10.
Add the list, mark, and delete lines.
Step 3 MUST NOT start until the test in Step 2 passes.
Cap the probe at 10 questions.
Stop the probe if invented facts exceed 2.
This removes the blocker of a citation on the wrong span.
Domain: Complex.
Reason: induction from trials, and a new topic can break the pattern.
Leverage is a guess.

4. Stochastic.
Metric: unsupported-claim rate.
Baseline: 20 questions with no prompt.
Pass threshold: a rate at most half the baseline.
Sample size: 20.
Score 20 held-out questions with the full prompt.
Step 4 MUST NOT start until Step 3 meets its threshold.
This removes the blocker that the error rate stays unseen.
Domain: Complicated.
Reason: analysis of the score picks whether to keep the prompt.

Follow-up
If no source text exists, this prompt refuses most answers.
In that case, add a search step before Step 2.
