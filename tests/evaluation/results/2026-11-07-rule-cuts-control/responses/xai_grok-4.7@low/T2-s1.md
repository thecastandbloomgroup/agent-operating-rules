Headline

No prompt can fully stop false claims stated as facts.

A rule that answers only from given sources blocks many inventions.

A required quote shows which claim has no support.

A second check deletes claims that still lack a quote.

Only a scored sample shows that the false-claim rate fell.

Background

Hallucination means a false claim stated as a fact. The request asks for one prompt that stops this error. Models still produce the error when the prompt only forbids it [judgment].

Relevance

False facts cause rework and bad decisions now. Therefore bind the model to sources before the next factual answer.

Assumption: the task is factual answers with sources in the message. Why not measured: the material does not state it. Validate by: label the next 10 requests as factual or not. If wrong: drop the refusal rule for creative work.

The other option is one line that says never invent facts. It loses because it has no quote rule and no second check. The verification paper shows a second check lowers the error.

[1]

Use this system instruction:

Answer only from the sources in this message. If the sources do not contain the fact, write: I do not know. For each claim, quote the source line that supports it. Do not use outside knowledge to fill a gap. If two sources conflict, report both and do not choose. After the draft, check each claim against the sources. Delete any claim that lacks a quote.

End

Follow-up

If the task is fiction, drop the "I do not know" rule. Replace it with a rule that marks each guess as a guess. That change applies because fiction has no source fact to miss.
