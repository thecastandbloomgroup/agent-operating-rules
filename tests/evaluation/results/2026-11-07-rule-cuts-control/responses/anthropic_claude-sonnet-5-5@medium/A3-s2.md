Yes, enable gzip for the API, because JSON compresses well and the CPU cost is small.

- JSON is repetitive text, so a 400 KB body is likely to shrink by 70 to 90% [judgment].
- Smaller bodies cut transfer time, which matters most for mobile and distant clients.
- Compression costs a few milliseconds of CPU per response at a middle compression level [judgment].
- Gzip is a standard HTTP content coding, so clients that do not support it still get plain JSON.

Your API returns JSON that averages 400 KB per response. You ask whether to turn on gzip, a common compression format for HTTP bodies.
