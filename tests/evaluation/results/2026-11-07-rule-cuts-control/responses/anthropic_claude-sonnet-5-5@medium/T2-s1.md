## Headline

No prompt removes hallucination, but a grounding prompt with an "I don't know" rule and a self-check cuts it most.

- Ground the model in supplied sources, because the model then copies facts instead of recalling them.
- Allow a refusal, because the model otherwise fills gaps with guesses.
- Add a verification pass, because it removes unsupported claims after drafting.
- Test the prompt on your own questions, because results differ by model and task.

## Background

You want one prompt that stops a language model from stating false facts. Hallucination means output that is fluent but not supported by facts or sources [1]. The cause lies partly in the model, so a prompt lowers the rate but cannot set it to zero.

## Relevance

A false claim that looks confident costs you time or trust. A prompt costs nothing to try, so test it first.

## Information

Evidence:

- Grounding in retrieved text improves factual output on knowledge tasks (primary-source experiments in a secondary paper) [2].
- A draft-then-verify routine lowered hallucination in the authors' tests (secondary source) [3].

Large models often judge well whether their own answers are true, so asking for a confidence level is useful (secondary source) [4].

Confidence that this prompt lowers your hallucination rate: likely (66 to 100%), based on the three independent sources above.

The prompt (replace the brackets):

```text
Answer only from the sources below.
If the sources do not contain the answer, write: "The sources do not say."
Do not guess. Do not use outside knowledge.
Quote the sentence that supports each claim.
State your confidence as a percentage.
Then check each claim against the quotes.
Delete any claim that has no quote.

Sources:
[paste text]

Question:
[paste question]
```
