## Headline

No prompt stops hallucination fully, but the prompt below, paired with source documents, cuts it most.

- The prompt lets the model say "I don't know" and forces claims to rest on supplied text.
- Source documents in the context give the model facts, so it guesses less.
- A test on your own questions shows whether the prompt works.

## Background

You asked for one prompt that stops a language model from stating false facts. Models produce fluent text whether or not they know the answer. This is called hallucination: output that is unsupported or false [1].

## Relevance

A false answer that reads well is hard to catch. A prompt costs nothing to try, so test it first.

## Information

**The prompt.** Put it in the system message:

```text
Answer only from the SOURCES below.
Quote the exact sentence that supports each claim.
If the SOURCES do not contain the answer, reply: "Not in the sources."
Do not use outside knowledge. Do not guess numbers, names, dates, or links.
Before you answer, check each claim against its quote. Delete any claim without a quote.
```

**Evidence.**

- Supplying retrieved documents improved factual output on knowledge tasks compared with a model that used only its memory.

  [2]

- A step that drafts verification questions and answers them reduced false statements in tests.

  [3]

- A prompt alone cannot reach zero errors. Likelihood that a prompt removes all hallucination: very unlikely (0 to 10%). [judgment]
- Likelihood that this prompt lowers the error rate on a task with supplied sources: likely (66 to 100%). [inference]

**Assumption log.**

- Assumption: you can supply source text for your questions. Why not measured: the material does not state it. Validate by: run five real questions with sources attached. If wrong: the prompt can only force "I don't know", so Step 1 becomes a search for sources.
- Assumption: the model accepts a system message. Why not measured: the material names no model. Validate by: paste the prompt at the top of a normal message. If wrong: no change in the recommendation.

**Alternative considered.** Fine-tune the model on correct answers. It loses because it costs more than a prompt change and still leaves errors on new topics. [judgment]
