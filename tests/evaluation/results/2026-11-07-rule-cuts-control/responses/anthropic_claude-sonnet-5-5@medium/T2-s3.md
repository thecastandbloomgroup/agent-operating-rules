## Headline

No prompt removes hallucination, but one grounded prompt cuts it most, and the block below is that prompt.

- The prompt works because it limits the model to supplied sources and allows a "not found" answer.
- A prompt alone fails when the sources are missing, so supply the sources.
- Measure the result on your own questions, because the effect size varies by model and task.

## Background

You asked for the best prompt to stop a language model from stating false facts. Models produce fluent text whether or not the facts are known. A prompt can change this behavior but cannot guarantee correctness.

## Relevance

A false answer that reads well is hard to detect. Therefore a prompt that reduces false answers, plus a test that proves it, lowers your risk today.

## Information

Here is the prompt. Paste it into the system message and put your source text inside the tags.

```text
Answer using only the text inside <sources> tags.
Before you answer, copy the exact quotes that support each claim.
Attach the matching quote to each claim.
If the sources do not contain the answer, reply: "Not found in the sources."
Do not use outside knowledge.
Do not guess numbers, names, dates, or links.
If the question is unclear, ask one question before you answer.
```

Evidence:

- Hallucination is a documented, persistent failure in text generation models. The survey covers its causes and mitigations. Confidence: high, one broad survey.

  [1]

- Retrieval of source text before generation improved factual accuracy on knowledge tasks.

  [2]

- Models partly judge whether they know an answer, so a "not found" option is usable. Confidence: medium, one study.

  [3]

- The size of the drop from this prompt on your task is unknown. [judgment]

Assumption log:

- Assumption: you use a chat model and can paste source text. Why not measured: the material does not state it. Validate by: check that your tool accepts a system message. If wrong: use Step 2 with a retrieval tool instead.
- Assumption: your questions are factual, not creative. Why not measured: the user has not answered. Validate by: read ten recent questions. If wrong: apply the prompt only to the factual ones.

Alternative considered: ask the model to check its own answer afterward. It loses because the same model often repeats its own error. [judgment] Source grounding checks claims against text, not against the model's memory.

## End

I recommend that we take these steps, in this order:

1. Build a test set of 100 questions: 70 answerable from your sources and 30 not. Record the baseline rate of unsupported claims with no special prompt.
   - Blocker removed: no way to tell whether any prompt helps.
   - Kind: stochastic. Test first: metric is the share of answers with an unsupported claim. Baseline is the Step 1 result. Pass threshold is a drop of at least 50% relative. Sample size is 100.
   - Domain: Complicated. Deduction from standard evaluation practice.
2. Supply the source text in the prompt, or through retrieval, for every question. Step 3 MUST NOT start until Step 1 has a recorded baseline.
   - Blocker removed: the model has no facts to ground on.
   - Kind: stochastic. Test first: same metric and sample as Step 1. Pass when the threshold is met on all 100 questions.
   - Domain: Complicated. Analysis of where your sources live picks the method.
3. Run the prompt above as a probe, in parallel with Step 2. Budget: one working session and 100 model calls. Stop if the refusal rate on the 70 answerable questions exceeds 10%.
   - Capability added: a "not found" answer for the 30 unanswerable questions.
   - Kind: stochastic. Test first: at least 27 of 30 unanswerable questions return "Not found in the sources."
   - Domain: Complex. Induction from trials. The pattern breaks if the model ignores the tags on long sources. The leverage here is a guess.
4. Add a human check on any answer that drives money, health, or law decisions.
   - Blocker removed: residual errors that no prompt catches.
   - Kind: evaluative. Rubric first: criteria are quote present (weight 50%), quote supports claim (weight 50%). Pass threshold: 100% on both. Evidence: the quote text.
   - Domain: Clear. Best practice: a reviewer compares claim and quote.

If Step 1 shows the baseline is already under 5%, skip Steps 3 and 4 and monitor monthly.
