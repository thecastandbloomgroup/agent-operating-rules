Headline

No prompt makes a model stop hallucinating. The best available prompt grounds every claim in text you provide and allows the answer "I do not know."

The core prompt: "Answer only from the documents below. After each factual claim, add the quote that supports it. If a fact is not in the documents, write: I do not know."

Supporting points:

- Grounding plus forced quotes cuts hallucination more than any wording trick, because the model must point at input text instead of memory.
- A second pass that checks each claim against the source catches most remaining errors.
- Residual errors stay above zero, because the failure is partly in the model, not only in the prompt.

Relevance

A wrong answer costs more rework than a "not found" answer. Prompt changes are cheap to test, so they are the first fix to try.

Information

1. A survey of hallucination research lists training data gaps and decoding behavior as root causes [1]. Because causes sit inside the model and data, a prompt alone cannot reach zero. This contradicts the goal of "stop", so the realistic target is a lower rate.
2. SelfCheckGPT detects false claims by sampling several answers and checking them against each other and the source [2]. This supports the idea of a check pass after the first answer.
3. [judgment] Instructions that allow refusal reduce confabulation. The model then has a low cost path for missing facts, so it takes it instead of inventing one.
4. [judgment] Low temperature alone does not fix it. Deterministic decoding still selects a wrong token with confidence.
