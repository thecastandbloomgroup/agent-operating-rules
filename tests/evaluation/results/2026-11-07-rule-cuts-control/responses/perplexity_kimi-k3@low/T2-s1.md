# Headline

No single prompt stops hallucination, but a prompt that forces abstention and citation reduces it the most [judgment]. The prompt below instructs the model to say "I do not know" instead of guessing, which cuts unsupported claims [judgment]. Retrieval, that is supplying source documents in the prompt, removes hallucination more effectively than any instruction [1]. The prompt works best combined with that source and with a low temperature setting [2].

# Background

Hallucination means the model states false content with confidence [1]. Request asks for one best prompt to prevent that. Model and task type are unspecified, so general-purpose defaults apply.

# Relevance

Wrong answers stated confidently cause more harm than refusals in most downstream uses [1]. A reusable prompt template therefore has direct practical value.

# Information

**Evidence:**

Empirical research finds that large language models (LLMs) tend to produce a guess instead of admitting uncertainty [3]. Instructions that permit abstention reduce error rates [4]. Retrieval augmented generation (RAG), that is grounding the reply in supplied documents, reports the largest factual accuracy gains in these studies [1].

**The prompt:**

```text
Answer using only the information in the sources below.
If the sources do not contain the answer, reply: "I do not have enough information."
Do not fill gaps with general knowledge.
After each factual claim, name the source and section.
If no sources are provided, say what you would need to answer reliably.

Sources:
[paste documents here]

Question:
[paste question here]
```

Key elements and the reason for each:

1. Abstention option: gives the model an accepted exit, so guessing is not required [4].
2. Source restriction: blocks reliance on memorized, error prone facts [1].
3. Attribution requirement: forces each claim to trace to text, which exposes unsupported statements [2].
4. Gap statement: turns missing context into a question to the user, not an invented answer [4].

**Additional settings that matter as much as the wording:**

- Set temperature to 0 to 0.3. Lower randomness reduces invented content [2].
- Paste the actual documents. Prompt instructions alone fail on niche facts [1].
- Ask for verbatim quotes from sources. Quotes are checkable; paraphrases are not [judgment].

**Assumption log:**

Assumption: the target model is a modern instruction-following LLM. Why not measured: the material does not state it. Validate by: run the prompt once on the target model. If wrong: older or base models need few-shot examples instead of instructions.

Assumption: "hallucination" means factual invention, not reasoning errors. Why not measured: the material does not state it. Validate by: check whether failures are false facts or broken logic. If wrong: add a step-by-step verification instruction instead.

**Alternative considered:**

Few-shot prompting with worked examples of "I do not know" responses. It loses because it costs more tokens per call and generalizes less well across topics than an explicit abstention instruction [judgment].

# Follow-up

Conditions that change the recommendation: if the task is creative writing, remove the source restriction. If the model is fine-tunable, training on abstention examples outperforms prompting [3].
