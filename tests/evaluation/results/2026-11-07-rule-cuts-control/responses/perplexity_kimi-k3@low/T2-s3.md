## Headline

No prompt stops hallucination, but the best single prompt is "Answer only from the sources below. If the answer is not there, say 'I don't know.'"

- Prompts reduce hallucination; they do not eliminate it. [judgment]
- Grounding the model in provided sources cuts unsupported claims the most. [judgment]
- An explicit "abstain" instruction lowers the rate of confident wrong answers. [judgment]
- Retrieval (search or documents) plus this prompt beats any prompt alone. [judgment]

## Background

The request is for one prompt that prevents fabricated answers. Hallucination is a property of the model, not only of the input [inference]. So the realistic target is reduction, not elimination.

## Relevance

A wrong prompt gives false confidence. A grounded prompt with an abstain option gives measurable improvement at zero cost.

## Information

**The prompt:**

> Answer only using the sources I provide below. Quote the source for each claim. If the sources do not contain the answer, reply "I don't know" and list what is missing.

Three variants, in order of effect [judgment]:

1. Best: attach real sources (documents or search results), then use the prompt above. Grounding is the largest lever. Retrieval-augmented generation lowers hallucination rates in reported evaluations [no source].
2. Good: add "State your confidence as a probability for each claim." This exposes weak answers.
3. Baseline: "Think step by step and cite a source for every fact." Helps, but the model can fabricate citations.

No prompt reaches zero hallucination. High confidence, this follows from models generating plausible text rather than verified facts [inference]. Verification (a second pass, a tool, or a human check) is the only path to near-zero rates [judgment].

**Alternative considered:** fine-tuning or switching models. It loses because it costs more and still requires grounding [judgment].

## End

I recommend that we do the following:

1. Add the grounding prompt to every query where accuracy matters (Clear: a known best practice exists, deduction). Test: Given a question not covered by the sources, When the prompt runs, Then the model replies "I don't know." Deterministic.
2. Attach source documents or search results before the query (Clear, same test as Step 1). This removes the largest blocker: missing facts.
3. Add a verification pass for high-stakes answers: have a person or tool check each cited quote against the source (Complicated, analysis needed to pick the check). Test: rubric with criteria "citation matches source" and "claim supported," pass at 100% on a sample of 20 answers. Evaluative.
