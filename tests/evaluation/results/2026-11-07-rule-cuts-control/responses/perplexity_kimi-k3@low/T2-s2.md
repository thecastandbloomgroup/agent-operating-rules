Headline

No prompt can stop hallucination, but the strongest single tactic is to require the model to quote sources from its context before answering, and to answer "I don't know" when no quote exists. Three supporting points:

1. Forcing a quoted citation grounds the answer in provided text instead of the model's memory.
2. Permission to say "I don't know" removes the hidden pressure to always produce an answer.
3. Verification works better than prohibition: checks beat commands like "do not hallucinate."

Background

You asked for the best prompt to reduce hallucination, that is, fabricated statements a language model presents as fact. The user message contains no details about your model or use case.

Relevance

Hallucination is a statistical behavior, not a bug a sentence can switch off. Prompting reduces its rate but cannot reach zero, so knowing which prompt helps, and its limits, sets correct expectations.

Information

Prompt-based citations and "answer only from context" instructions measurably reduce fabricated claims in retrieval setups [judgment]. A command like "do not make things up" fails because the model cannot inspect its own reliability in that step [judgment].

The recommended prompt (fill the brackets):

```
Answer using ONLY the text in [DOCUMENTS]. Before each claim,
quote the exact passage from the text that supports it. If the
text does not contain the answer, reply: "I don't have enough
information." Never fill gaps with outside knowledge.
```

Letting the model say it lacks information is the key part. Models trained to always answer produce confident filler when evidence is absent [judgment]. For open tasks with no documents, add: "List every factual claim you make. Mark each [verified] or [uncertain]."
