## Background

The service is an order status API in one file, `service.py`. It writes 14 messages with `print`, and one of them goes to stderr. The request is to use the standard `logging` module at INFO level.

## Relevance

`print` output has no timestamp, no severity, and no filter. With `logging`, operators can sort and filter lines when they find a fault.

**Changed code** (all other lines stay as they are)

```python
import logging

logger = logging.getLogger(__name__)
```

In `main`, set up logging first:

```python
def main():
    logging.basicConfig(
        level=logging.INFO,
        stream=sys.stdout,
        format="%(asctime)s %(levelname)s %(name)s %(message)s",
    )
    logger.info("starting order service on port %s", PORT)
    conn = connect()
    init_db(conn)
    Handler.conn = conn
    server = HTTPServer(("", PORT), Handler)
    try:
        server.serve_forever()
    except KeyboardInterrupt:
        logger.info("stopping")
    finally:
        conn.close()
        logger.info("database closed")
```

The other calls change as follows:

The `ERROR` and `WARNING` prefixes are dropped, because the level field now carries them. The `sys` import stays, because `main` uses `sys.stdout`.
