Checkout fails for all users since 09:12. You are the on-call engineer. The exec call starts in ten minutes.

## Relevance

## Information

- Impact: 100% of users get 500 on checkout, from 09:12 (your report).
- Mitigate first and diagnose later. This practice shortens outages [1].
- Cynefin domain: Chaotic. Every user fails and the cause is not visible, so stabilise first [2].

Assumption log:

A3. A status channel exists for executives. Why not measured: the material does not state it. Validate by: open the incident channel. If wrong: send the update by email.

Alternative considered: find the root cause before any change. It loses because the cause is unknown and a rollback takes minutes [1]. Also, a wrong guess is cheap to reverse [judgment].

1. **Roll back the latest change (minutes 0 to 4).**
   - Increment: list changes from 08:42 to 09:12, then roll back the newest one.
