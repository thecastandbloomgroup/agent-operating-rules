1. **Capture failures.** Copy the last 10 failed-job logs into one file. Increment: one file, one session. Blocker removed: no shared evidence. Domain: Clear, because log collection has a known best practice. Test first (deterministic):

   `Given the CI job history, When the collection script runs, Then the file holds 10 failure names with timestamps.`

2. **Classify each failure into one bucket: test logic, environment, or external dependency.** Increment: a filled table. Blocker removed: unknown cause mix. Domain: Complicated, because an expert reads each log. Test first (evaluative rubric): criteria are bucket match to log text (weight 1.0, pass = every row has a quoted log line as evidence). Step 2 MUST NOT start until the test in Step 1 passes.
3. **Probe the top bucket.** Disable the single worst test and rerun the suite 20 times. Increment: one quarantined test plus 20 runs. Blocker removed: no confirmed cause. Domain: Complex, so this is a capped probe with a budget of one day. Test first (stochastic): metric = pass rate, baseline = current rate, pass threshold = 20 of 20 passes with the test disabled, sample size = 20 runs.
4. **Fix the confirmed cause**, for example replace a fixed sleep with a wait on a condition. Increment: one merged fix. Blocker removed: the defect itself. Domain: Complicated, because the probe in Step 3 identifies the cause. Test first (deterministic):

   `Given the fixed test, When the suite runs 20 times, Then pass rate is 20 of 20.`

If A1 is wrong, replace Step 3 with a dependency-cache and toolchain check. If A2 is wrong, run Step 3 locally.
