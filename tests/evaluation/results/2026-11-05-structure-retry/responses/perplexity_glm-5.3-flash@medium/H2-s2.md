# Headline

Stop all external statements now, verify the facts within 24 hours, then issue one correction through a single owner: this sequence protects the company better than a fast public response.

- The freeze stops new damage while the facts are unverified [judgment].
- One named owner removes the conflict between legal, PR, and the board, because they all route through it.
- The correction follows the verified facts, so it cannot become a second false statement.

# Background

A journalist published that the CEO's statement from yesterday was false. Legal, PR, and the board send conflicting instructions. The request is a set of next steps for today.

# Relevance

Each uncoordinated hour raises the cost of the correction, because groups that speak at cross-purposes become new stories [1].

# End

**I recommend that we** run these five steps in this order.

**Step 1, within the next hour: freeze and centralize.** Send a one-line directive to legal, PR, and the board: no external statements or replies, and all inquiries go to one named coordinator [1]. This removes the blocker: uncoordinated messages. Domain: Chaotic, because cause and effect are invisible in a live crisis, so the move is act first. Kind: deterministic. Test, written first:

```gherkin

When a journalist contacts any of them
Then they respond only with the coordinator's contact
```

**Step 2, today, end of day, and it MUST NOT start before Step 1: build the fact file.** Collect the full text of the CEO statement, the full article, and every piece of evidence behind each. This adds the capability to judge what happened. Domain: Confused, because the domain of the problem itself is unknown, so the action gathers what is needed to classify it. Kind: deterministic. Test, written first:

```gherkin
Given the statement and the article exist
When the fact file is compiled
Then it contains both full texts and each piece of evidence with its source and date
```

**Step 3, tomorrow morning: decide the path.** Score three paths with a rubric: full correction, partial correction, or standing by the statement. Criteria and weights: evidence strength, 40%; legal exposure, 30%; stakeholder impact, 30%. Pass threshold: one path with a documented score, no default. Evidence needed: the fact file and legal's check on A3. This removes the blocker: the owner cannot publish without a decision. Domain: Complicated, because analysis by legal picks the correct practice among several. Kind: evaluative; this rubric is the analysis. Domain check on A3 runs inside this step.

**Step 4, within 24 hours after Step 3 passes: publish one correction.** The coordinator publishes the approved statement on one channel, with all other channels pointing to it. This removes the blocker: the public record stays false. Domain: Complicated, because the practice is picked by deduction from the Step 3 decision plus legal analysis of the draft. Kind: deterministic. Acceptance test, written before drafting:

```gherkin
Given the decision from Step 3
When the draft is released
Then it matches that decision, contains no new unverified claim, and carries legal's sign-off
```

**Step 5, same day as Step 4: brief all three groups with one page.** Send the same memo to legal, PR, and the board, and hold a 15 minute joint call. This removes the blocker: the misalignment that started this request. Domain: Clear, because everyone knows the best practice, one agreed text, so the action applies it as one step. Kind: deterministic. Test, written first:

```gherkin
Given the approved memo
When each group is briefed
Then all three groups hold the same text before the next external contact
```
