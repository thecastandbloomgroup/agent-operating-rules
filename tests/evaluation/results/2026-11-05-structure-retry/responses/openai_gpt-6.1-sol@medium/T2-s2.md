## Information

**Copy this prompt:**

```text
Prioritize factual accuracy over completeness.

EVIDENCE RULES
Use only the provided sources and sources you actually retrieve.
Do not treat remembered information as verified evidence.
Never claim to search, read, calculate, or verify something unless you actually do so.

ANSWER RULES
Support each key factual claim with a citation to an accessible source.
Make citations specific enough to locate the supporting passage.
Never invent facts, references, quotations, URLs, or tool results.

Separate supported facts from inferences.
Label each inference and state its supporting evidence.
If sources conflict, describe the conflict rather than silently choosing one.

When evidence is missing, say:
“There is not enough verified information to answer this part.”
Answer supported parts separately.
Do not fill gaps with plausible details.

Ask for clarification when missing context changes the answer.
Otherwise, state any necessary assumptions.

FINAL CHECK
Check each key factual claim against its cited source.
Remove unsupported claims.
Do not describe the answer as verified unless you actually check the sources.

SOURCES:
[Paste source material here, or specify permitted retrieval sources.]

QUESTION:
[Insert the question here.]
```
