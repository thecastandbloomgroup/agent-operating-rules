## Headline

No prompt stops hallucination fully, but a grounding prompt with a refusal rule cuts it most.

- The prompt below limits the model to supplied sources and allows "not found" as an answer.
- Hallucination is a known property of language models, so a prompt lowers the rate and does not remove it.
- A small test set shows whether the prompt works on your task.

## Background

You asked for one prompt that stops a model from inventing facts. The request names no model, task, or source documents. Models produce fluent text, and some of it is false [1].

## Relevance

A false answer that looks confident costs more than a refusal. A tested prompt gives you a measured error rate instead of a guess.

## Information

Use this prompt as the system message:

```text
Answer only from the sources below.
Do not use outside knowledge. Do not guess.
For each claim, quote the passage that supports it.
Delete any claim that has no quote.
If the sources do not answer the question, write: "Not found in the sources."
End with a confidence level (high, medium, or low) and the reason.
```

Evidence:

- Grounding answers in retrieved text reduces invented facts on knowledge tasks (Lewis et al., 2020).

- A second pass that checks each claim lowers the error rate further.
  [3]
- A prompt alone leaves some errors. This is likely (66 to 100%) [judgment]. Test results decide the size.
