## Headline

No single prompt stops hallucination, but a grounding prompt with an abstain rule reduces it the most.

- The prompt restricts the model to sources that you supply.
- The prompt allows the answer "Not found in the sources."
- The prompt forces a supporting quote for each claim.
- A test on your own questions confirms the effect, because results differ by model.

## Background

Hallucination means the model states facts that no source supports [1]. You asked for one prompt that stops it. A prompt changes model behavior but does not change how the model generates text.

## Relevance

An unsupported claim looks the same as a correct one. A prompt that reduces such claims lowers your review cost now.

## Information

Here is the prompt:

```text
Answer only from the sources below.
If the sources do not contain the answer, write: "Not found in the sources."
Before each claim, quote the source sentence that supports it.
Delete any claim that has no quote.
Do not guess. Do not use outside knowledge.
```

Evidence:

- A second pass that checks each claim against the sources lowers hallucination in the cited study, compared with its baseline [2].
- Source: Dhuliawala et al., Chain-of-Verification, 2023.
- The prompt reaches zero errors with under 10% likelihood. [judgment]
- The grounding prompt reduces errors with likely (66 to 100%) odds, because it removes the need to recall facts. [judgment]
