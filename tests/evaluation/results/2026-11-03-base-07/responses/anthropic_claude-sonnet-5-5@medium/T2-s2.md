## Headline

No single prompt stops hallucination (a confident statement that the source does not support), but a grounding prompt cuts it the most.

- The prompt must limit the model to supplied text, because the model then has a source to check against.
- The prompt must allow "the documents do not say", because the model otherwise fills gaps with guesses.
- A test set must measure the result, because the effect of a prompt varies from run to run.

The request asks for one prompt that ends hallucination. The material names no model, task, or source documents. A prompt changes how the model behaves, but it does not change what the model knows.
