Headline
No prompt ends hallucination, so use a source-only rule, fetched text, and a fixed test.
A source-only rule blocks claims that the input does not support.
Fetched text cuts errors that wording alone cannot reach.
A second check finds claims the first pass still invents.

Background
Hallucination means a false statement given as fact.
Language models sometimes do this when the input lacks the fact.
The request asks for one prompt that ends this behavior.
Prompt text can limit invention, but it does not remove the cause alone.

Relevance
False facts in answers create rework and bad decisions.
A tested source rule lowers that risk on the next factual task.

Information
A survey groups hallucination causes across generation tasks [1].
Therefore a ban on false facts does not cover every cause.
Retrieval-augmented generation means the model reads fetched text, then answers [2].
So the answer depends less on memory for facts outside the message.
No published prompt removes hallucination on all tasks [judgment].
Confidence is high, based on the survey and the retrieval paper.
Use this prompt when source text is in the message.
Answer only from the sources in this message.
If the sources do not hold the answer, write: Not in the sources.
Do not add facts from memory.
For each claim, name the source line that supports it.
If sources conflict, quote both and do not choose.
A1. The task is factual question answering. Why not measured: the material does not state it. Validate by: run one creative sample. If wrong: the gap reply blocks useful output.
A2. Source text can enter the same message. Why not measured: the material does not state the interface. Validate by: paste one page and ask a question from it. If wrong: add retrieval before the prompt.
The strongest alternative is a long ban that says never invent facts.
It loses because the model still has no evidence to check against [judgment].
