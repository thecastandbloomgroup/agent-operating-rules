Background
You asked for the best prompt to stop a model from hallucinating. A model can invent facts when it answers from memory. Therefore the prompt must lock the answer to text you supply.

Relevance
False claims cost review time and can reach users. The prompt below is ready to paste today.

Information
Hallucination here means a fluent claim that the supplied sources do not support.
[judgment]

Closed-book means the model answers from memory, with no documents. Retrieval means the model reads fetched documents, then answers.

A survey treats this error as a known failure, not a rare bug.
[2]

Retrieval plus generation beats closed-book answering on open-domain questions.
[1]

Therefore the prompt should force source use, not only ask the model to be accurate.

```text
Answer only from the sources in this message.
Cite each factual claim with the source name and location.
If the sources do not contain the answer, reply only: Not in sources.
Do not use outside knowledge.
Do not fill gaps.
If two sources conflict, state both claims and cite each one.
```

A2. Source text will sit with the question. Why not measured: the material does not state the workflow. Validate by: run one question with a pasted paragraph. If wrong: add retrieval before live use.

Alternative considered: The strongest other option is a prompt that only says to be accurate. It loses because it sets no source limit, so memory errors remain.
[judgment]
