## Headline

Build a measured quality loop before changing the summariser, because agents report errors but no baseline exists. Instrument sampled summaries, classify failures, and set pass thresholds. Tune prompts, retrieval, and review flow only against those measures. Keep a human check for high risk tickets until the error rate stays low.

## Background

The support tool added an LLM summariser. Agents say it is “sometimes wrong,” and no metrics exist [1]. The request is to make it better without a defined target.

## Relevance

Unmeasured edits can hide failure modes and raise risk in customer replies. A small evaluation set turns agent complaints into rates, causes, and release gates.
