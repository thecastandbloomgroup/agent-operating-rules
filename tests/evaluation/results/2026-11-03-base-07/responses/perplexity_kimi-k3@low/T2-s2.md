# Headline

There is no prompt that stops hallucination, but one instruction reduces it measurably better than others. Forcing the model to cite or abstain is the effective technique. Long "do not hallucinate" instructions do not work (high confidence, consistent with published research).

# Background

The request is for a single best prompt to stop hallucination. Hallucination means the model states false content as fact.

# Relevance

This matters now because a wrong fix gives false trust. Picking the right instruction changes output quality in the next session.

# Information

Evidence: studies show self-critique and refusal-when-unsure prompts cut factual error, while pleas like "be accurate" add no gain [1]. Retrieval grounding cuts error more than any prompt alone [2]. The claim that retrieval beats prompting rests on secondary sources here, so treat it as likely, not certain.

The strongest alternative is "write a detailed system prompt forbidding invention." It loses because large models do not reliably follow negative meta-instructions; they lack access to their own uncertainty without a grounding signal. [judgment]

Best prompt, adapted to the use case:

> "Answer only from the provided text. Quote the passage that supports each claim. If the answer is not in the text, write 'Not in source.'"

If no source text exists:

> "Answer only if you are confident. If unsure, say 'I do not know' instead of guessing. Mark each factual claim with its source or with [unverified]."

A1. The use case allows a pasted source text. Why not measured: the material does not state it. Validate by: ask which mode applies. If wrong: use the second prompt form above.

# End

I recommend that we do these steps:

1. Paste the source text. Prepend: "Answer only from this text." Increment: one session. Blocker removed: ungrounded invention. Domain: Clear, because the practice is known and repeatable. Test first (deterministic):
   - Given a question whose answer is absent from the source,
   - When the model answers,
   - Then it replies "Not in source" in 10 of 10 trials.
2. Where no source exists, use the abstention prompt in Information. Blocker removed: confident guessing. Domain: Clear, same reason. Test (stochastic): 30 known-answer questions; baseline the current error rate; pass when false claims fall by half.
3. For recurring use, add retrieval of real documents. Blocker removed: dependence on model memory. Domain: Complicated, because setup needs analysis. Test (stochastic): same 30-question set; pass at error rate under 5%.

Step 3 MAY start in parallel with Step 1. If A1 is false, skip Step 1 and start at Step 2.
