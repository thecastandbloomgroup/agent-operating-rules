## Headline

Use a verification-first prompt that forces sources, uncertainty, and refusal when evidence is missing; no prompt can fully stop hallucination.

- A prompt can reduce confident invention, but it cannot prove every claim is true.
- The best prompt makes the model cite evidence, mark unknowns, and separate facts from guesses.
- The larger gain comes from testing outputs against sources, not from wording alone.

## Background

The request asks for one prompt that makes a model stop hallucinating. Hallucination means fluent output that is false, unsupported, or misattributed.

## Relevance

This matters because a better prompt is cheap to deploy now. It matters because unsafe trust in fluent text can spread errors fast.

## Information

Copy this prompt:

```text
Answer only from the provided sources or from knowledge you can support.
For every factual claim, output:
1. Claim.
2. Source name, URL, or exact quote.
3. Confidence: high, medium, or low.
If the source is missing, say "unknown".
If sources disagree, show both sides.
Do not invent citations, dates, numbers, quotes, or links.
Keep the answer short.
End with a list called "Unverified" for anything not proven.
```

Evidence: risk guidance frames generative errors as measurable risks to map, measure, and manage, not remove by instruction alone [1]. Vendor prompt guidance also puts clear tasks, context, references, and explicit output rules before clever wording [2]. The exact wording above is [judgment] based on those two practices.

The strongest alternative is a stricter prompt such as "never be wrong." It loses because it gives the model no testable way to handle missing evidence and can increase concealed error [judgment].

## End

1. Adopt the verification-first prompt above in the next session. Increment: paste it once before the next task. Blocker removed: unsupported claims can enter without a visible unknown state. Test, deterministic: Given a question with no sources, When the model answers, Then the answer contains "unknown" or a source for each factual claim. Cynefin: Clear, because a fixed template already exists.

2. Add a two-source rule for consequential answers. Increment: require two independent sources for any medical, legal, financial, or production change.
