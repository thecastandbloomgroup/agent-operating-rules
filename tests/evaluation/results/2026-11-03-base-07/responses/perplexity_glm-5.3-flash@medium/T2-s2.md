# Headline

No prompt can stop hallucination by itself, so the best fix is the prompt below plus restriction to supplied context, a verification pass, and a measured test.

- A prompt can force quotes, refusal, and a warning label for low-context answers.
- Restriction to supplied documents removes the model's use of outside knowledge.
- A second-pass check catches claims that survive the prompt.
- A measured eval decides whether any change actually reduced the error rate.

# Background

The request: give one prompt that makes a model stop producing false content. This response assumes a chat model used through a prompt, with no retraining.

# Relevance

Hallucination directly damages trust in any output the reader cannot check. The fix costs one working session to install and test.

# Information

**Evidence.** Hallucination is defined as generated content that is not faithful to the source [1]. Recent work argues the error comes from training rewards that favor plausible answers over correct ones, so instructions change behavior but do not remove the source [2]. Theme: methods that measurably cut hallucination combine grounding, refusal, and verification; two sources in this session support this theme [1] [2]. Confidence: high for the mechanism, medium for any specific percentage, as no run in this session measured it.

**Assumption log.**

- A1. The user means a chat model, not a fine-tune or product feature. Why not measured: the user has not answered. Validate by: check the stated model name and task. If wrong: the recommendation shifts to data-level fixes [2].
- A2. The task has a source of truth, such as documents or a database. Why not measured: the request states no context. Validate by: confirm whether documents exist for the task. If wrong: replace Step 2 with web retrieval and accept a weaker verification.

**Alternative considered.** The alternative is a bare instruction, for example "never invent anything, always be accurate." It loses because instruction alone does not change how the model samples answers, and the model still fills gaps with plausible text [2] [judgment].

## The prompt

```text
You answer only from the supplied context.
Before each factual claim, quote the sentence in the context that supports it.
If the context does not support the claim, write: "Not answered by the supplied documents."
Do not use outside knowledge.
Do not fill gaps with plausible text.
State one line of warning when the context covers less than half the question.
```

# End

I recommend that we install and measure the fix in four moves.

**Step 1 (Clear).** Add the prompt above as the system prompt for the task. This removes output that lacks quotes or refusal, in one session. The test is deterministic: 
Given a new session on the target model, 
When the system prompt is set and a context-aware question is sent, 
Then each answer contains either a quoted context sentence or the exact refusal line.

**Step 2 (Complicated).** Restrict each answer to passages from the supplied source through retrieval. This requires analysis to pick the retrieval source, so the domain is Complicated. This step MUST NOT start until the test in Step 1 passes. The test is deterministic:
Given a question about the supplied source,
When retrieval runs before generation,
Then the answer quotes only retrieved passages and adds no outside claims.

**Step 3 (Complex), run in parallel with Step 1 and Step 2.** Probe prompt wording with a measured eval, because cause and effect here become visible only after a run. The measure is a factual error rate: wrong claims divided by total claims, on a fixed question set with known answers. The baseline is the plain "always be accurate" instruction. The pass threshold is at least a 30 percent relative cut in the error rate. The sample size is 30 questions per variant. The stop condition is three prompt variants with no cut in error, at which point the wording work stops. The budget is one working session. Leverage here is a guess.

**Step 4 (Clear).** Add a second pass in which the model, or a second model, checks every claim against the context and flags any claim without a quote. This catches claims that survive Steps 1 to 2. Step 4 MUST NOT start until the eval in Step 3 meets its threshold. The test is deterministic:
Given an answer from Step 2,
When the second pass runs,
Then every claim carries a context quote, or the answer carries a warning label.

# Follow-up

Conditions that change the recommendation: if the model produces no supplied context in its task, replace Step 2 with web retrieval and treat Step 4 as mandatory. If A1 is wrong, the fix moves to training data and reward design [2].
