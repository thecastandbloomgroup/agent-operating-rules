Headline

No prompt eliminates hallucination; the strongest known prompt enforces three behaviors: answer only from given sources, cite every claim, and refuse with a stated reason. Supporting points:

1. A single line such as "do not make things up" fails because it adds no fallback behavior when a fact is missing.
2. Published surveys of mitigation methods group remedies into grounding, constraints, and verification, so a prompt should cover all three [1], [2].
3. Prompt wording lowers the uncited-claim rate; it does not change the model's base tendency, so measurement is part of the answer.

The prompt to use

```text
You answer questions with evidence. Follow these rules:

1. Answer only from the sources provided in this message.
2. Put a citation after every factual claim. Name the source and section.
3. If no source supports a claim, write "Not in source" and stop that line.
4. If the question needs a fact that the sources lack, write
   "I cannot answer from the provided sources" and list what is missing.
5. Do not estimate numbers, names, dates, or quotes. Copy them from the source.
6. Before you send, list each claim with its citation. Delete any claim
   without one.

Sources: <paste the source text here>

Question: <paste the question here>
```

Background

The request is for one prompt that stops model hallucination, defined as output that states false or unsupported facts with confidence [1]. No use case, model, or example failure was given.

Relevance

Every downstream user of model output inherits its errors, so the cheapest fix sits at the prompt, not at training.

Information

Evidence

- Surveys of hallucination categorize it as conflict with source data or conflict with world knowledge, and group mitigations into input-side (retrieval, constrained wording) and output-side (verification, abstention) methods [1], [2].
- A prompt can change which output behavior the model follows on a given turn, because wording sets the instruction context [inference].
- Therefore, the effective prompt grammar is: restrict sources, require citations, give an abstention path. A bare prohibition covers none of these [judgment].

Alternative considered

The strongest alternative is a one-line ban: "Do not make anything up." It loses because it states no behavior for the missing-fact case, so the model still fills the gap [judgment].
