# Headline

No single prompt stops a model from inventing facts; a prompt lowers the rate, and source grounding plus checking controls it.

- Language models produce fluent text even when they lack the fact, so invented statements come from the training setup, not from bad wording [1][2].
- Published prompt trials show the wording changes the rate of invented facts, both up and down, so editing the prompt is a real but partial fix [3].
- The control that works is to give the model the source text, make it refuse when the text lacks the answer, and check the output.

# Background

The request asks for one prompt that makes a model stop hallucinating [2]. "Hallucinating" here means stating false facts in fluent text. The user wants a practical fix now, in one message.

# Relevance

Invented facts spread into notes, code, and decisions. Each one costs time to find and correct, so the fix pays back on the next question.

# Information

**Evidence.** A theoretical result states that a model which stays calibrated to its training data must invent facts when asked about topics outside that data [1]. A survey of mitigation methods groups prompt changes as one class of fixes and reports that they lower, but do not remove, invented facts [2]. Prompt trials on models found that instructions to answer with care and to ask about unknown details change the rate of invented facts in both directions [3]. Therefore the wording of the prompt is a lever, not a switch.

**Assumption log.**

A1. The user uses a chat model and can edit a system prompt or saved instruction. Why not measured: the user has not answered. Validate by: inspect one session setting. If wrong: the same rules go into the question text instead.

**Alternative considered.** Fine tuning or model choice reduces the rate more than any prompt [2]. It loses here because the user asked for a prompt, and a prompt costs nothing to test [inference].

# End

I recommend that we (1) ground the model in source text, (2) add a refusal rule, (3) measure the change, and (4) check high-stakes answers by hand.

1. **Ground each question in the source text.** Paste the relevant document into the context before the question. This removes the blocker: a model with no source must guess. Test, deterministic, write first:
   - Given a source text and one question
   - When the model answers
   - Then every sentence traces to the text or reads "the text does not say"
   - Domain: Clear, because applying a known best practice covers it.

2. **Add a refusal rule and a trace rule to the prompt.** Apply this test before you write the final text. Write rules in this form: "Answer only from the text above. If the text lacks the fact, write: I do not know. For each claim, name its passage." This removes the blocker: open-ended permission to fill silence. Test, deterministic:
   - Given a question the text does not answer
   - When the model answers the test prompt
   - Then the model writes "I do not know" and adds nothing else

3. **Measure the change.** Let this run as capped checks, not as a hard test. Run 20 questions with known answers, count false statements, and compare with the rate before the change. Use a post-hoc check: pass threshold (t) is the false statement rate at or below one half of the baseline; minimum questions (n) is 20. Domain: Complicated (test 3), because the result needs analysis before trust. Test, deterministic:
   - Given a set of 20 questions with known answers
   - When the model answers each question
   - Then the false statement rate does not exceed one half of the baseline rate
   Dependency: Step 3 MUST NOT start until the rules in Step 2 are in the prompt.

4. **Check high-stakes answers by hand.** Do the trace check against the primary source when a wrong answer costs time or money. Test first, evaluative: criteria (a) each claim traces to a source passage, (b) each fact matches the source, (c) no invented number appears; pass bar is 80 percent with each check equal in weight (t). Domain: Complicated, because the check needs judgment, not a fixed rule.

Likelihood for step 1 plus step 2: likely (66 to 100%) [judgment, grounded in the trials in [3]].
