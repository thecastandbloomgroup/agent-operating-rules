### Define what “better” means

Use three separate measures. The thresholds below are proposed pilot rules, not measured results. [judgment]

| Measure | Definition | Proposed pilot rule |
|---|---|---|
| Factual error rate | Share of summaries containing an unsupported or contradicted statement | At most half the current rate |
| Required-information coverage | Share of required facts that the summary includes | No worse than the current version |
| Agent effort | Median time agents need to check and correct a summary | No worse than the current version |

Also count **serious errors** separately: errors that change the required action, customer commitment, account identity, or safety decision. [judgment]

Set a zero-serious-error gate for the pilot. Passing that gate does not prove a zero error rate in production. [judgment]
