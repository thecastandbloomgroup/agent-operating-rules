## Headline

Replace all 14 `print()` calls with `logger.info()` and configure logging at `INFO` in `main()`.

- Keep the service’s database and HTTP behavior unchanged.
- Route request logs through the same logger.

## Background

The supplied service uses `print()` for startup, database, request, and error messages. Its HTTP handler also overrides `log_message()` with `print()`. [1]

## Relevance

This change puts the existing messages under standard logging control without changing response bodies or status codes. [judgment]

## Information

All existing messages use `INFO`, including those containing `WARNING` or `ERROR`, as requested. The patch preserves their text and uses deferred `%s` formatting.

**Alternative considered:** Use `warning()` and `exception()` for problem messages. This adds severity distinctions beyond the requested `INFO` conversion. [judgment]

The checks below are acceptance tests, not executed results.
