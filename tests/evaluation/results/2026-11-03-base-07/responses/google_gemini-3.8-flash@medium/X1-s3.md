# Background

You deployed a Large Language Model (LLM) summariser in your support tool, but support agents report that it is sometimes incorrect. The team has no metrics to measure summarisation quality, error frequency, or user dissatisfaction. Therefore, you need a measurement framework and concrete prompt improvements to raise summary accuracy.

# Relevance

Without quantitative metrics, you cannot determine if model changes improve quality or cause regressions. Establishing a baseline now lets you resolve agent distrust before bad summaries harm customer interactions.
