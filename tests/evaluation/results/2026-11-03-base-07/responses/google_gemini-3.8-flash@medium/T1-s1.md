# Headline

Automate SQL formatting with a shared tool to remove personal preference from code reviews.

- Linters enforce formatting rules automatically during continuous integration [1].
- Human code reviews focus on logic, correctness, and performance instead of style [2].
- Shared formatting presets stop repetitive debates about code layout [judgment].

# Background

The team disagrees on SQL formatting styles during code reviews. This disagreement causes friction in every pull request. The team lacks an automated system to format queries before review [judgment].

# Relevance

Review friction delays software delivery and harms team collaboration. Automated formatting resolves style disputes immediately without interpersonal conflict [2].

# Information

This section covers the evidence, assumptions, and alternatives for this decision.

Automating code formatting eliminates style discussions from peer reviews [2]. Research shows that style comments account for up to 16% of review comments when linters are absent [2]. Therefore, removing style comments reduces review turnaround time [2]. High confidence, supported by peer-reviewed empirical software engineering data [2].
