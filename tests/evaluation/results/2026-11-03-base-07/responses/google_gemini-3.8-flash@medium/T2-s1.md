You asked for the best prompt to stop model hallucinations. Language models produce false assertions because next-token prediction lacks an internal truth model [1]. Prompts can constrain generation, but prompts cannot eliminate structural training limitations alone [inference].

### Relevance

Using an ungrounded prompt in production risks presenting false statements as facts to users. Applying structured grounding constraints reduces factual errors immediately without retraining the model.

### Information

Specifically, instructions that explicitly permit refusal reduce unforced errors [2]. Therefore, effective prompts combine three elements: provided reference text, an instruction to use only that text, and a direct refusal fallback.
