## Headline

No prompt stops hallucination, so use a source-bound prompt that requires a quote or Unknown.

## Background

The request asks for the best prompt to stop hallucination. Hallucination means a stated fact that the supplied source does not support. The prompt below is the strongest prompt control for that failure.

## Relevance

Fluent unsupported facts waste review time. This prompt forces a gap the reader can see before use.

## Information

Surveys define the failure as output that is unfaithful to the source.
[1]

They also treat the prompt as one control among training and decoding.
[2]

Therefore the prompt cannot remove the failure alone. [judgment]

Assumption: The task is answers over text the user supplies. Why not measured: The material does not state the task type. Validate by: Run one question with a source and one without. If wrong: Insert retrieved text into SOURCE first, or most answers will be Unknown.

Alternative considered: The line "Do not hallucinate." It loses because it sets a goal and gives no quote to check. [judgment]

Use this prompt.

Answer only from the text in SOURCE.

For each claim, quote the shortest span that supports it.

If SOURCE has no support, write Unknown.

Do not add a name, number, or date that SOURCE does not contain.

Label any step past the quote as Inference.

Delete any claim that has no quote.
