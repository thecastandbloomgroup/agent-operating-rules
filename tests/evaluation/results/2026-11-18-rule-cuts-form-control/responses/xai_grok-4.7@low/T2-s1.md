Background
The request asks for one prompt that stops invented facts. Hallucination is a fluent claim that the given sources do not support. A prompt can lower that rate, but it cannot set the rate to zero.

Relevance
An unchecked answer can drive a wrong decision in the current task. Therefore the prompt should make missing evidence visible before use.

Information
This section covers the control, the evidence, and the prompt text. The main control is retrieved text plus a grounded instruction. A ban on the word hallucination does not add evidence.

Lewis and others report gains when retrieval comes before generation.
[1]

A review, which is a tertiary source, still records unsupported claims after instruction methods.
[2]

Therefore a prompt is a control, not a proof of truth. [judgment] It is likely (66 to 100%) that the prompt below cuts unsupported claims when sources are in the message. [judgment]

Assumption: The goal is a copy-paste instruction for a general chat model, not a full retrieval system. Why not measured: The material does not state it. Validate by: Ask which product is in use and whether documents are attached. If wrong: Replace the prompt with a retrieve step before the same instruction.

Alternative considered: A line that says "Never hallucinate," plus a temperature of zero. It loses because it adds no text the model can check.

Use this prompt:
Use only the sources in this message.
If those sources lack the answer, reply: Not in the sources.
For each factual claim, quote the supporting sentence.
Mark any step past the sources with the word Inference.
Do not use outside knowledge to fill a gap.

Follow-up
If no source text exists, the prompt will abstain on most questions. In that case, put a retrieve step before the prompt.
If the task must use general knowledge, the abstention line will block useful answers. In that case, label those answers Unverified instead of banning outside knowledge.
