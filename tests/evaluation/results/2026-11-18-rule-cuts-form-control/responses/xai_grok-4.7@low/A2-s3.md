## Headline

Rename `orders.user_id` to `account_id` inside a transaction, and commit only after the name check passes.

- The rename changes the column name and does not rewrite row data.
- Set a 3 second lock limit first, so a blocked lock fails fast.
- Functions and application code that still use the name `user_id` do not change.
- Roll back if the new name is missing.

## Background

The orders table has a column named `user_id`. The request is to rename it to `account_id` before a flight. The catalog is the database record of table structure, and this change updates that record.

## Relevance

The statement takes an exclusive lock on `orders` until it finishes. Therefore a lock wait or a broken caller is hard to fix after boarding.
