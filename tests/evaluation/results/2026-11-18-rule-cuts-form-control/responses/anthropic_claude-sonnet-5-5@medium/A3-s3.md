The API returns JSON with an average body of 400 KB. Gzip is a compression format that a server applies to the response body. A client asks for it with the `Accept-Encoding` header, and the server marks the result with `Content-Encoding: gzip` [1].

Large responses cost transfer time, especially on mobile networks, and bandwidth fees. The decision is cheap to test now and cheap to undo.
