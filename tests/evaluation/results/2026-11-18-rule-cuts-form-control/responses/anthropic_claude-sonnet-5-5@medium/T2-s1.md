## Headline

No prompt stops hallucination fully, but a source-only prompt with a refusal rule cuts it, and a test proves the cut.

- The prompt below forces each claim to rest on supplied text.
- It gives the model a legal way to say "no answer".
- A 50-question test shows whether it works on your model.

## Background

You asked for one prompt that stops a model from hallucinating, that is, from stating false or unsupported facts. The material gives no model name, task, or source documents. Therefore this answer assumes a general chat model that can receive source text.

## Relevance

A wrong answer stated with confidence costs more than a refusal. A tested prompt gives you a measured result, not a hope.

## Information

Use this prompt as the system message:

```text
Answer only from the sources in this conversation.
Quote the supporting text for each claim.
If the sources do not contain the answer, reply: "Not in the sources."
Do not guess. Do not fill gaps from memory.
Label any claim from memory as [no source].
```
