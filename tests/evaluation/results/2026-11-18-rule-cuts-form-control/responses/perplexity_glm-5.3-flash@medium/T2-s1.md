# Headline

No prompt stops hallucination, because generative hallucination is a property of the model; the best prompt forces the model to ground, quote a source, and abstain. [2]
- A hallucination is a fluent answer that contains false or invented content.
- Prompt wording alone cannot reach zero errors; say so in every decision that trusts the answer.
- Verification and retrieval steps after the prompt cut wrong answers more than wording does. [3], [4]
- The prompt below trades some completeness for correctness: it makes the model say "NOT IN SOURCES" instead of guessing.

## Background

The request asks for one prompt that removes invented content from model answers. The request names no model, API, or source documents.

## Relevance

Each invented answer that reaches production costs review time or a wrong decision. A prompt tests in one session, so it is the cheapest first step.

## Information

**Evidence**

1. Surveys identify the cause of hallucination in generation limits, data gaps, and training on unknown facts, not in prompt word choice. [1], [2]
2. Chain-of-Verification, a generate-then-verify-then-revise loop, lowers factual error rates against reference facts on measurable test sets. [3]
3. SelfCheckGPT finds hallucinated sentences by sampling and comparing variants, which supports the verify-pass pattern. [4]
4. Fine-tuning on facts the model does not know raises hallucination on those facts. [5]
5. Each claim above rests on a secondary source; no tool ran in this session behind them; each title and author set is identified with high confidence.

Therefore baseline comparisons below use judgments with a stated basis, because error rates vary by model and task.

**Assumption log**

**Alternative considered**

Fine-tuning or a trained hallucination classifier loses for this request: both need labeled error data and days of work; the prompt tests in one session. [judgment]

**The prompt**

With sources:

```text
Answer the question under these rules.

1. Use only the text in the SOURCES section.
2. Put the source name next to each fact you state.
3. If the SOURCES text does not answer the question, write "NOT IN SOURCES".
4. Mark each number and date as "exact" or "approximate".
5. Re-read your draft against SOURCES. Delete any sentence you cannot trace to a source.
```

Without sources:

```text
Answer the question under these rules.

1. State only facts you are sure of from training.
2. Label each claim "sure" or "not sure".
3. For each "not sure" claim, write the reason in one sentence.
4. If you know no fact that answers the question, write "not known".
5. Re-read your draft. Delete any claim labeled "not sure" that has no reason.
```
