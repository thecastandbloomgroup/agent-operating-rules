## Headline

Hold all public statements now, name one owner for the response, and issue one verified statement within a 24-hour cycle.

- A wrong statement today is permanent; a verified statement tomorrow survives.
- Parallel messages from legal, PR, and the board will produce quotes that conflict, and reporters quote the conflict. [judgment]
- The decision to correct or to defend depends on evidence nobody has verified yet.

## Background

A journalist reported today that the CEO's public statement from yesterday was false. Legal, PR, and the board each messaged management directly, and no single response owner exists. The request is for the next steps.

## Relevance

The first framing of a disputed story tends to hold for the following cycles, so the response window closes fast. Because three functions are acting in parallel, the cost of delay is internal disagreement becoming external. [judgment]

## Information

**Evidence**

- In a Confused situation, the first action is to collect what is needed to classify the situation, per the Cynefin framework. [18]
- Every published statement becomes a fixed record that later corrections compare against, so accuracy pressure rises with each hour of silence. [judgment]
- The response choice is binary only after a per-claim check: each disputed sentence is accurate, inaccurate, or unverifiable. [judgment]

**Assumption log**

- `Assumption: the journalist holds a source such as a recording, transcript, or document. Why not measured: the material does not state it. Validate by: check each quote in the article against the company's own record. If wrong: the dispute becomes a correction request to the outlet, not a response decision.`
- `Assumption: the story is live and incoming coverage will grow during the next 24 hours. Why not measured: no monitoring tool is connected in this session. Validate by: article and mention counts for the next 24 hours against today's baseline. If wrong: extend the deadline, and the response gains less weight.`
- `Assumption: legal, PR, and the board will defer to one named owner if the CEO or chair names that person within 2 hours. Why not measured: measuring costs more than the decision is worth, because it requires a live governance test. Validate by: observe voting in the first response call. If wrong: route all approvals through the board chair.`
- `Assumption: the CEO's disputed claims are checkable against written records. Why not measured: the session holds no documents. Validate by: request the records in Step 1. If wrong: classification stalls at "unverifiable", and the default response becomes "we are reviewing".`

**Alternative considered**

Issue a full denial within the hour. It loses because a fast denial is refuted permanently if the journalist's source is real, and internal review has not verified one claim yet. Assumption [1] drives this loss.

## End

I recommend that we run the four steps below today, in this order, unless the board chair already named an owner.

1. **Assemble the fact record.** Increment: a two-hour working session that produces one table. Blocker removed: nobody can judge the CEO statement without it, so this step decides every later step. Test (deterministic; Gherkin):
   ```gherkin
   Given the article, the CEO statement transcript, and the company records
   When the group lists each disputed claim with its supporting source
   Then every quote in the article has one row, and each row names one source type
   ```
   Cynefin: Confused. Reason: the domain of the situation itself is unknown, so this step gathers what classifies it.

2. **Freeze external messaging. Increment: a 30-minute notice naming one owner and one approval channel; run it in parallel with Step 1.** Blocker removed: conflicting statements from three functions. Test (deterministic; Gherkin):
   ```gherkin
   Given the freeze notice sent to legal, PR, and the board
   When any channel prepares an outbound statement
   Then the channel routes it to the owner and publishes only with written approval
   ```
   Cynefin: Clear. Reason: a known rule applies, so this is one direct step.

3. **Classify each claim.** Increment: a two-hour legal and facts review that labels every row from Step 1 as accurate, inaccurate, or unverifiable. Blocker removed: without labels, the response choice is a guess. Rubric (evaluative; sonsider Kepner-Tregoe format criteria): source quality (weight 3), match to the record (weight 3), legal exposure if defended (weight 2); pass means the two reviewers agree on the label for the claim. Test written before the work, with the two reviewers scoring independently, then comparing. Cynefin: Complicated. Reason: labels come from analysis of records by experts, not from one rule. Step 3 MUST NOT start before the Step 1 table exists.

4. **Publish one response and monitor it. Increment: draft, approve, and publish the statement in one 60-minute session; the probe then runs 24 hours.** Blocker removed: the story currently has only one voice, the journalist. Acceptance test (stochastic), written first: metric = share of next-cycle articles that use the company's framing of the dispute; baseline = 0% today, because no company statement exists; pass threshold = 50% or more across a sample of 10 articles in 24 hours. Stop condition: if defamatory or wrong facts appear in the response, retract within 1 hour and escalate to the chair. Cynefin: Complex. Reason: reader and media reaction is visible only after publication, so this is a safe-to-fail probe, and its leverage is a guess. Step 4 MUST NOT start before Step 3 classifies every row, because the wording depends on the labels.

Branch rule for Step 4: if Step 3 marks the CEO statement inaccurate, the response is a correction with a fix date. If it marks the statement accurate, the response is a rebuttal package sent to the journalist and the outlet. If any row is unverifiable, the default response is "we are reviewing the record and will comment by <date>."

## Follow-up

**Conditions that change the recommendation**

- If assumption [1] is wrong, that is, the journalist has no verifiable source, replace Step 4 with a factual correction request to the outlet.
- If the board chair requires approval for any public statement, insert a chair sign-off gate between Steps 3 and 4, and budget 2 hours for it.
- If incoming coverage stays flat for 24 hours versus today's baseline, drop the probe threshold to 30% and hold the next review for 48 hours. [judgment]
