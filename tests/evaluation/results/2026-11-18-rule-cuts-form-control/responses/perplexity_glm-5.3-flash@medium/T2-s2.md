## Headline

No prompt can stop hallucinations fully. A prompt can cut their rate when the prompt forces grounding in sources, demands citations, and permits "I do not know". Full control needs verification and checks, not prompt text alone. [1], [2]

## Background

Protection is needed against false output for a model. The request asks for one best prompt. Overconfidence is a known failure mode of large language models. [1]

## Relevance

Unverified output leads to wrong decisions. The fix shapes sleep quality of every task that relies on model text. [1]

## Information

Evidence follows.

1. Surveys locate the causes of hallucination in training data, lack of grounding, and decoding, so prompt text alone cannot fix them. [1], [2]
2. Mitigation methods that target grounding, such as retrieval augmented generation, show measured gains over instruction alone. [3]
3. Baseline for comparison: a plain prompt with no grounding instructions leaves the model free to invent missing facts. [1], [2]
4. Theme from sources: methods that ask the model to cite spans and to verify against a source outperform instruction text only, with support in [1], [2], and [3]; no source in this list argues that a single prompt is sufficient.
