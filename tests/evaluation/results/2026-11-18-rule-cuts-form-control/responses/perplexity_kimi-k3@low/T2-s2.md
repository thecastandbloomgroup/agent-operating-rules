## Information

Prompt wording reduces, but does not eliminate, hallucination. A model predicts plausible text; it does not verify against ground truth unless grounded with retrieval. This is high confidence, consistent report across vendor documentation and research [judgment].

The full prompt that works best in practice:

> "You answer questions on this topic only from the sources I paste below, or facts you can state with high confidence. For each claim, either cite the source by name or write 'Unverified'. If you lack enough information, write 'I do not know' and state what is missing. Do not invent names, dates, numbers, quotes, URLs, or references."
