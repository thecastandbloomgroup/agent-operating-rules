## Headline

No prompt can fully stop hallucination, so the best prompt forces the model to ground its answer and admit when it does not know.

- Prompts change behavior but not the underlying cause: the model predicts plausible text, not verified facts [inference].
- The most effective pattern combines three rules: use only provided sources, say "I do not know" when unsure, and cite evidence for each claim [judgment].
- For factual accuracy, retrieval (giving the model real documents) beats any wording change [judgment].

## Background

The request is for a single prompt that stops hallucination. Hallucination means the model states false content with confidence. It arises from how the model generates text, so wording alone cannot remove it [inference].

## Relevance

A good prompt reduces confident errors now. It also tells you when to distrust the output, which protects decisions that depend on it.

## Information

Use this template. Fill in the brackets before sending.

```text
Answer the question below using only the sources I provide.

Sources:
[paste your documents, data, or references here]

Question:
[your question]

Rules:
1. Base every factual claim on the sources above. Cite the source for each claim.
2. If the sources do not contain the answer, reply: "The sources do not answer this."
3. Do not use outside knowledge, memory, or guesses.
4. If part of the answer is uncertain, state your confidence as a percentage and say why.
```

Why each rule earns its place:

- Rule 1 forces grounding: claims must map to text the model can see [judgment].
- Rule 2 replaces the worst failure mode, a fluent fabricated answer, with a safe refusal [judgment].
- Rule 3 blocks the model from filling gaps with training data, which is where most fabrications come from [inference].
- Rule 4 exposes residual risk instead of hiding it [judgment].

Alternative considered: a short instruction like "do not hallucinate" or "be accurate." It loses because the model already tries to be accurate; without sources and a refusal path, nothing changes [judgment].

Limit the expectation: 70% likely this cuts fabrications sharply when sources cover the question [judgment]. It cannot help when the sources themselves are wrong or missing.
