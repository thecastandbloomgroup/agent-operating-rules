# Headline

No single prompt stops model hallucination completely.
Prompt constraints reduce ungrounded claims, but cannot eliminate them alone [19].
Effective mitigation pairs bounded system prompts with external reference data [20].
Verification steps catch remaining errors before output reaches users [21].

# Background

You asked for a single prompt that stops model hallucinations.
Generative models predict tokens based on statistical likelihood rather than grounded truth [19].
Therefore, prompt wording alone cannot fully prevent factual errors [20].

# Relevance

Unchecked hallucinations cause factual errors in production applications.
Relying only on prompt engineering creates a false sense of safety.
Understanding prompt limits prevents deployment failures.

# Information

Research shows prompt techniques reduce errors by limiting model freedom [20].
For example, constraining answers to provided text reduces hallucinations from 14% to under 2% in question answering [20].
However, residual errors persist because token generation remains probabilistic [19].

Assumption: The user builds a factual question-answering workflow.
Why not measured: The material does not state it.

If wrong: General creative tasks require different sampling parameters instead of strict grounding.

Alternative considered:
The strongest alternative is relying purely on negative prompting, such as "never make things up".
This loses because probabilistic decoders lack internal factual boundaries without reference documents [19].
