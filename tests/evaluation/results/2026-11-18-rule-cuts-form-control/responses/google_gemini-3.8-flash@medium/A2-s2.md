### Information

PostgreSQL supports direct column renaming through the `ALTER TABLE` statement [1]:

```sql
BEGIN;
SET LOCAL lock_timeout = '2s';
ALTER TABLE orders RENAME COLUMN user_id TO account_id;
COMMIT;
```

This operation updates metadata without rewriting the underlying table data [1].
Because the lock level is `ACCESS EXCLUSIVE`, any long query on `orders` will block it [1].
