# Headline

No prompt stops hallucination, but a grounding prompt cuts it the most. Use this: "Answer only from the provided text. If the answer is not in the text, say 'I do not have that information.' Cite the passage you used." Prompts reduce errors; retrieval and verification remove more [judgment].
