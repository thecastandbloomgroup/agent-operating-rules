## Headline

No prompt stops hallucination on its own; the strongest prompt cuts unsupported output with three rules: answer only from supplied documents, cite a source after each claim, and refuse when no passage answers.

1. False output has causes in training data and decoding, and prompt wording reaches only the output stage [1].
2. Prompt-side mitigation is one listed category in the survey literature, and it reports reduced errors, not zero errors [2].
3. The refusal rule trades coverage for accuracy, so the user sets that trade.

## Background

The request asks for one prompt that stops a model from producing false content. The request does not name the task, the model, or the context of use.

## Relevance

Prompt rules are cheap to apply today, so they are the fastest lever the user controls. Their measured limits decide whether a retrieval system is also needed.

## Information

**Evidence**

A survey of hallucination research attributes false output to data gaps and model limitations. Because these causes sit below the prompt, prompt wording cannot remove them [1].

The mitigation survey lists prompt-based methods as one reduction category. It reports no complete removal through prompting alone [2]. Therefore the target is a lower error rate, not zero.

The template below applies the three prompt-side rules with support in that literature [2].

```text
Answer only from the documents in this conversation. For each answer:

1. Quote the passages that answer the question.
2. If no passage answers it, reply with only:
   "I do not know from the documents." Then stop.
3. Write the answer. Add a citation after each claim,
   in the form (document, section).
4. Before you send, check each sentence against the quotes.
   Delete any sentence without a quote.
```

**Assumption log**

A1. The task is question answering over documents that the user supplies. Why not measured: the material does not state a task. Validate by: confirm the task with the user. If wrong: swap the grounding rule for the task type, per [2] [no source for the swap].

A2. The user can set the system prompt. Why not measured: not stated in the material. Validate by: test one system prompt edit in the target tool. If wrong: place the template in the first user message instead. The effect size then differs [judgment].

**Alternative considered**

The strongest alternative is retrieval augmented generation (RAG), a system that fetches documents before the model answers. It loses as the first step because it needs system changes beyond a prompt, and the grounded template captures most of its gain for a single task [judgment]. Surveys rank RAG above prompting for reduction strength [2].

## End

I recommend that we apply the template in one working session, with these steps.

1. **Insert the template** into the system prompt. Blocker removed: answers without sources. Test:
```gherkin
Given a source passage that answers a test question,
When the model drafts an answer,
Then every claim in the draft carries a citation
in the form (document, section).
```
This change is deterministic. Domain: Clear, because a documented best practice exists [2].

2. **Build a 20 question test set**: 10 questions answerable from the documents, 10 unanswerable. This step MUST be done before Step 3. Blocker removed: no baseline exists. Test:
```gherkin
Given the 20 question set,
When a reviewer checks each item against the documents,
Then all items carry a checked gold answer
and an answerable flag.
```
This change is deterministic. Domain: Clear, because the rule is one step.

3. **Run the 20 trials** and score each answer against the gold answers. Sample size: 20. Metric: share of correct answers on answerable questions, and share of correct refusals on unanswerable questions. Baselines: 8 of 10 and 8 of 10. Accept at that sample size only. Blocker removed: unknown effect of the prompt. This change is stochastic. Domain: Complex, because model output varies run to run, so it is a capped probe with a budget of 20 trials.

4. **Pick the follow-up fix**, and only if Step 3 fails. Use a Pugh style rubric: criteria are residual failure count (weight 0.5), effort (weight 0.2), coverage loss from refusals (weight 0.3); pass threshold is the lowest weighted score against a fixed baseline of "keep the prompt as is". Evidence per criterion comes from the Step 3 scores. Blocker removed: an unranked choice between narrow the scope and add retrieval. This change is evaluative. Domain: Complicated, because the analysis in the rubric picks the practice [16].
