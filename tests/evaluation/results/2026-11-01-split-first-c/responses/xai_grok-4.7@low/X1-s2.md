Headline
Measure the error before you change the summariser.
- Agent notes give no error rate and no error type.
- A fixed ticket set shows whether a later change helps.
- The first sample ranks which error type to fix first.

Background
The support tool uses a large language model to write summaries. A summariser is that writing part. Agents say some summaries are wrong, and the team has no error metric.

Relevance
Agents act on these summaries during live tickets. Therefore a wrong summary can send the next action off course.

Information

Cause and effect for these failures are not visible yet. Therefore this work starts as Confused, and the first move is to classify [1].
