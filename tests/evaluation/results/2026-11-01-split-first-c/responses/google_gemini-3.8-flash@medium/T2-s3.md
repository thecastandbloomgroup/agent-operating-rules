### Headline

No single prompt can eliminate hallucinations entirely because generative models predict tokens by probability [judgment].
Constraining the model to cite provided reference text reduces unsupported statements [1].
Directing the model to admit ignorance prevents invented answers when context lacks facts [2].
Requiring verbatim quotes before synthesis creates an audit trail that catches errors [judgment].

### Background

The request asks for a single prompt to stop model hallucination.
Large language models generate text based on statistical token prediction rather than factual recall.
Therefore, prompt phrasing alone cannot guarantee factual accuracy across arbitrary queries [judgment].

### Relevance

System builders need reliable techniques to prevent incorrect outputs in production environments.
Applying structured grounding instructions lowers risk before you spend engineering effort on fine-tuning.

### Information

Evidence:
First, benchmark studies show that retrieval augmentation reduces hallucination rates below 5% when models cite source material [1].
Second, directing models to refuse unanswerable queries decreases false claims compared to open generation [2].
Third, without source context, ungrounded prompts continue to generate false facts at measurable rates [judgment].
For example, system prompts that mandate refusal reduce fabricated answers when evidence is absent [2].

The grounded prompt template is:
```text
Context: {context}
Question: {question}

Instructions:
1. Answer the question using only the facts stated directly in the context.
2. If the context does not contain sufficient information, state: "I do not know based on the provided context."
3. Do not extrapolate, speculate, or interpret beyond the explicit text.
```
