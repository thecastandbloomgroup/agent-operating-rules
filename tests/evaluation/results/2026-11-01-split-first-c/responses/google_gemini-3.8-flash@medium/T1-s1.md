### Background

The development team lacks an agreed standard for formatting SQL queries.
Developers argue about SQL layout during merge reviews, which creates friction.
The request asks to solve this team culture problem.

### Relevance

Formatting debates slow down feature delivery and damage team collaboration now [judgment].
Removing subjective debates protects focus for substantive logic and security issues [1].

### Information

Subjective discussions on trivial code details represent the law of triviality, also known as bikeshedding [2].
Google found that automated tools handle formatting better than humans in code reviews [1].
Their study showed automated checks reduce review turnaround time and eliminate interpersonal friction [1].
Therefore, software teams solve style friction by delegation to software rather than negotiation [judgment].
