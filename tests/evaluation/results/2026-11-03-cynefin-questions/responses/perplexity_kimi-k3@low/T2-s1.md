# Headline

No single prompt stops a language model from hallucinating. 1) Prompts reduce hallucination frequency but cannot remove the cause, which is in the model's weights. 2) The strongest prompt pattern is one that forces grounding in a provided source and permits "unknown" as an answer. 3) Reliable results come from retrieval plus verification, not from prompt wording alone.

# Background

The request asks for one best prompt to end hallucination. Hallucination means fluent output with no factual basis.

# Relevance

A wrong belief here wastes effort. Prompt-only fixes fail in silent cases, so the limits matter now.

Best prompt pattern:

```text

If the text does not contain the answer, reply: "Not in the source."

Do not use outside knowledge.

Source text:
<paste the source here>

```
