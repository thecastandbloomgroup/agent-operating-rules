## Information

Flaky tests and builds share one root: non-determinism. Common causes, grouped as themes from the cited sources and from experience:

1. Timing and concurrency, for example race conditions and fixed sleeps [1], [judgment].
2. Shared state between runs, for example leftover files or database rows [1].
3. External calls: network, clocks, and randomness [1].
4. Unpinned dependencies, so two runs resolve different package versions [judgment].
