## Background

You asked for one prompt that stops a model from hallucinating. Hallucination means the model states content that is false or unsupported by its sources [1]. The cause sits in how the model generates text, so a prompt reduces the problem but does not remove it.

## Relevance

A wrong answer that sounds sure costs you more than an honest "Not found". A tested prompt tells you now how much it helps.

## Information

The prompt (paste it as the system message):

```text
Answer only from the sources in this conversation.
Quote the passage that supports each claim.
If the sources do not contain the answer, write: "Not found in the sources."
Do not guess. Do not invent names, numbers, quotes, or links.
State your confidence as high, medium, or low, with one reason.
Before you answer, check each claim against its quote.
Remove any claim that has no quote.
```

Evidence:

- Grounding answers in retrieved text improves factual output on knowledge tasks (secondary source, one paper).

  [2]

- A draft, verify, then revise step lowers unsupported claims (secondary source, one paper).

  [3]

- Both sources test specific models, so the size of the gain for your model is unknown. [judgment]
- The "Not found" rule works only if you supply sources. Without sources the model falls back on memory. [inference]
- Confidence: medium, two independent papers, neither run on your model.
