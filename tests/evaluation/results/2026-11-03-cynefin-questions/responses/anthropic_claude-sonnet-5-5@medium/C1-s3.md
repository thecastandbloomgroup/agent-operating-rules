## Headline

Replace all 14 `print` calls in `service.py` with a module-level `logging` logger, and configure the INFO threshold once in `main()`.

- The change touches one file and adds one import, one logger, and one `basicConfig` call.
- Each `print` maps to one logger call, so no behavior changes except the log format.
- A test that checks the log output and a search for leftover `print` calls prove the change.

## Background

The service is a 129-line HTTP API over an orders database. It reports events with 14 `print` calls [1]. The request is to use the standard `logging` module at INFO level [2].

## Relevance

`print` output has no timestamp, no level, and no filter. Operators cannot sort errors from routine events. A configured logger fixes this without a new dependency.

## Information

**Evidence.** The attached file has 14 `print` calls: 1 in `connect`, 2 in `init_db`, 1 in `get_order`, 1 in `list_orders`, 2 in `update_status`, 2 in `do_GET`, 1 in `do_POST`, 1 in `log_message`, and 3 in `main` [1]. The `logging` module supports the DEBUG, INFO, WARNING, ERROR, and CRITICAL levels and lazy `%s` formatting [2].

**Setup lines.** Add these at the top of the file and as the first line of `main()`:

```python
import logging
logger = logging.getLogger(__name__)

# first line inside main():
logging.basicConfig(
    level=logging.INFO,
    stream=sys.stdout,
    format="%(asctime)s %(levelname)s %(name)s %(message)s",
)
```

**Call mapping.** Use `%s` placeholders, not string joins.

| Function | New call |
|---|---|
| `connect` | `logger.info("opening database %s", DB_PATH)` |
| `init_db` | `logger.info("checking schema")` and `logger.info("schema ok")` |
| `get_order` | `logger.info("order not found: %s", order_id)` |

| `do_POST` | `logger.info("bad JSON from %s", self.client_address[0])` |
| `log_message` | `logger.info("request: %s %s", self.address_string(), format % args)` |
| `main` | `logger.info("starting order service on port %s", PORT)`, `logger.info("stopping")`, `logger.info("database closed")` |
