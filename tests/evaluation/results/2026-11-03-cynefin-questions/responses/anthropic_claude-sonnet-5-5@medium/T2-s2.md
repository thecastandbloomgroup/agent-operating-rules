## Headline

No single prompt stops hallucination, but a grounding prompt that forces quotes and allows "Not in the material" cuts it the most.

- The model invents facts when it lacks the answer, so the prompt must give it a permitted way to say "no".
- Source material in the prompt gives the model facts to use instead of memory.
- A quote rule makes each claim checkable.
- A test on your own questions shows whether the prompt works.

## Background

You asked for one prompt that stops hallucination. Hallucination means the model states false or unsupported content as fact [1].

The prompt below applies three known controls: supplied source text, a refusal option, and a quote rule.

## Relevance

An unsupported claim in a report, code, or advice costs you rework or trust. A prompt costs minutes to change.

## Information

**The prompt**

```text
Answer only from the material below.
If the material does not contain the answer, write: "Not in the material."
Do not guess.
Quote the sentence that supports each claim.
Rate your confidence as high, medium, or low, and give the reason.

Material:
<paste here>

Question:
<paste here>
```

**Evidence**

- Retrieval of source text improves factual output on knowledge tasks [2].
- Hallucination persists in all current model types [1]. Therefore no prompt gives a zero rate [inference].
- The refusal phrase and quote rule are a prompt design choice [judgment]. Test them on your data.

A2. The model is a chat model without web or file tools. Why not measured: no tool can reach your setup. Validate by: run one question that needs a live fact. If wrong: use the tool to fetch the material, then use the same prompt.

**Alternative considered**

The strongest alternative is a short instruction such as "Do not hallucinate." It loses because it gives the model no source and no allowed way to decline [judgment].
