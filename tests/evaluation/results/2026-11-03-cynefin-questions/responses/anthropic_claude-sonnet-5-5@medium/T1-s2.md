## Headline

Replace opinion with a tool: adopt one automated SQL formatter, enforce it in CI, and stop style comments in reviews.

- Style friction comes from people judging format by hand, so a tool removes the judgment.
- One time-boxed decision on the rules ends the debate, because the tool then holds the rules.
- A four-week trial shows whether review friction falls.

## Background

The team disagrees on how to format SQL. Every review contains style comments. The request is to fix the cause, which is a shared habit, not a single file.

## Relevance

Style comments cost review time and strain trust between teammates. Each new query in a mixed style makes a later cleanup larger.

## Information

- SQLFluff lints SQL and fixes violations automatically. It reads its rules from one config file in the repo [2]. This source is secondary.

## End

I recommend that we:

1. **Decide the rules in one 45-minute session.**
   - Increment: choose between the tool default and one team variant. If the group does not agree, the tech lead decides.
   - Blocker removed: no agreed rule exists.
   - Kind: evaluative. Test written first: a rubric.

   - Domain: Complicated. An expert can deduce the best option from the rubric and the trial data.

2. **Commit the formatter config to the repo.**
   - Increment: one config file and one run command.
   - Blocker removed: the rules exist only in people's heads.
   - Kind: deterministic. Test written first:
     - Given a SQL file that breaks the chosen rules

   - Step 2 MUST NOT start until Step 1 meets its threshold.
