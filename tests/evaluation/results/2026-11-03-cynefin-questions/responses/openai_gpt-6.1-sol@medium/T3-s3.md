## Headline

Separate the JWT migration from sign-up improvements, and establish the current authentication rules before changing production code. [judgment]

- The migration needs explicit rules for token storage, expiry, logout, and account revocation. [judgment]
- Sign-up changes need a measured baseline, not an assumed source of friction. [judgment]

## Background

## Relevance

Authentication changes affect access control, while sign-up changes affect account creation. Therefore, the safest starting point is to define both acceptance criteria before implementation. [judgment]

## Information
