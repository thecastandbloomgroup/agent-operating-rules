Headline: No prompt can stop hallucination, so use a source-lock prompt and refuse gaps.

The prompt below blocks answers that the given sources do not support.
A separate refusal line blocks invented names, numbers, dates, and citations.
A claim list makes unsupported text visible before you use the answer.
Facts outside the prompt still need retrieval or a tool, because a prompt adds no knowledge.

## Background

The request asks for the best prompt to stop a model from hallucinating. Hallucination means the model states false content as fact. A prompt can cut that risk, but it cannot remove it.

## Relevance

A bad fact can drive a bad decision in the next task. This prompt is the fastest control you can add before you change tools or data.

## Information

Paste this prompt as the system instruction:

```text
Answer only from the sources in this message.
If the sources do not contain the answer, reply only: Not in sources.
Do not invent names, numbers, dates, quotes, or citations.
For each factual claim, add a short source quote, or write Unsupported.
Start each inference with Inference:.
Put the direct answer first.
Then list each claim with its support.
```

A1. The task is factual answering, not fiction. Why not measured: the material does not state the task. Validate by: confirm the task type in one message. If wrong: remove the refusal line for creative work.

A2. Source text can sit in the same message. Why not measured: the material does not state the setup. Validate by: check for a document or tool. If wrong: add retrieval before you trust the answer.

The strongest alternative is a role line such as "never hallucinate." It loses because that line does not check a claim against a source. [judgment]

## End

I recommend that we take these steps.

1. Clear: anyone would apply a known grounding rule, by deduction from that rule. Test first. Given a question and sources that lack the answer, When the model replies, Then the reply is only "Not in sources." Increment: paste the prompt above into the system message in one session. Blocker removed: gap filling from memory.

2. Complicated: an expert can pick the variant from error data, by deduction after that review. Test first. Rubric: grounded quote 50%, correct refusal 30%, no invented citation 20%. Pass threshold: 80 of 100. Evidence: ten held-out questions with known sources. Increment: score ten answers in one session and keep the variant that passes. Blocker removed: the wrong rule for this task. Step 2 MUST NOT start until the test in Step 1 passes.

3. Complex: the rate shows only after a trial, so this is induction, and a prompt change or a new topic can break the pattern. Leverage is a guess. Test first. Metric: share of claims marked Unsupported that are actually false. Baseline: the same twenty questions without the prompt. Pass threshold: false-claim share at or below half the baseline. Sample size: 20. Stop if the share does not fall, or if the session budget ends. Increment: one capped probe, not a full rollout. Blocker removed: unknown residual error. Step 3 may run in parallel with Steps 1 and 2.
