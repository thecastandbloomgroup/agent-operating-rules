Headline
No prompt makes a model stop hallucinating.
A ban on invention still lets the model add missing facts.
Source checks cut unsupported claims more than style rules.
An abstain line helps when the text has no answer.
A second check pass catches claims the first pass missed.

Background
You want one prompt that stops false claims.
Hallucination means the model states a fact the sources do not support.
No wording removes that failure on its own.

Relevance
A weak prompt wastes a review cycle on invented facts.
Therefore use a source rule now if the next answer must be checkable.

Information
First, survey work treats hallucination as a standing failure, not a wording error.
[1]
Next, retrieval that adds source text before generation makes the model use stored memory less.
[2]
A later check pass cuts false claims in reported tests.
[3]
Therefore the strongest prompt binds each claim to a quote or an abstain line. [judgment]
Abstain means the model says the sources lack the answer.
Confidence is very likely (90 to 100%) that some false claims remain after that prompt.
The survey reports residual errors after studied methods.
[1]
The check-pass paper reports a reduction, not removal.
[3]

Use this prompt:

Use only the sources in this message.
For each factual claim, quote the supporting span.
If no span supports the claim, write: Not in the sources.
Do not use outside knowledge.

A1. The task is factual answers, not fiction. Why not measured: the material does not state it. Validate by: label the next task as fact or fiction. If wrong: drop the abstain line and mark each added fact.

A2. Sources can be pasted into the same message. Why not measured: the material does not state it. Validate by: paste one source and rerun one question. If wrong: retrieve text before the answer step.

Alternative: a one-line ban, "Never hallucinate." It loses because it gives no source test and no abstain path. [judgment]

End
I recommend that we do these four actions.

1. Clear. Deduction from a known rule: an answer needs its evidence in view.
Deterministic test:
Given one source pasted above the question
When the model answers
Then each factual claim has a quote from that source.
Increment: paste that source in the same message before the question.
Blocker removed: answers drawn only from memory.

2. Clear. Deduction from the same rule: a gap must produce an abstain line.
Deterministic test:
Given a question absent from that source
When the model answers
Then the text is "Not in the sources" with no added fact.
Increment: add the prompt in Information to the system slot.
Blocker removed: gap filling with no abstain path.
Step 2 MUST NOT start until the source from Step 1 is in the message.

3. Complicated. An expert can judge each claim once the quote list exists. Deduction from quote-match rules.
Deterministic test:
Given the draft and the source
When the check pass runs
Then each remaining claim has a matching span or the abstain line.
Increment: run one check pass on the draft in this session.
Blocker removed: unchecked claims from the first pass.
Step 3 MUST NOT start until the prompt from Step 2 is saved.

4. Complex. The result shows only after a trial. Induction from 10 questions. The pattern can break on other topics.
Stochastic test:
Metric: share of claims with no source span.
Baseline: the same 10 questions with no source rule.
Pass threshold: at least 50 percent fewer unsupported claims.
Sample size: 10 questions.
Budget: one working session.
Stop if more than 3 replies refuse a question the source answers.
Increment: run this probe in parallel with Steps 1 to 3.
Blocker addressed: unknown gain on this question set.
Leverage of this probe is a guess.

Follow-up
If A1 is false, replace the abstain line with a label on each added fact.
If A2 is false, replace Step 1 with retrieval that returns text before the answer.
