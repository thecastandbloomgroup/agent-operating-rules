Headline
No prompt can stop hallucination.
The strongest pattern limits the model to supplied sources, a quote, and an abstention.
A bare line that says "do not hallucinate" does not remove invented facts.
A later check against the sources is still required.

Background
Generation models can write fluent text that is false.
The request asks for the best prompt to stop that behavior.
A prompt can cut unsupported claims. It cannot remove the risk.

Relevance
A false claim can drive a bad decision in the next step.
Therefore the prompt must make silence cheaper than invention.

Information
A survey treats hallucination as a known failure of generation models.
[1]

Retrieval of documents before generation improves knowledge tasks.
[2]

A demand for a source id and a quote cuts unsupported claims more than a warning line. [judgment]

Use this prompt with the source text in the same message.

```text
Use only the source text below.
For each claim, give the source id and a short quote.
If the sources do not support the claim, write "Not in sources."
Do not add facts from memory.
If you lack support, write "Not in sources."
```

A1. The user can paste source text into the same message. Why not measured: the material does not state it. Validate by: check whether sources exist before the run. If wrong: retrieve sources before this prompt.

Alternative considered: lower the sampling temperature and keep an open prompt. It loses because fluent error remains when no source constrains the answer. [judgment]

End
I recommend that we take these steps.

1. Test: Given source text in the message, When the model answers, Then each claim has a source id and a quote or the text "Not in sources."
Paste the prompt and the sources in one working session.
This removes the open invitation to invent.
Domain: Clear, because one known practice applies: constrain output to given text, by deduction from that rule.

2. Test: Given ten claims from the reply, When each claim is checked against its quote, Then at least nine quotes support the claim.
Score the ten claims in one session.
This removes undetected false support.
Domain: Complicated, because an expert can judge support from the quotes, by analysis.
Step 2 MUST NOT start until Step 1 has a reply.

3. Test: metric is unsupported claims per ten claims, baseline is the same questions with no source rule, pass threshold is a drop of at least half, sample size is ten questions.
Run that probe with a stop if two answers invent facts outside the sources, and a budget of one session.
This tests whether the prompt helps on this task.
Domain: Complex, because the rate shows only after the trial, by induction, and a new topic can break the pattern.
Leverage is a guess.
Run Step 3 in parallel with Step 2, capped by that budget.

Follow-up
If A1 is false, replace Step 1 with a retrieval step, then use the same prompt.
Do not rely on temperature change alone.
