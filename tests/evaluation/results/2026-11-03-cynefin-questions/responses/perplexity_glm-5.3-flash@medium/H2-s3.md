## Background

A journalist published an assessment that the CEO's public statement from yesterday was false. Legal, PR, and the board each send you separate instructions. You must set the next steps now.

## Relevance

Every unaligned statement a different team sends gives the journalist another quote. So the window for one credible response shrinks each hour. [judgment]

## Information

The session contains no documents, so the driving claims carry [judgment] or [inference] labels. I cannot estimate the probability that the CEO's statement is false; the recommendation does not depend on that estimate, because Step 2 produces it.

Assumptions:

`A1. No crisis protocol is in force right now. Why not measured: the material does not state it. Validate by: ask the general counsel's office for the plan and its owner within one hour. If wrong: follow the plan, keep the freeze, skip the setup in Step 1.`

`A2. The dispute is about facts that records or witnesses can settle. Why not measured: the material does not state it. Validate by: compare the statement text with the journalist's claim in one session. If wrong: legal analysis replaces fact-checking in Step 2, and counsel leads.`

Alternative considered: publish an immediate denial today. It loses because an unverified rebuttal fails if the journalist holds a document, and that failure dominates the story. [judgment]

## End

I recommend that we take these five steps, in this order:

1. **Stabilize (Chaotic, deterministic).** Within one hour, send one message to legal, PR, and the board: no external statement leaves without one named approver, and name the spokesperson (CEO or a designee). This removes the parallel messaging that creates new quotes. Write the test first: 
```gherkin
Given a drafted external statement
When any team member prepares a release
Then the named approver has logged approval first
```
Domain reason: harm happens now, and analysis would delay control. Stabilize before leverage is measured. [1]

2. **Verify (Complicated, evaluative).** Today, in one session, counsel plus the keeper of the source records compare the statement with the underlying records. Output: a one-page timeline, each contested point linked to a document. This removes the blocker of not knowing whether to correct, clarify, or rebut. Write the rubric first, Kepner-Tregoe layout [2]: criterion 1, document match (weight 50, evidence: record text); criterion 2, counsel judgment on statement wording (weight 50, evidence: counsel's written note). Pass threshold: two independent records agree on each contested point. Domain reason: an expert reading enough records can settle this, so deduction from analysis applies. Step 2 MUST NOT start later than today's end.

3. **Align in one forum (Clear, evaluative).** Tonight, hold one 45-minute call with legal, PR, and one board delegate. Output: a one-page decision memo with the holding statement text, the full response owner, and the deadline. This removes the three parallel instruction streams. Test first:
```gherkin
Given the call ends
When the memo circulates
Then legal, PR, and the board delegate confirm by reply within 30 minutes
```
Domain reason: one forum with one output is a known practice that anyone would apply. [1] Step 3 MUST NOT start before Step 2 ends, because the memo contains Step 2's result.

4. **Release the holding statement (Complicated, deterministic).** Tomorrow morning, publish a statement of 150 words or fewer through the single channel. If Step 2 shows the CEO's statement is false, it names that fact and the correction plan. This removes the information vacuum that invites speculation. Test first:
```gherkin
Given the confirmed decision memo
When the statement is drafted
Then each factual claim cites a source document
And the statement carries one approval from each party
```
Domain reason: the content follows from Step 2's analysis, so it waits on analysis before release. Step 4 MUST NOT start until Step 3's test passes.

5. **Monitor with a cap (Complex, stochastic).** For 72 hours after release, one analyst logs each new article and executive mention daily, at a budget of 4 analyst-hours total. Stop condition: no new story cites the discrepancy across two consecutive days. Acceptance test first: metric, count of new follow-up stories per day; baseline, count on release day; pass threshold, zero across two consecutive days on the tracked outlet list; sample size, the full tracked outlet list, times 2 days. Domain reason: the effect shows only after release, so this runs as a safe-to-fail probe, not a committed plan. [1] It runs in parallel with the step it follows, capped by its 4-hour budget.

## Follow-up

Conditions that change the recommendation:

- If A1 is false and a crisis plan exists, follow the plan and keep the freeze from Step 1.
- If the statement implicate a regulator or a court, counsel leads every step, and Step 4 needs counsel sign-off. [inference]
