## Headline

No prompt can stop hallucination fully; you can lower the error rate and catch the rest with a check pass. Supporting points:

1. A language model predicts likely text, so wrong facts come from the mechanism itself, not from one switch you can turn off [1].
2. The prompt with the largest measured effect grounds each answer in text you supply, requires a quote per claim, and allows the answer "Not in the source."
3. Prompting alone reduces errors but does not remove them, so measure the error rate and add a second check pass.

## End

I recommend that we apply the prompt below, then measure and verify. All three actions are stochastic: the output varies per run, so each test states a metric, a threshold, and a sample size, and the test is written before the work. All three actions sit in the Complex domain: the result shows only after a trial [18], so each step is a small probe with a stop condition.

1. **Measure the baseline.** Run 20 questions with a known answer key on your current prompt. This gives a number to compare against, so later changes are not guesses. Test: fact-error rate on 20 questions; record it; stop if any question has no checkable answer. Domain: Complex, because the rate is known only after the run [18] [judgment].
2. **Switch to the grounded prompt.** It removes answers that come from memory alone, the largest source of invented facts [1]. Use this text: "Answer only from the source text below. For each claim, add one short quote from the source. If the source does not contain the answer, write: Not in the source. Do not add facts from other knowledge." Test: same 20 questions with the source pasted in; pass when the error rate is 1 error or fewer (5%); stop and change method if errors stay above that. Domain: Complex, because the pattern holds only if your model follows quote instructions; the quotes are what could break it [18].
3. **Add a check pass.** A second pass re-reads each claim against the source and flags claims without a quote, so it catches errors that step 2 lets through. Test: on 20 flagged responses, a claim is accepted only when a human confirms the quote supports it; pass when 18 of 20 flags are correct (90%); if flags fall below that, drop the pass. Domain: Complex, because flag quality shows only per run [18].

Step 3 MUST NOT start until the test in Step 2 runs, because it checks the output of step 2.

If A1 is false and your task is code or data, replace step 3 with an execution test: run the code or query and compare the result with the expected output.
