Below is the prompt that starts the work, stated to the point of refusal.

```text
Answer only from the passages in the Sources section. Cite a passage
number for every factual sentence. If no passage supports the answer,
reply exactly: Not in the documents. Do not use knowledge from training.
Do not soften a refusal. After the draft, list each claim with its
passage. Delete any claim with no passage.
```

The task kind is stochastic, since the same prompt gives different runs. The alternative is training the model on the target domain, which loses because it costs order of decades more effort than edits [3] and does not reach zero per [2].
