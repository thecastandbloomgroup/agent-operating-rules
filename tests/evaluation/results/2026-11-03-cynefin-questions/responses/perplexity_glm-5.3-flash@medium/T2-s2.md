## Headline

No prompt removes fabrication completely. The best prompt forces citations, refusal without a source, and a separate verification pass, and even that only reduces the rate [1] [2].

1. Prompting alone gives a partial reduction, not zero [1] [2].
2. A separate verification step cuts the error rate more than an instruction alone [2].
3. Any answer without a source must carry the label "[inference]" or a refusal.

## Background

The request asks for one prompt that stops a model from inventing facts. Hallucination here means fluent output that states false facts, names, or citations [1]. A single instruction cannot remove it because the cause sits in training, not in wording [1].

## Relevance

A false name, number, or citation passing as fact can cost review time or worse. A prompt change takes one session, so it is the cheapest first control.

## Information

**Evidence**

Hallucination arises from how the model is trained, and it is systematic, so wording alone cannot remove the cause [1]. A 2023 study tested a chain-of-verification prompt pattern. The model drafts an answer, writes check questions, answers each check alone, and then revises. The study reported fewer factual errors across tasks than the baseline prompt [2].

**Assumption log**

A1. The target is a general text LLM in a chat setting, with no retrieval tool attached. Why not measured: the material does not state it. Validate by: ask which model and tools are in use. If wrong: put a retrieval step before the prompt change, because grounding beats wording [1].

A2. False answers carry work or safety cost for the user. Why not measured: the user has not answered. Validate by: ask the stakes for one recent use case. If wrong: skip the review rubric in Step 3.

**The prompt**

Put these four clauses in the system prompt, in this order:

```text
Use only the provided sources. Cite every external fact with a number.
If no source supports a claim, write [inference] or say you do not know.
Do not invent names, numbers, dates, or citations.
Before you send: check each factual sentence against a source.
Drop or relabel every sentence that fails the check.
```

**Alternative considered**

Fine-tuning or a retrieval system is the stronger fix over months [1]. It loses here because it costs more and takes days. The prompt change lands in one session and tests the ground before any spend.
