Headline
The best prompt is a refuse rule: answer only from the user text, or say you do not know.

- This rule blocks a claim that the user text does not support.
- No wording can check a fact that sits outside that text.
- A 20-item test shows the change on your model.
- A tool that fetches sources is a stronger and separate control.

Background
The request asks for the best prompt to stop a model from hallucinating. Hallucination means a fluent claim with no support in the user text or in a real source. The need is one instruction a chat model can follow.

Relevance
An unsupported claim can still sound sure, so a reader may act on it. A text rule is the control you can apply before a tool or a model change.

Information
Neural generators emit text that is not faithful to a source, even when that source is present.

Survey work treats this unsupported output as a known failure mode of generation models.
[1]

A prompt can forbid an unsupported claim. Therefore it cannot supply a missing fact.

Confidence is high, with two secondary papers as the basis.
