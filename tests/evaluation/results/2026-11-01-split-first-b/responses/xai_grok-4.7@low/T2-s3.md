Headline
No single prompt stops a model from inventing facts.
A source bound instruction limits answers to given text.
Retrieval supplies facts the model does not hold.
A separate check rejects claims that lack a source span.
A fixed question set shows whether the unsupported rate falls.

Background
You asked for the best prompt to stop hallucination. Hallucination here means a fluent claim that the given sources do not support. A wording change cannot add missing knowledge or guarantee truth.

Relevance
Decisions that use model text fail when a claim has no source. Therefore a prompt needs a boundary, a source, and a test.

Information
Ji and others define hallucination as generated text that is unfaithful or not factual [1].
Lewis and others add retrieved documents as extra input before generation [2].
On knowledge tasks, that setup beat generation from model memory alone [2].
High confidence, instruction text does not bind every token: no prompt guarantees zero invented claims [judgment].
Therefore the useful prompt is a constraint, not a wish.

Use this prompt:

Answer only from the sources in this message.
If those sources do not contain the answer, write: Not in sources.
Do not add facts from outside the sources.
Cite the source line for each claim.
If sources conflict, report both and do not choose.

A1. The goal is fewer unsupported factual claims, not creative writing. Why not measured: the material does not state the task. Validate by: name the task type on one sample. If wrong: drop citation rules and keep a style prompt.
A2. Sources or a retrieval tool are available. Why not measured: the material does not state the setup. Validate by: check for a document store or tool. If wrong: abstention is the limit, and new facts will not appear.

Alternative considered: the line "Never hallucinate" loses because it sets no evidence boundary and no test.
