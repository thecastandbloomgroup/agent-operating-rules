## Headline

The engineering team will migrate authentication to JSON Web Tokens in two stages and test sign-up conversion separately.
The auth service will issue JSON Web Tokens with asymmetric keys to remove database session lookups.
A dual-read adapter will validate legacy session cookies during migration to prevent user logouts.
An isolated split experiment will test registration form simplifications to improve sign-up conversion.

## Background

This section covers the request to replace stateful sessions with JSON Web Tokens, known as JWT [1].
The user request also seeks better sign-up conversion in the same work stream.
The current system stores active session records in a relational database [judgment].

## Relevance

Coupling security infrastructure changes with registration form changes creates operational risk [judgment].
Therefore, the team must decouple token verification from user acquisition experiments to prevent service outages.

## Information

First, this section covers authentication performance and registration funnel benchmarks.
Stateful session checks require central database lookups that add 5 to 15 milliseconds of latency per request [judgment].
In contrast, asymmetric JWT verification per RFC 7519 takes under 1 millisecond on local CPU cores [1].
However, token revocation requires short expiry windows or revocation lists [judgment].
Sign-up conversion drops by 10% for every additional input field per form design benchmarks [2].
For example, removing non-essential fields improves completion rates without altering backend authentication logic [judgment].

Conversion lift from field reduction is likely (66 to 100%), based on published form benchmarks [2].

A2. Extra registration fields cause current user drop-off. Why not measured: The material does not state it. Validate by: Review drop-off rates by form field in analytics. If wrong: Test landing page value propositions instead of form length.

Reason it loses: A single deployment conflates token validation defects with user registration friction [judgment].
