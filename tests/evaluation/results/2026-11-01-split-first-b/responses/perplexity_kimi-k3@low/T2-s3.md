# Headline

No single prompt can stop hallucination, but the best prompt pattern is one that forces the model to cite sources and say "unknown" when it lacks evidence.

- Prompts can reduce false claims but cannot remove them, because the cause sits in training, not in wording [judgment].
- The strongest pattern combines three parts: demand citations, permit refusal, and forbid guessing.
- Retrieval of real documents beats prompting alone, so add documents when accuracy matters.

# Background

The request is for one prompt text that prevents fabricated answers. Hallucination means the model states false facts with confident wording.

# Relevance

A wrong prompt gives false confidence, and fabricated facts in downstream work cost more than a cautious "unknown."

# Information

**Recommended prompt text:**

> "Answer only from the provided sources. Cite the source for each factual claim. If the sources do not contain the answer, reply 'I do not have enough information' and list what is missing. Do not guess. Do not use outside knowledge."

Evidence and reasoning:

1. Grounding in provided sources cuts fabrication because the model repeats given text instead of generating from memory [judgment].
2. An explicit refusal option works because trained models default to answering, so permission to decline changes the output [judgment].
3. No prompt reaches zero hallucination, because generation is probabilistic [no source]. Confidence: high, based on consistent behavior across model evaluations [judgment].
