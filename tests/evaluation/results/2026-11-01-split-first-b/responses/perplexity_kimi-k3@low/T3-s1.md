# Headline

Split this into two independent initiatives: migrate sessions to JWT first, then run a measured sign-up conversion experiment.
1. The two changes share almost no code, so coupling them adds risk without saving work.
2. JWT migration is deterministic and testable; conversion is stochastic and needs an experiment, not a code change.
3. Shipping both together makes it impossible to attribute a conversion change to either cause.

# Background

The request combines an authentication migration (stateful sessions to stateless JWT) with a sign-up conversion improvement. These are different task kinds with different test methods.

# Relevance

Bundling them creates a confounded rollout. If sign-ups rise or fall after release, the team cannot tell which change caused it.
