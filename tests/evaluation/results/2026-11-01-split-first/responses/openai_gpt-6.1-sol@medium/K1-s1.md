### The connection-scope discrepancy

The deployment has four pods and eight worker threads per pod. The pool configuration specifies eight connections. [2]

If each pod has one independent pool, the nominal total is 32 connections. [inference] Yet the reported peak active connections from this service is eight. [1]

Active connections and configured capacity differ, so this does **not** prove a shared eight-connection limit. [judgment] Check pool instances, connection proxies, database role limits, and metric scope before choosing a new size. [judgment]
