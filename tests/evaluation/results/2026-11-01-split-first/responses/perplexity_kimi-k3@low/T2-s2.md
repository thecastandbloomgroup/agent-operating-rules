# Headline

No prompt can make a model stop hallucinating, but a grounding plus abstention prompt reduces it measurably.

- Hallucination is a feature of how language models generate text, so no prompt removes it fully [1].
- A prompt that limits answers to provided sources and requires an "I do not know" reply cuts the rate [judgment].
- The gain is real only when measured, so run a before and after test on your own data.

# Background

You want one prompt that prevents a language model from inventing facts. No such prompt exists, but one pattern performs best in practice.

# Relevance

A wrong fact in production output erodes trust and can carry legal risk. A small prompt change plus a measurement step reduces that risk today.

# Information

The recommended prompt text, placed as a system or instruction message:

```text
Answer only from the sources provided below.
If the sources do not contain the answer, reply exactly: "I do not have enough information."
For every claim, quote the source line that supports it.
Never invent facts, numbers, names, or references.
```

Three properties drive its effect. First, it restricts the answer space to the supplied context, which removes most opportunities to invent. Second, it gives the model an acceptable exit, so not answering becomes allowed instead of being replaced by a guess. Third, the quote requirement creates an audit trail a reviewer can check.

Supporting evidence:

- Hallucination is documented as an inherent generation failure, and mitigations work by grounding and verification, not instruction alone [1].
- The abstention and quote requirement mechanisms rest on [judgment], drawn from common prompt engineering practice, not a single controlled study. Medium confidence.

Assumption log:

A1. The model is used in a chat or API setting that accepts a system message. Why not measured: the material does not state it. Validate by: check the API surface in use. If wrong: apply the same text as a user message prefix, with slightly weaker effect.

A2. Source documents exist to ground answers. Why not measured: the material does not state it. Validate by: confirm a retrieval step or pasted context exists. If wrong: add retrieval first, or drop the quote requirement.

Alternative considered: asking for step by step reasoning (chain of thought) is the strongest alternative. It loses because it improves arithmetic and logic, not factual accuracy, and can produce convincing wrong answers [1].

# End

I recommend that we:

1. Add the grounding plus abstention prompt above to the system message in one session. This removes the open door to invented facts. Deterministic and Clear, because the edit is a known best practice with a fixed acceptance result.
   Given the system message contains the four lines,
   When a user asks a question outside the sources,
   Then the model replies "I do not have enough information."
2. Attach source documents or retrieval output to every request in the same session. This gives the model the facts it is allowed to use. Deterministic and Clear, for the same reason as Step 1.
   Given a request includes a sources block,
   When the model answers,
   Then each claim carries a quote from that block.
3. Measure hallucination rate on 50 past questions before and after Steps 1 and 2, within a two hour budget. Complex and stochastic, because model output varies per run, so this is a capped probe with a measure. Metric: share of answers with an unsupported claim. Baseline: the pre-change rate on the same 50 questions. Pass threshold: a drop of at least 50% at a sample size of 50. Stop condition: stop at two hours even if fewer samples are done.

Steps 1 and 2 run in parallel. Step 3 MUST NOT start until the checks in Steps 1 and 2 pass.

If A2 is false, replace Step 2 with setting up a retrieval step, and rerun Step 3 after it works.

# Follow-up

Conditions that change the recommendation: no available sources activates the If clause in A2, and a model without system message support activates A1.
