### Headline

No prompt stops hallucination on its own; the strongest single prompt forces the model to answer only from supplied sources and to say when the answer is missing.

- Prompt wording alone leaves high error rates: a strong model gave truthful answers on 58% of test questions, against a 94% human baseline [1].
- Grounding the reply in retrieved or pasted sources reduces fabrication relative to the same models without sources [3].
- A required refusal phrase works because models can report, better than chance, when they do not know an answer [2].
- The errors that remain need a measured rate and a verification pass, not more prompt text [4].

### Background

Hallucination means a fluent answer that contains invented facts. The request asks for one prompt that stops it. Benchmarks show no prompt reaches zero errors, so the answer below pairs a template with measurement and checks.

### Relevance

Invented facts in output cost user trust and cause rework. A tested template with a measurement loop gives the largest reduction available without new tooling [judgment].

### Information

Evidence, first. It is very likely (90 to 100%) that no text-only prompt reaches zero invented facts on open tasks [judgment]. On a standard truthfulness test, the best large model scored 58% truthful while humans scored 94% [1]. Adding retrieved documents to the prompt raised factual accuracy on knowledge tasks compared with the same models without retrieval [3]. Large models can predict whether they know an answer, which supports mandatory abstention [2]. Sampling a model twice and comparing answers flags inconsistent, likely invented, claims without external tools [4].

The template, for use as the system prompt:

```text
Answer only with facts from the sources under SOURCES.
If the sources do not contain the answer, reply exactly: "No source contains this answer."
Do not invent dates, numbers, names, citations, or links.
After each factual sentence, add the source number in brackets, for example [2].
```

Variant for chats where no sources can be attached:

```text
Answer only facts you know with confidence.
When unsure, reply exactly: "Not enough information to answer."
Do not invent dates, numbers, names, citations, or links.
```

Assumption log:

A1. The target is a general chat model without retrieval attached. Why not measured: the material does not state it. Validate by: run the template once with sources attached and once without. If wrong: do Step 2 first.

A2. The tasks are factual, not open creative writing. Why not measured: the material does not state it. Validate by: review one week of representative queries. If wrong: keep only the no-invention clause, and relax Step 3.

Alternative considered: a role prompt alone, for example "You are a truthful expert," loses. Instruction-only wording leaves falsehood rates near the 58% baseline above [1], because generation stays probabilistic [judgment].
