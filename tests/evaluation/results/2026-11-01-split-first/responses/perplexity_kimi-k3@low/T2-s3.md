Information
The recommended prompt text:

"Answer only from the context below. Do not use knowledge outside the context. If the context does not contain the answer, reply exactly: 'I do not have that information.' After each claim, quote the exact context passage it comes from. Context: [paste source text here]"

Second, an explicit refusal phrase gives the model a valid exit, which cuts confident guesses [judgment]. Third, requiring a quote per claim makes unsupported claims visible, so a reader can check them in one pass [judgment].
