## Headline

The fix is not cultural alignment; it is removing the choice by adopting an automated SQL formatter.

1. Disagreement about style is a tool problem, so automate the style and end the debate.
2. One short document records the chosen configuration, which ends the rationale debate.
3. Continuous integration (CI) enforcement removes enforcement from humans, which ends the friction in reviews.

## Background

The team argues about SQL formatting in each review. The request is to fix the culture problem.

## Relevance

Style debate in review consumes reviewer time and creates conflict. A formatter ends the debate at low cost, therefore the team can discuss logic instead of commas.
