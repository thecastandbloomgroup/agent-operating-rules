## Headline

Treat this as a decision-rights problem, not a culture problem: pick one style once, then let a tool enforce it.

- The disagreement lasts because nobody owns the decision.
- A formatter in CI moves style out of human review.
- A one-time reformat prevents noisy diffs afterward.
- A measured trial shows whether the friction actually drops.

## Background

The team has no shared SQL format, and every review turns into a style debate. The request is to end that friction. The material gives no tooling, dialect, or team size.

## Relevance

Each style comment costs reviewer time and delays merges. The debate also hides real defects in the query logic. [judgment]

## Information

**Evidence**
- Style debates are repeatable and rule-based, so a program can settle them. [inference]
- SQLFluff lints and fixes SQL, reads a per-repo config file, and sets the dialect in that file [1].
- A formatter in CI gives the same verdict on every run, so no reviewer has to raise style. [inference]
- Confidence that the fix removes most style comments: medium confidence, no team data yet.

**Alternative considered**
