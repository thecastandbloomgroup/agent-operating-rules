## Headline

Reconcile the Q3 report (third-quarter report) to its source data, one figure at a time, before you change anything.

- The report is not attached, so the first step is to list which figures look wrong.
- Next, compare totals with the source system to find where the gap starts.
- Then check definitions, dates, and formulas, because these cause most mismatches [judgment].
- Last, fix the cause and re-issue the report with a change note.

## Background

The request says that some numbers in the Q3 report look wrong. The message names no report, no figure, and no expected value. The plan below works for any quarterly report that draws on a source system.

## Relevance

A wrong figure in a published report spreads to later decisions. Early correction costs less than correction after readers have acted on the numbers [judgment].

## Information

Evidence:

- Common causes are a period cut-off error, duplicate rows, a changed definition, a currency mismatch, and a formula range error [judgment].
- A formula or range error in the report is about as likely as not (33 to 66%) [judgment].

Each action carries a Cynefin domain. The domain describes how cause and effect relate in the work.

Assumption log:

A1. The report is a business report for July 1 to September 30, 2026. Why not measured: the material does not state it. Validate by: ask the report owner for the period. If wrong: change the dates in Steps 2 and 3.

A2. A source system (for example a ledger or database) exists for comparison. Why not measured: no tool can reach it. Validate by: ask who owns the source data. If wrong: compare with the Q2 report and a manual sample instead.

A3. The goal is to find and fix the cause, not to rewrite the report. Why not measured: the user has not answered. Validate by: confirm with the user after Step 1. If wrong: stop after Step 3.

Alternative considered: ask the user to send the report first. This loses because the plan is the same in either case, and Step 1 collects the same facts at no extra cost.

## End

I recommend that we take these steps in order:

1. **List the suspect figures.** Increment: one table with the report value, the expected value, and the basis for the expectation, for each figure.
   - Blocker removed: no one knows which figures are wrong.
   - Kind: deterministic.
   - Domain: Confused, because the scope of the problem is unknown.
   - Test:
     - Given the Q3 report and the prior quarter report
     - When each suspect figure is entered in the table
     - Then every row has a report value, an expected value, and a basis

2. **Compare totals with the source.** Step 2 MUST NOT start until the Step 1 test passes. Increment: a line-by-line comparison for the largest suspect figure.
   - Blocker removed: the location of the first gap is unknown.
   - Kind: deterministic.
   - Domain: Complicated, because analysis of the data finds the answer.
   - Test:
     - Given the report total and the source export for July 1 to September 30
     - When both are summed by line
     - Then each difference is zero or has a written reason

3. **Rank the causes.** Step 3 MUST NOT start until the Step 2 test passes. Increment: check cut-off dates, duplicates, definitions, currency, and formulas for the gap in Step 2.
   - Blocker removed: the cause is not yet named.
   - Kind: evaluative.
   - Domain: Complicated, because expertise can separate the causes.
   - Rubric: criteria are fit to the gap size (weight 50%), evidence from the data (30%), and ease of confirming (20%). The pass threshold is a score of 80% for one cause, with a data sample as evidence.

4. **Fix and re-issue.** Step 4 MUST NOT start until Step 3 names one cause that passes the rubric. Increment: correct that cause, then re-issue the report with a change note.
   - Capability added: a report that readers can trust.
   - Kind: deterministic.
   - Domain: Clear, because the fix for a named cause is standard practice.
   - Test:
     - Given the corrected report and the source export
     - When the totals are compared again
     - Then all differences are zero and the change note lists each edit

## Follow-up

Conditions that change the recommendation:

- If A2 is false, replace Step 2 with a comparison against the Q2 report and a manual sample.
- If the figures come from a forecast model, treat Step 3 as stochastic. Set a metric, a baseline, a threshold, and a sample size first.
