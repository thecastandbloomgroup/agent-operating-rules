## Headline

No prompt stops hallucination fully, but a grounding prompt with supplied sources cuts it most.

- Hallucination has several causes, so one prompt cannot remove all of them [1].
- Supplied sources give the model facts to copy, so they remove the largest cause.
- An "I don't know" rule and a verification pass catch most of the remaining errors.

## Background

You asked for the best prompt to stop a model from inventing facts. The request names no model, task, or source material. Section 1 below gives the prompt, and the End section gives the steps to use it.

## Relevance

A false answer that reads well costs more than a refusal. A tested prompt lets you measure the gain instead of trusting it.

## Information

**Prompt (copy this):**

```text
Answer only from the sources below.
Do not use outside knowledge.
If the sources do not contain the answer, reply: "Not in the sources."
For each claim, quote the sentence that supports it.
Do not guess names, numbers, dates, or citations.
If you are unsure, state your confidence as a percentage.

Sources:
<paste sources here>

Question:
<paste question here>
```

**Evidence:**

- Retrieval of source text improves factual accuracy on knowledge tasks (supports the "sources" line) [2].
- A second pass that checks each claim lowers the count of false statements (supports the "quote" line) [3].
- Model confidence tracks correctness on many questions, but not on all (supports the "percentage" line) [4].
- No source claims a prompt removes hallucination. It is very likely (90 to 100%) that some errors remain.
- Confidence in this view is high: four secondary sources agree, and none disagrees.

**Assumption log:**

A1. You use a chat model with no search tool. Why not measured: the material does not state it. Validate by: ask the model for today's date and a recent fact. If wrong: skip Step 1 and use the tool's own retrieval.

A2. Your task is factual question answering. Why not measured: the user has not answered. Validate by: read your last five prompts. If wrong: the quote rule changes for creative work, where you should drop it.

**Alternative considered:** Fine-tune the model on your domain data. It loses because it costs far more than one prompt and still leaves errors [1]. [judgment]

## End
