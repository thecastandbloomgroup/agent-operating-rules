## Headline

No prompt stops hallucination fully, but a source-grounded prompt with an explicit "not found" exit lowers it most.

- Grounding the answer in supplied text removes the main cause: the model fills gaps from memory.
- A required exit phrase gives the model a safe option when the sources lack the answer.
- A required supporting quote makes each claim checkable.
- A small test set shows whether the prompt works on your task.

## Background

You asked for one prompt that stops a language model from stating false facts (hallucination). The model, task, and source material are not stated. This answer gives a prompt for the common case and a way to test it.

## Relevance

A false statement that looks confident costs more than a refusal. The prompt below is cheap to deploy, and the test shows within one session whether it helps.

## Information

The prompt (replace the bracket with your source text):

```text
Answer only from the sources below.
Do not use outside knowledge.
Quote the exact sentence that supports each claim.
If the sources do not answer the question, reply: Not in the sources.
Do not guess numbers, names, dates, or links.
Before you reply, check each claim for a quote. Delete any claim without one.

Sources:
[paste text here]
```

Evidence:

1. Surveys name unsupported generation as the core failure and list grounding in source text as a main mitigation.

   [1]

2. Retrieval of source passages improved factual accuracy on knowledge-intensive tasks against a model without retrieval.

   [2]

3. Models estimate well whether they know an answer, so a prompt that permits "Not in the sources" can use that signal.

   [3]

4. The prompt lowers the rate of false claims: likely (66 to 100%). It removes them: very unlikely (0 to 10%). [judgment]
