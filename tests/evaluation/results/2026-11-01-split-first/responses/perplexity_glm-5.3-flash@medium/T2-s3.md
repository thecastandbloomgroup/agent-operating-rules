## Headline

No prompt can stop hallucination, because part of it is built into how language models score answers [1]. The best prompt is the shortest one that forces a checkable source for every claim. It makes the model either cite the given material or answer exactly "NOT FOUND". Grounding the model in real documents cuts the error rate more than wording does [3].

## Background

The request: the best prompt that makes a model stop inventing facts. The answer depends on task type, so the recommendation below also adds a test to measure the rate.

## Relevance

Prompt wording alone changes little, and teams often trust a well written prompt without measuring it. The test set in the End section closes that gap.

## Information

**Evidence.**

Three findings drive the recommendation.

1. Hallucination has parts that no prompt removes. Kalai and coauthors argue that models now score well on benchmarks that reward guessing over abstention, so some error persists by design, and the training target limits how far prompting can reduce it [1]. This is secondary analysis of primary results [S next to the claim, because only the paper's own runs are primary].
2. The survey of Ji and coauthors lists prompt methods, citations, and answer abstention as partial mitigations, not cures [2].
3. Retrieval grounding lowers hallucination in long form question answering. Shi and coauthors report a lower hallucination ratio across three question answering tasks when the model uses retrieved material, compared with no retrieval [3].

Uncertainty statement. The rate improvement varies by model and task. Confidence: moderate, three independent papers agree, but none reports a rate for the model the user runs [inference until Step 3 of the End section measures it].

**Assumptions.**

- A1. The user controls a system prompt in the product that runs the model. Why not measured: the material does not state it. Validate by: check the platform settings for a system prompt field. If wrong: use the template as the first message per request, word for word.
- A2. The task is factual question answering, not creative writing. Why not measured: the user has not answered. Validate by: list 10 past tasks and count how many need true facts. If wrong: skip the abstention rule, because inventing detail is a feature in fiction.

**The prompt.**

Replace system prompt wording such as "do not hallucinate" with rules that produce checkable output:

```text
Answer only from the SOURCE TEXT provided in this conversation.
For each factual claim, add (source: paragraph N or exact quote).
If the source text does not contain the answer, write exactly: NOT FOUND.
Do not add outside knowledge to fill a gap.
Before the answer, list any part of the question you could not verify.
```

The reason it works better than a plea such as "be accurate": each line is checkable by a scorer, and the abstention token gives a separate, countable output [1], [2].

**Alternative considered.**

A longer prompt with many safety instructions. It loses because exhortations without a checkable rule give no countable signal, and calibration studies show models abstain poorly when told to be careful [1], [2].

## End

I recommend that we deploy the evidence and abstain template above with a measured test set, and add retrieval only when Step 3 shows the rate misses the threshold.

1. Step 1 (deterministic, Clear). Build a test set of 50 questions in one session: 25 answerable from a source document and 25 not answerable. Blocker removed: no baseline exists. Because no baseline exists, the later steps cannot show improvement. Test, written first:
   ```gherkin
   Given a source document and 50 questions with expected answers
   When the scorer compares each answer to the key
   Then each answer is labeled correct, wrong, or NOT FOUND
   And the 25 unanswerable questions expect NOT FOUND
   ```
2. Step 2 (deterministic, Clear). Install the prompt template in the system prompt field. Blocker removed: claims without checkable sources. Test:
   ```gherkin
   Given the template in the system prompt and one test question
   When the model answers
   Then every factual claim carries a source marker
   And unanswerable questions return NOT FOUND
   ```
3. Step 3 (stochastic, Complex). Run 3 trials of the full 50 question set with the new prompt. Metric: wrong answer rate. Baseline: scoring key from Step 1. Pass threshold: no more than 5%, that is 2 wrong of 50. Sample size: 50 per trial. Budget: one session. Stop condition: threshold missed on the third trial, so go to Step 4. Cynefin: Complex, because the effect depends on this model and task, and the leverage over Step 1 is a guess until the trials run. Cynefin splitting note: the domain stays Complex from the original prompt evaluation problem, because cause and effect become visible only in the trials.
4. Step 4 (Complicated). Do not start until Step 3 misses the threshold. Add retrieval: paste the source documents into the context before the model runs, so the citation rule points at real text. Analysis step: compare paste in context with a retrieval tool, then pick one. Blocker removed: the model answers from memory, where [3] shows the rate is higher. Test: rerun Step 3 on the same set; threshold unchanged.
